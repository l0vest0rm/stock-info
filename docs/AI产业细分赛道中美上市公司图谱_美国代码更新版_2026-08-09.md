## 一、口径与使用方法

### 1. “中国公司侧”和“美国市场侧”如何定义

- **中国公司侧**：以中国大陆或中国香港为主要经营/总部所在地的上市公司，上市地可为A股、港股或美国市场。
- **美国市场侧**：只要具有可核验的美国交易代码，即可纳入，不以公司总部或注册地是否在美国为限制。各赛道主表优先纳入NYSE、Nasdaq等主要交易所标的。
- **†**：总部或主要注册地不在美国，但在美国主要交易所上市/交易，例如台积电（TSM）、ASML（ASML）、SK海力士（SKHY）、Arm（ARM）。
- **‡**：仅有美国OTC代码。OTC与NYSE/Nasdaq上市并不等价，流动性、报价连续性、券商可交易性、存托凭证类型及信息披露义务可能明显不同，因此统一放在文末单列。
- 同一家公司可能同时出现在“中国公司侧”和“美国市场代码速查表”中。例如阿里巴巴、百度、小鹏汽车既是中国公司，也具有美国交易代码。

### 2. AI暴露级别

| 级别 | 含义 | 研究要求 |
|---|---|---|
| **A：直接核心** | AI产品、AI资本开支或AI工作负载是核心业务/关键增长来源 | 必须核验AI收入、订单、客户、产品代际、单位经济性和现金流 |
| **B：显著受益** | AI是重要增量，但公司仍有较大非AI业务 | 需要拆分AI与传统业务，避免用整体收入替代AI敞口 |
| **C：外围映射** | 通过电力、工业、材料、终端换机等间接受益 | 传导链较长，只有可核验订单/收入才应给予AI权重 |
| **高风险** | 新上市、持续亏损、客户高度集中、资本密集或商业模式仍在验证 | 优先看现金跑道、融资/稀释、客户合同与真实交付 |

### 3. 产业链总览

```text
AI需求与应用
├─ 模型与软件：基础模型 → 数据平台 → 企业Agent/Copilot → 消费应用 → 安全
├─ 云与数据中心：云平台 → IDC/算力租赁 → 服务器 → 网络 → 存储
├─ 核心硬件：GPU/ASIC/CPU → HBM/DRAM → 先进封装 → 光/铜互连
├─ 制造与基础设施：晶圆代工/设备/材料 → PCB/连接器 → 电源 → 液冷 → 电网
└─ 物理AI：AI PC/手机 → 自动驾驶 → 机器人 → 医疗与科学发现
```

真正的瓶颈会沿产业链迁移：**芯片供给 → HBM与先进封装 → 网络与光互连 → 电力与散热 → 集群利用率 → 应用变现**。因此，不能把“AI行业”视为单一赛道，也不能把所有数据中心、半导体或软件公司都视为同等AI标的。

## 五、中美上市公司结构的主要差异

### 1. 美国市场更强的是“平台与全栈”，且汇集全球关键供应商

美国市场既覆盖GPU、定制ASIC、交换芯片、云、数据库、企业软件和全球分发平台，也通过ADR、ADS或普通股上市汇集台积电、ASML、SK海力士、Arm、NXP、STMicroelectronics、SAP等非美国总部公司。NVIDIA、Microsoft、Amazon、Alphabet、Broadcom等平台公司能够把芯片、网络、云和软件收入连接起来；全球供应商则提供先进制造、存储、IP和企业软件敞口。研究重点是**巨额资本开支是否形成使用量、定价权与自由现金流，以及美国证券与本土证券之间的存托比例、汇率和流动性差异**。

### 2. 中国侧上市标的在硬件制造链更密集

中国A/H股在光模块、光器件、PCB、服务器制造、电源、液冷、通信设备与国产半导体设备方面公司较多。优势是产业链完整、扩产和交付速度快；风险是**客户集中、价格竞争、营运资本占用、技术代际变化和资本开支过剩**。

### 3. 中国“纯AI”上市池在2025—2026年明显扩容

摩尔线程、沐曦、壁仞、天数智芯、爱芯元智、智谱、MiniMax、长鑫科技等上市后，中国市场不再只有“AI概念映射”，而开始拥有GPU、基础模型、边缘芯片和DRAM的直接标的。但这些新公司通常伴随高估值、高研发、亏损、客户集中或供应链不确定性，不能用成熟平台公司的估值框架机械套用。

### 4. 光模块与存储的投资逻辑完全不同

- **光模块/光器件**：更受端口速率、模块数量、客户份额、良率、ASP和技术路线驱动，产品周期较短。
- **存储**：既有AI带来的HBM/高容量需求，也有典型的供需、库存、合约价与资本开支周期。
- **服务器/ODM**：收入体量可能快速增加，但通常毛利率不高，现金流和营运资本决定质量。
- **软件/模型**：资本开支较轻或中等，但推理成本、获客、留存和价格竞争决定盈利路径。

## 六、研究每个赛道时应重点追踪什么

| 赛道 | 最关键的经营指标 | 最常见误区 |
|---|---|---|
| GPU/AI芯片 | 产品代际、软件栈、客户验证、出货、集群稳定性、毛利、研发和现金跑道 | 只比较理论算力或单卡参数 |
| HBM/DRAM/NAND | 位元出货、ASP、良率、产品结构、库存、资本开支、客户认证 | 把所有存储公司都当成HBM公司 |
| 光模块 | 800G/1.6T出货、端口数、客户份额、ASP、良率、产能、CPO/LPO路线 | 把送样或技术能力当成规模收入 |
| 网络/交换 | 交换容量、端口速率、设计赢单、客户集中、拥塞控制、软件附加值 | 忽略GPU利用率和网络架构变化 |
| PCB/连接 | 层数、低损耗材料、良率、单机价值、扩产、客户集中 | 只看产能，不看技术门槛和良率 |
| AI服务器 | 积压、GPU供给、交付、毛利、库存、应收、经营现金流 | 把低毛利转售收入等同高质量增长 |
| 电源/液冷 | 机柜功率、项目订单、客户认证、产能、服务能力、毛利 | 用“小额样机/测试”外推大规模收入 |
| IDC/算力租赁 | 电力、签约、上架率、利用率、租期、融资成本、资本回报 | 认为拥有土地电力就等于拥有AI云能力 |
| 云厂商 | AI收入、用量、RPO、资本开支、折旧、利用率、自由现金流 | 只看资本开支，不看回报和现金流 |
| 基础模型 | API/订阅收入、付费用户、留存、推理成本、毛利、现金余额 | 用榜单分数替代商业化和单位经济性 |
| 企业软件 | AI付费率、ARPU、净留存、销售效率、增量毛利 | 把免费AI功能当作独立收入 |
| 自动驾驶 | 量产车、真实里程、接管率、安全、单车成本、监管、付费率 | 把演示视频等同可规模运营 |
| 人形机器人 | 实际交付、任务自主性、BOM、毛利、客户复购、数据闭环 | 把遥操作或预设动作当成通用自主智能 |
| AI医疗/制药 | 临床证据、监管、付费方、医院工作流、里程碑、现金跑道 | 只看算法准确率或早期候选分子 |

## 七、从公司清单进一步筛选的通用框架

对任何一家“AI公司”，建议按下面顺序核验：

1. **AI收入是否真实可拆分**：来自产品销售、订阅、API、项目、租赁还是一次性授权？
2. **客户是否真实且可持续**：前五大客户占比、合同期限、取消条款、应收账款与回款。
3. **产品代际是否跟得上**：芯片/光模块/存储看代际，软件看模型与产品迭代，机器人看自主性。
4. **单位经济性是否改善**：毛利率、推理/电力成本、获客成本、折旧、售后与交付成本。
5. **现金流能否支撑扩张**：经营现金流、资本开支、存货、预付款、债务、股权融资和稀释。
6. **AI增量是否被传统业务抵消**：例如AI搜索可能增加成本并侵蚀传统广告，AI服务器可能拉低整机毛利。
7. **供应链与监管风险**：先进制程、HBM、设备、出口限制、数据合规、医疗/自动驾驶监管。
8. **估值是否已经透支执行**：高增长不自动等于高回报；需要把增长、利润率、资本需求和稀释放进同一模型。

### 4. 代码使用注意事项

1. **ADR/ADS比例**：一个美国存托凭证可能对应若干本土普通股，也可能只对应普通股的一部分，不能直接按股价比较。
2. **汇率与存托费用**：美国代码的回报会受本币兑美元汇率、存托费、税务和分红转换影响。
3. **主要交易所与OTC不同**：OTC不等于NYSE/Nasdaq上市；报价、成交量、做市商覆盖和信息披露框架可能明显不同。
4. **同名代码风险**：搜索代码时应同时核对公司全称、CUSIP/ISIN、证券形式和交易场所，尤其是OTC证券。
5. **代码会变化**：新ADR上市、退市、并购或存托计划终止都可能改变代码。交易前必须以公司IR、交易所或存托银行的最新资料为准。

## 十、使用限制与更新建议

- 本清单不包含实时股价、市值、估值倍数和盈利预测，因为这些数据变化很快，应在具体公司研究时重新抓取。
- “AI暴露级别”是研究分类，不是评级，也不代表收入占比的精确数字。
- 公司可能因并购、拆分、二次上市、ADR/ADS计划变化、退市或业务重组而改变代码和业务边界；交易前应核验公司IR、交易所、SEC/存托银行与券商的最新资料。
- 文中的OTC代码只表示存在美国场外交易标识，不代表所有券商账户都可交易，也不代表具有与美国主要交易所相同的流动性、监管层级或投资者保护。
- 建议至少按季度更新一次，并在重大芯片代际、云资本开支指引、模型价格、出口管制或新股上市后即时修订。
