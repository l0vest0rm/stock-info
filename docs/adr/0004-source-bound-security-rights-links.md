# Source-bound security-rights links

Security rights are versioned records on each listed security, and an A/H or ADR relationship is a separate, source-bound link between two securities that are already confirmed to the same operating company. We reject name-only matching and require declared official HTTPS filing, exchange, depositary, or issuer evidence because a shared issuer does not establish equivalent holder rights, conversion, price, liquidity, tax, or access; the extra manual workflow is intentional auditability rather than an automatic ticker merge.
