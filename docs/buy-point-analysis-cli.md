# 股票买点分析 CLI

按指定股票的东方财富前复权日 K，分析超跌条件、反转确认、均线趋势、量价关系和流动性风险：

```bash
npm run analyze:buy-point -- 688256
```

可用选项：

```text
--code CODE       股票代码；支持 688256、SH688256、688256.SH
--as-of DATE      分析截止日期，适合复现历史时点
--from DATE       K 线起始日期，默认截止日期前一年
--base-url URL    stock-info API 地址，默认 https://tinfo.cc
--config FILE     覆盖指标阈值配置
--json            输出机器可读 JSON
```

CLI 通过仓库的 `/api/kline` 行情 owner 读取数据，不包含其他 K 线源。默认至少需要 65 根有效日 K；阈值和评分位于 `web/src/config/buy-point-analysis.json`，并与个股“买卖建议”页面共用。

量能部分包括当日/20 日均量、5/20 日均量、上涨日/下跌日平均量、缩量回调和放量下跌。流动性部分包括当日与 20 日平均成交额、换手率和数据覆盖率。只有成交额或换手率数据覆盖达到配置门槛时，模型才会判定“流动性不足”；旧缓存缺少字段时会显示“数据不足”，不会误判为低流动性。

输出中的“支撑观察区”用于识别位置，“右侧确认触发”要求收盘确认，“参考失效位”用于在入场前估算风险。超卖不是单独的买入理由：跌破此前 20 日低点、均线仍为空头、反转没有量能确认或流动性不足时，结果会明确提示等待。该结果不含估值、基本面、公告、盘口深度和个人仓位信息，不构成投资建议。
