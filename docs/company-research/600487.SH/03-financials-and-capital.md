- 重要来源：[2026年第三季度报告（10-29披露）](https://static.cninfo.com.cn/finalpage/2026-10-29/1225635137.PDF)、[2026年半年度报告（8-27披露）](https://static.cninfo.com.cn/finalpage/2026-08-27/1225513678.PDF)、[2026年9月25日定增预案](https://static.cninfo.com.cn/finalpage/2026-09-25/1225582516.PDF)、[员工持股计划草案](https://static.cninfo.com.cn/finalpage/2026-09-25/1225582533.PDF)。

## 2. 营运资本与现金质量（2026-09-30）

| 指标 | 三季报披露值 | 关注理由 |
|---|---:|---|
| 货币资金 | 132.66亿元 | 不等于全部可自由使用现金 |
| 期末现金及现金等价物 | 91.08亿元 | 与“货币资金”口径不同 |
| 应收账款 | 239.13亿元 | 大项目/增长可能占用营运资本 |
| 存货 | 122.54亿元 | 备货、在制品与价格风险 |
| 短期借款 | 123.30亿元 | 期限结构及融资成本 |
| 经营现金流净额（1—9月） | 8.41亿元 | 对比归母利润61.63亿元需解释 |
| 购建固定资产、无形资产等支付现金（1—9月） | 26.31亿元 | 扩张期资金流出 |

**分析**：公司2026年前三季度盈利增长强劲，但经营现金流相对归母利润仍偏低，且当期建设支出较大。不能仅因货币资金较多认定无融资需求，也不能仅因现金流偏低认定资金危机。应连续分析应收周转、客户预付款、库存与合同资产、经营现金流在Q4的季节性变化，以及是否有并表/工程结算的非经常性影响。

## 3. 2026年拟向特定对象发行A股股票

2026-09-25公告的定增预案：**拟募资上限66.36亿元**，项目总投资合计约93.66亿元，发行价不低于发行期首日前20个交易日均价的80%，发行股数不超过发行前总股本的30%。后者只是**发行股数法定上限**，不是实际稀释率。以2026年10月三季报披露进度，尚需股东会、上交所审核、证监会注册，**不得写成融资已完成**。

### 公司正式解释与研究推断的分界

- **公司披露用途**：保障高端光学材料、扩充特种纤及高密度连接能力、CPO研发、海洋工程制造和交付、补充流动资金、优化长期资本结构。
- **研究推断**：光棒扩张希望降低上游瓶颈，高端组件希望向芯片端延伸；但在光纤景气高位规划、两三年后释放产能，具有典型周期逆转风险。
- **需要验证**：为生产扩产对应的真实合同、财务内部收益率、项目净现值、产能利用率、发行定价是否在当时保护老股东，以及19.9亿元补流的使用明细。不存在完整资料时不生成项目ROIC或目标价。

## 4. 2026年员工持股计划（与定增分开）

[正式草案](https://static.cninfo.com.cn/finalpage/2026-09-25/1225582533.PDF)：
- 参加人数计划不超过222人；来源为**公司此前回购的股份**，不等同于新增定增股份；
- 拟转让股票不超过843.68万股、约总股本0.34%；拟受让价34.27元/股；
- 2026/2027年度解锁比例分别60%/40%；以2025年度为基准，归母净利润增长率**目标值**分别90%/100%，或营业收入增长率目标值分别15%/20%；达标采用“或”，且存在触发值和部分解锁机制。
- **分析**：2026年1—9月累计归母利润已较高，指标挑战性需要对照2026全年实际结果与2027年项目周期，不能在没有真实股权成本及完整业绩验证前直接做利益输送结论。

## 5. 事件及风险结论

- 2026-09-25：披露定增预案及员工持股计划草案。
- 2026-10-29：三季报仍表述定增待股东会审议、交易所审核和证监会注册；**本次归档未发现已完成发行的正式公告**。后续如进度更新，以最新公告改写现时状态并在跟踪记录中保留变更。
- 股价变动与定增同时发生不等于因果关系已被证明；研究时分解行业景气、估值变化、政策/技术新闻与发行稀释。

## 跟踪与反证

1. 新光棒/光纤/FAU项目的建设节点、客户认证及实际产能释放；后续资本开支与折旧。
2. 2027年及后续光纤价格与毛利率是否受同行扩产影响。
3. 经营现金流、应收账款、存货、合同资产、短债与受限资金随季度变化。
4. 定增最终进度、发行价格/股数、募集资金实际用途和项目效益；员工持股实际过户、股份支付与解锁条件。
5. 海缆与海洋通信项目在手订单的转化质量、毛利率、境外执行风险。

**不能把本档案视为“买入/卖出建议”；无当期行情和可比市场预期数据，不给2026年10月31日目标估值。**
