## 核心研究主线

亨通应拆成两套相互影响但周期不完全同步的业务：**通信网络（光棒—光纤—光缆—光连接与海洋通信）**与**能源互联（电力线缆、海洋能源及海上工程）**。2026年前三季度利润增长，公司在三季报中主要归因于光通信需求增长、产品价格上涨及业务增长；同时营运资本和资本开支带来现金流压力。

- **景气线**：AI数据中心及网络升级带来的光纤品种结构升级、G.657抗弯/低损光纤价格弹性；注意普通光纤与高端特种光纤不可混称。
- **投资线**：2026年9月公告拟定增不超过66.36亿元，项目覆盖特种光纤、光棒、高密度MPO光缆、FAU/CPO、海洋能源和补充流动资金；不等于已发行或达产。
- **工程线**：海底电缆、海洋通信系统及PEACE运营相关在手订单，为光纤涨价之外的观察维度；订单不等于利润。
- **风险线**：2027—2028年起光棒等新增供应投放、价格高位回落的可能性；前三季度经营现金流远低于利润，需要持续核对回款。
