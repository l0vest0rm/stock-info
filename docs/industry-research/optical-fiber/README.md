# 光纤光缆行业｜2025—2030年需求、供给、价格与周期风险

- 研究基准日：2026-10-31
- 范围：光纤预制棒—裸纤/光纤—光缆—数据中心高密度连接的供需关系；此文是**行业主题档案**，不能把行业预测直接视作某家公司销量或收入。
- 关联公司：[亨通光电](../../company-research/600487.SH/README.md)；长飞光纤等公司的独立研究档案今后按需求另建。
- 数据状态：**已发布历史数据 / 公司引用机构预测 / 券商预测 / 研究推论分开列示**。

## 1. 必须先区分的四个量

1. **光纤/光缆需求**：实际采购或预计消耗的芯公里，须有区域、规格和渠道统计。
2. **实际出货量与实际产量**：不同公司/行业的成品出库及产线产出；全球光纤出货量不等于中国统计局“光缆产量”。
3. **名义产能与有效产能**：光棒吨数、拉丝芯公里、成缆芯公里是不同环节，受规格、良率、认证与稼动率影响，无法简单相加。
4. **缺口**：只对来源相同、地区相同、统计期间/产品口径一致的供给与需求作差。不同机构的缺口可能截然不同，不拼接计算。

截至本次归档，未找到可逐项核查、产品口径一致的2026年全年**实际产量**和2027—2030年**实际产量**（未来本就只能预测，不能叫实际）。历史讨论曾引用“2026年全球供给7.25亿、2027年8.07亿芯公里”和对应缺口，但本次未取得相同模型的完整原文供给表，因此**不把这些数放入确认的数据表**；行业观察清单保留待核验。

亨通半年报还转引“2026年全球光纤缺口约1.8亿芯公里”的机构估计，该口径与其他模型差异较大，且缺需求/供给完整对应表。**不可和华泰预测拼接、不可认定为全球唯一真实缺口。**

## 4. 2026—2030年供需演变：条件性分析

| 阶段 | 可支持的供需逻辑 | 关键分歧与风险 | 需要验证的事实 |
|---|---|---|---|
| 2026 | AI数据中心+运营商网络建设+部分其他应用共同提升需求；上游有效光棒、特种规格及认证限制短期供给 | 总需求与缺口不同研究机构差异较大 | 同口径全球实际出货和产量、各区域及规格报价 |
| 2027 | 有机构预计需求进一步增长；已有扩产项目逐步建设 | 需求若不及预期，价格中枢可能提前下行 | 新增项目实际产能爬坡、合同与成品价格 |
| 2028 | 光棒项目通常需要较长建设和工艺爬坡，供给可能逐步释放 | 高位扩产可能产生“周期顶部投资、下行期投产”风险 | 主要厂商有效光棒投产进度、普通与特种纤价格分化 |
| 2029—2030 | AI网络演进和地域投资可能持续；高端低损、多模、空芯/多芯需求路径不同 | 供需预测误差更大，高端规格也并非无价格风险 | 产能利用率、行业库存、存量替代与高端商用普及率 |

这张表是**研究判断，不是已核验的2030年供需或光纤价格预测**。

## 5. 哪些因素决定“涨价能持续多久”

- **需求组成**：AI数据中心内部高芯数布线、跨数据中心互联、运营商FTTH与400/800G骨干网、海外宽带和其他需求需要分开估算；不能认为全球增长全部由AI驱动。华泰专题还讨论了无人机及其他特殊用途，必须检查需求分项是否持续。
- **光棒有效供给**：公司可能宣布光棒吨数扩产，但高性能规格的纯度、良率、认证、拉丝匹配和爬坡周期决定真正可交货的量。
- **产品结构**：G.652.D普通纤、G.657抗弯、G.654长距、OM4/5多模以及空芯/多芯不具有可简单互换的单一“光纤价格”。
- **成缆与连接组件**：MPO项目为高密度光缆的成缆能力，FAU按“片”计量，两者不能视为新产生相应数量的独立裸纤。
- **供给反应**：在景气高位集中开建的项目，可能两年后开始投放；重点看真实达产而非项目宣布数量。

## 6. 关联到亨通的资本配置观察

[亨通定增预案](https://static.cninfo.com.cn/finalpage/2026-09-25/1225582516.PDF)中的800吨/年光棒、600万芯公里/年光纤、5,000万芯公里/年MPO高密度光缆、约6,300万片/年FAU是**不同环节的规划能力**。任何预测都必须先证明建设期、良率、出货和产品ASP；其中上游光棒和光纤的关系涉及内部配套，不能直接叠加为行业新增实际光纤数量。详情见[亨通产品与产能](../../company-research/600487.SH/02-products-and-capacity.md)。
