# 资讯投资相关性前置过滤方案（本地已实现）

> 历史 v4 方案；当前已切换为默认拒绝的白名单，见 [information-feed-whitelist.md](information-feed-whitelist.md)。以下“不确定时放行”规则不再适用。

本地运维：先运行 `npm run backfill:feed:relevance:dry-run` 查看数量与样例，再运行 `npm run backfill:feed:relevance`。每次 apply 会将原 `metadata_json` 归档到忽略提交的 `data/local/backups/`；新来源拒绝记录写入 `data/local/information-feed-relevance-rejected.jsonl`，按 10 MiB 滚动保留当前文件及上一份。规则调整必须递增 `config/information-feed-relevance.json` 的 `version` 并重跑 backfill；紧急回滚可关闭 `enabled`、重跑 backfill、重新构建/启动本地服务，不直接删除已提取记录。

## 目标与现状

目标：只有与投资决策有关的独有资讯进入“资讯”页面和模型提取；在 `requestLocalDirectLlmText` 之前拦截明确无关内容，减少调用，不以误删重大投资信息换取调用量。此处的“投资相关”与“能匹配现有 56 个提取类别”是两个不同判断；不能用模型的空记录或 `categoryCandidates` 反推相关性。

当前 `scripts/information-feed.mjs` 的链路为来源格式/48 小时校验、去重、存储、按时间选取待提取文档、调用本地模型。`normalizeFeedSource` 只检查来源、格式和文本，不判断投资相关性；本地 `/api/knowledge/feed` 仍可显示尚未提取的新闻。2026-09-27 对本地数据库的只读抽样：最近 48 小时约 340 篇，其中 129 篇待提取、203 篇已完成；已完成中 49 篇为 `no_information`。样本包含体育奖牌、熊猫出访、一般外交会见、无经济关联的灾害等，也包含油气设施停运、航运、货币政策和公司交易。`no_information` 不等于无投资价值，以上数量不作为可节省调用的估算。

## 相关性口径（建议默认）

1. **纳入：直接标的事件。** 上市公司或其他可投资发行人的业绩/预测、订单、经营、产品、产能、融资、并购、股权、治理、诉讼、监管、信用和重大资产事件。公司未能映射证券代码时仍可纳入。
2. **纳入：市场基本面事件。** 利率、财政、贸易和产业政策，具有具体变动的经济数据；大宗商品供需、能源/物流/供应链中断，或可明确影响行业供需的事件。无需原文点名股票，但必须有具体经济、资产或供需事实，不能仅凭模型猜想“可能影响股市”。
3. **排除：明确无关的日常社会信息。** 体育比赛结果、娱乐八卦、礼节性会见、普通治安/天气/事故、政治表态等，前提是全文没有上述投资信号。例如赛事名次直接排除；油气管道停运、霍尔木兹海峡通航变化不能按“国际新闻”排除。
4. **排除：低信号行情流水。** 无新事实支撑的盘中价格涨跌、成交额、资金流、技术面、重复背景及标题党；与现有提取原则一致。
5. **待定但默认放行：边界案例。** 单一弱信号、标题正文矛盾、长文中混有经济段落、未见过的行业事件和解析失败，先交给模型，不能用“没证券代码”“没公司名”“不在类别目录”直接拒绝。若用户更重视节省调用，可在独立验收后改为人工待审队列。

## 前置门禁契约与位置

新增一个无远程模型依赖、可单测的纯函数，例如 `evaluateInvestmentRelevance({title, body, sourceKey, contentType, entityCodes, kind, previousStoryRelevant})`，返回：

```text
{ decision: pass | reject | uncertain, effectiveDisposition: pass | reject,
  reasonCodes: string[], evidence: string[], policyVersion: string }
```

只在明确无关且无任何覆盖性投资信号时给 `reject`；`uncertain` 在第一阶段的 `effectiveDisposition` 为 `pass`。正向信号和否定/例外必须在标题与正文上共同检查，不能把来源栏目、证券代码或关键词命中当成充分条件。规则文件需版本化，使用可解释的 reason code，不依赖模型输出类别。异常时告警并放行，不将解析失败误判为无关。

执行顺序：`normalizeFeedSource` → 48 小时窗口 → 现有 exact/repeat/update 去重 → **对 new 正文或 update 独有段落做相关性判断** → 仅放行者 `prepareKnowledgeContent` / 写 `knowledge_docs` → `tagPending` → 模型提取。`repeat` 继续不调用模型。已相关 story 的后续修正/撤回默认放行，以免因 delta 很短而漏掉投资事实的变化；先前被拒绝的来源出现新版时重新评估全文，允许作为新 story 进入。不能把旧版拒绝结论永久套在相同 URL 上。

放行文章在现有 `metadata_json.feed.investmentGate` 中保存 `decision`、`effectiveDisposition`、`policyVersion`、输入哈希、原因和评估时间，作为 `tagPending`、API 与发布器的共同读取契约。被拒绝文章不写知识文档或正文内容，也不进入页面或远端发布；仅在本地审计文件记录来源身份、正文哈希、标题、时间、policyVersion、原因和判定，不含全文，并设置轮转/保留期。原始采集文件仍是回放来源。无需新数据库表。已写入的旧文档不能直接级联删除：先影子评估并标记/隐藏，保留已提取记录供抽检与回滚，再决定清理范围。

`tagPending` 在调用模型前必须再次验证当前门禁结果和内容哈希，拒绝者不能 `claimExtraction` 或占用每日额度；`feedInputFingerprint`/门禁判定与源正文变化各自独立失效。来源变更或门禁升级需要重新评估，但不应仅因门禁版本变化就强制重跑已有有效提取。页面列表、facets、实体记录检索和远端 `publicationEligible` 均只接受当前放行结果；本地可另设管理诊断入口看拒绝原因，不把拒绝项混成“待提取”。生产仍是 Worker 只读，`LLM_RUNTIME=production` 不得调用模型。

## 规则实施边界

- 第一版只实现**高精度硬排除**和明显投资信号的覆盖例外；不要维护一份“投资关键词白名单”作为准入条件。正向词可用于阻止硬排除，不能证明文章有投资价值。标题不足时检查正文；update 用独有段落并保留 story 上下文。
- 规则与现有受控类别分离。相关但无合适类别的文章仍可进入 `categoryCandidates`；类别目录是否补充宏观、能源供需、物流等由后续样本评估决定。
- 不接入另一轮远程 LLM 做“便宜的预判”。那仍消耗远程调用，并使预算、失败模式和生产边界更复杂；只有确定性门禁的节省率/漏判率验收不达标时，再单独评估本地小模型。
- 发布开关仍保持关闭；远端 D1/R2 迁移与真实 Worker API 验收独立于本地门禁上线。已有发布文档如被判拒绝，未来发布器须先撤销可见性，不能只阻止新增发布。

## 验收与上线

1. 对本地 2953 篇执行全量规则复核，抽查拒绝及不确定标题和正文，修复了“CPI 数据”“公司产品发布”“分析师评级”被纯行情规则误挡的问题；v4 又覆盖人道救援、艺术人物讣告、纯气象预警、无经济事实的军事动态和外交表态等误放行案例，并为经济性灾害、关税调整及工业设施受袭加回归样例。回填后 133 篇拒绝、1664 篇强信号放行、1156 篇不确定但放行，复跑 dry-run 零变化。**这不是经过人工标注的准确率，也不能推算实际模型节省比例。**
2. 上线到生产前仍需从两个来源按来源、时间、内容类型抽取至少 500 篇，人工双人标注“必留/可丢/争议”，保留标题和正文证据；重大公司事件、宏观政策、油气/航运冲击、非公司实体、综合长文、update/撤回和纯社会新闻须覆盖。先定义标注准则，再冻结样本，不能用模型空结果当真值。建议连续影子评估至少 7 天，重点复核全部高风险拒绝和随机拒绝样本，目标为必留召回率不低于 99%、重大事件零漏判、拒绝项确认精度不低于 99%。节省率仅按“本来会进入 `tagPending` 的独有文档”统计。
3. 单测覆盖体育/娱乐/礼节性外交的拒绝，油气停运、利率/关税、并购、公司灾害停产的放行，以及短 update、撤回、混合长文、无证券代码、来源改写、规则版本升级。集成测试用模型请求计数器断言 reject 零调用、零日额度消耗，pass/uncertain 不被误挡；页面/API/发布资格分别验证。
4. 先本地小流量开启，再处理存量未提取文档和页面默认列表；保留配置开关与版本化审计，以便立即回滚。不要自动删除历史成功提取或远端可见内容。通过本地 `./start-local.sh`、`/api/health`、`npm run test:feed`、`npm run test:smoke:pages` 后，生产另行验收。

## 需要确定的产品边界

建议把**宏观政策、量化经济数据、大宗商品供需及关键航运/供应链**纳入“投资相关”，即使没有对应上市公司；若实际只想看“直接关联证券/公司”的资讯，准入规则和漏判代价会显著不同，应在实施前明确。另需确认本地诊断入口是否允许查看被拒绝的标题和原因；默认不在普通“资讯”页展示。
