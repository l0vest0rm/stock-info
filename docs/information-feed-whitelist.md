# 资讯投资白名单（v7）

`config/information-feed-whitelist.json` 是人工维护的准入表，按 A 股、港股、美股、韩国重点上市公司、未上市明星企业、关键行业和宏观事项分组。命中名称本身不够：标题须命中明确主体或行业，标题与正文前 600 字还须有业务、供需、政策、财务或交易事实。纯行情报价和大盘收评优先排除。未命中默认拒绝，不再以“不确定”放行；因此资讯数量会减少，也可能漏掉未列入的有价值事件。

拒绝发生在本地内容入库和大模型提取之前。新拒绝项只追加到 `data/local/information-feed-relevance-rejected.jsonl`，包含标题、原文链接、来源、原因、规则版本及正文哈希，不保存全文或写入数据库。页面本地环境提供“已过滤（本地）”视图，可按标题、来源、原因筛选；生产 Worker 不提供该文件/API。历史已入库文档通过回填标记并从资讯/API/实体材料中隐藏，不做破坏性删除；回填时也将其标题和链接导出到本地审计文件。

调整名单或规则时同步升级 `config/information-feed-relevance.json` 的版本，再执行 `npm run backfill:feed:relevance:dry-run` 审核拒绝样本及 `npm run backfill:feed:relevance`。回填会先归档原元数据。审计文件不是标注真值；名单覆盖率、误放/误拒需持续人工 review，尤其检查未入白名单的新公司、新产品和重大宏观事件。生产发布仍关闭，生产不调用模型。

2026-09-27 本地存量复核：2954 篇中 1116 篇放行、1838 篇过滤；规则不再产生“不确定放行”。此为规则命中统计，不是人工标注的准确率或节省调用次数。
