## 目标与不可变边界

本架构服务 A 股、港股和美股的可追溯个股研究。它不生成自动交易动作，也不把价格、来源数量、模型输出或资料缺失转换成统一投资分数。

必须长期保持以下边界：

1. 经营公司与上市证券是不同对象；公司事实可以共享，价格、币种、股份类别、ADR 比例、权利和估值归具体证券。
2. 来源信息、确定性派生观察、研究分析和用户决定分别持久化，后层只引用前层，不能反向改写。
3. 信息预处理账本是来源候选与版本证据入口，不是可直接统计的预测数据库。
4. 来源预测、模型整理草稿、标准化结果、预测汇总、自建情景和实际校准分别存储。
5. 机会性收集的研报集合只能称为“已纳入样本的预测汇总”；`market_consensus` 默认且当前固定为 `false`。
6. 所有 LLM 调用都经过 `requestLlmText()`；只有 `LLM_RUNTIME=local` 可调用。生产路由不暴露写入或草稿生成能力，只读已物化结果。
7. 股票 K 线只使用 Xueqiu；A/H/美股财报目标来源分别为 Eastmoney、Eastmoney、Yahoo，不做跨来源自动回退。

## 领域与所有权

```text
knowledge document/version/information record
  └─ 来源预测候选（source-bound candidate）
       └─ 人工审核 + 口径标准化
            └─ source forecast（不可变版本）
                 ├─ consolidation snapshot（确定性派生观察）
                 ├─ local-LLM synthesis draft（无事实权威）
                 ├─ analyst scenario（自建假设）
                 └─ actual calibration（同口径实际校准）

filing-backed formal actual（追加事实、可重述）
  ├─ forecast/guidance calibration（同口径误差）
  └─ optional DCF observed-fact anchor（仅追加输入，不覆盖 analyst scenario）

operating company ──< listed security
       │                    │
       ├─ 公司财务/业务       └─ 行情/币种/股份权利/每股估值
       └─ 公司级预测
```

### 经营公司与上市证券

`research_operating_companies` 保存稳定经营主体；`research_listed_securities` 保存证券及经确认的公司映射。页面可以由证券代码进入，但公司映射未确认时：

- 证券行情仍可显示；
- 来源记录仍按原始 `target_code_normalized` 召回；
- 公司级共享研究、A/H/ADR 合并和跨证券比较必须保持不可用；
- 不自动按名称、ticker 或知识名称映射创建经营公司事实。

现有 `securities` 仍是搜索和行情代码目录，不承担法律主体、股份权利或跨上市关系。

### 信息预处理边界

来源链固定保存：

```text
information_id
  -> result_id
  -> version_id + content_hash
  -> doc_id
  -> source URL/content URL/source name/published_at
  -> processing run/model/prompt/input hash
```

现有 information record 只有 entity、information type、category、period 和 statement。它足以判断“这里存在一条来源预测候选”，不足以确认数字、机构、币种、单位或会计口径。因此数字进入汇总前必须经过独立审核。

## 预测账本

### 来源审核与不可变预测

`research_forecast_source_reviews` 保存候选记录当前的审核状态；`research_source_forecasts` 每次修改都新增一行，并用 `supersedes_forecast_id` 连接旧版本。原值和标准值同时保留。

纳入样本至少需要：

- 明确机构和预测日期；
- 指标与信息记录 category 一致；
- 明确财年；
- 金额或 EPS 有币种；
- 原始单位受支持；
- 会计、利润归属和每股口径显式记录，未说明时保存为 `unspecified`，不猜测。

`unspecified` 是待核验状态，不是可比口径：所有指标必须确认会计口径，净利润及其增速还必须确认利润归属，EPS 还必须确认基本/稀释口径；相关字段未确认时不得进入汇总。

确定性单位转换只处理受控比例：原币、万、百万、亿、十亿、百分比和原币/股。金额统一到“亿原币”，不自动换汇；不同币种继续分组。

### 去重与汇总

`forecast-consolidation.v4` 的顺序是：

1. 拒绝单位/币种不完整的样本；
2. 拒绝未绑定已确认来源身份和独立来源组的样本；自由文本机构名不能证明独立性；
3. 按指标、财年、币种、单位、会计口径、利润归属和每股口径分组；
4. 同一独立来源组同组只保留预测日期最新版本；转载、数据库镜像或别名不会因显示名称不同而重复计数；
5. 计算中位数、均值、最高、最低、样本数和总体标准差；
6. 冻结 header、group、included/excluded member、来源身份和独立来源组及原因。

来源身份是本地人工审核的不可变断言，带 HTTPS 审计证据、承载关系和独立来源组；它不从机构名称、URL 域名或模型推测。身份不明、未确认、转载/摘要/联合承载关系或旧快照均不能自动进入统计。历史 `forecast-consolidation.v2` 和未冻结身份断言的早期汇总必须重新审核并冻结 v4 快照，不能在页面上继续解释为独立来源样本。

### 模型整理草稿

本地端点 `/api/research/company/:code/forecast-synthesis-drafts` 只读取已审核来源预测和已冻结汇总，输出可比样本、分歧、来源观点和待核验项。草稿：

- 不创建新数字；
- 不生成自建情景；
- 不称市场一致预期；
- 每项引用 `forecastId`；
- 独立保存 model、prompt version、成员 ID 和 Markdown。

生产环境该端点返回 404，底层 LLM 客户端还有第二道硬拒绝。

### 自建情景与实际校准

`research_forecast_scenarios`、管理层指引、`research_formal_actuals` 和校准记录分别保存。本地页面可登记带 filing 证据的正式实际、重述和同口径校准，但不把业绩预告或快报当作正式实际，也不从来源汇总自动生成情景。

经营情景保存 DCF 时可以选择一个已保存的 `actualId`。服务端按账本读取该正式实际后，只有当前、可标准化、带 filing 证据、同证券/上一财年收入/同币种的记录才会作为 `observed_fact` 输入追加到不可变模型；它不能替换 `openingRevenue`、任何年度假设或估值日净债务。重述、不可比和缺失事实显式阻断锚定。

未来校准写入必须验证指标、期间、币种、单位、会计、归属和 EPS 口径；不可比时保留记录和原因，不计算误差百分比。

## API 与页面

### 当前已实现的可用垂直切片

`GET /api/research/company/:code/forecasts` 返回：

- 经营公司/上市证券映射状态和阻断缺口；
- 来源预测候选及 document/version/record 证据链；
- 已审核的不可变来源预测；
- 最新不可变汇总快照、分组统计和成员原因；
- 本地模型整理草稿；
- 独立情景和实际校准状态；
- 本地写入/LLM 能力标志。

`POST /api/research/company/:code/forecast-reviews` 仅在本地研究运行时开放，保存审核、不可变样本并立即冻结新汇总快照。

公司研究页还包括：字段化行业/同行、经营分部/合同/单位经济/市场空间、情景正向 DCF、反向 DCF、风险压力/关系/命题关联、催化剂复盘和公共快照历史。所有写入仅在 `LLM_RUNTIME=local` 时开放；生产页面只读；没有数据时显示“待补/不可用”，不以零或中性分替代。

### 兼容边界

旧 `/api/report/forecast`、逐篇 `app_kv` 预测缓存和知识页 `recommended` 字段继续服务现有页面，当前不作为新预测账本的来源事实或权威汇总。后续迁移必须先迁移 consumers，再废弃旧契约，不能直接改返回形状。

现有 company research 的行情/态势/风险区域暂作为市场观察旁路保留；它的分数和顶层状态不进入新的预测、估值或用户决定账本。

公司研究页不再把所有模块同时展开为一组“待录入”卡片，也不再提供通用 JSON 编辑器。页面现在有五个研究层：研究总览、基础事实、预测与估值、竞争/风险/复盘、个人研究。每个公开模块都在自己的层中展示其来源、认识边界、可得性和阻断原因；本地运行时使用领域字段录入新的版本化记录，生产环境保持只读且不会调用 LLM。

本轮新增的交互并不扩大数据来源权限：股票 K 线仍只允许 Xueqiu，三地财务遵守既定主源与法定复核，LLM 仍只能由 `LLM_RUNTIME=local` 调用。
