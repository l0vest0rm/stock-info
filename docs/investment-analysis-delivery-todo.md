## 领域依赖

```text
Research subject mapping + factual data requirement
  -> source facts / source forecasts / derived observations
  -> track profile + company focus profile + operating scenarios
  -> valuation scenario + risk register + research thesis
  -> dated investment analysis snapshot
  -> user-owned decision reference
```
