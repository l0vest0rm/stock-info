# A股、港股、美股统一个股投资分析框架

> 状态：需求与功能讨论稿，不涉及代码、接口和实现方案
> 版本：0.8
> 日期：2026-08-04
> 用途：明确 `stock-info` 面向 A股、港股、美股的个股投资分析需要解决什么问题、包含哪些功能，以及通用分析、市场差异、行业/赛道和重要公司侧重内容如何组合。本文不构成任何公司的实时投资结论或交易建议。

## 1. 产品定位

这套能力不是“输入股票代码后给一个买卖答案”，而是一套可持续更新、可追溯、可比较、可证伪的公司投资研究工具。

它要帮助用户回答五个问题：

1. 这家公司如何赚钱，长期价值由什么驱动；
2. 它所在行业或赛道的需求、供给、竞争和周期如何传导到公司；
3. 公司相对同行有什么优势、弱点和独有风险；
4. 当前上市证券的价格已经隐含了什么增长和风险预期；
5. 哪些新信息会加强、削弱或推翻原有判断。

核心原则是：

> 好行业、好公司、好证券和好价格是四个不同问题。

行业重要不代表公司一定获利，公司优秀不代表所有上市证券价格都合适，同一家公司的 A股、H股或 ADR 也可能因为股东权利、币种、流动性和估值不同而具有不同的风险收益。

## 2. 研究对象与范围

### 2.1 覆盖范围

- A股上市公司及其人民币普通股；
- 港股上市公司，包括 H股、红筹、民营企业和其他香港上市主体；
- 美股上市公司，包括美国本土公司和外国发行人的 ADR；
- 已盈利、周期、金融、稳定分红、资产型、未盈利成长和多元控股公司；
- 同一经营主体在多个市场上市的情形。

### 2.2 当前不纳入统一个股框架

- ETF、公募基金、私募基金；
- 债券、可转债、期权和其他衍生品；
- 纯技术分析、日内交易和盘口策略；
- 自动下单、自动仓位或无条件买卖建议；
- 将指数、行业或宏观研究直接等同于个股结论。

这些对象未来可以与个股研究关联，但不能混用同一估值和风险模型。

## 3. 首先区分经营公司与上市证券

跨市场分析的第一原则，是把“公司”与“股票”拆开。

### 3.1 经营公司

经营公司层回答：

- 业务、产品、客户和地区结构；
- 行业地位、竞争优势和管理层；
- 财务、现金流、资本配置和长期风险；
- 未来经营情景和企业整体价值。

这些内容原则上可以被同一公司在不同市场的上市证券共用。

### 3.2 上市证券

上市证券层回答：

- 具体代码、交易市场、币种和计价单位；
- 普通股、H股、ADR 或不同投票权类别；
- ADR 换算比例、总股本、稀释后股本和对应市值；
- 股东权利、分红税务、流动性、交易时间和市场制度；
- A/H 溢价、ADR 折溢价、可转换性和资金可达性；
- 该证券自身的价格、估值和预期收益。

### 3.3 多地上市的处理规则

```text
一套经营公司分析
  + 每个上市证券各自的市场与证券分析
  = 对该证券的完整投资分析
```

例如同一银行的 A股和 H股可以共用资产质量、净息差和资本充足分析，但必须分别计算币种、股本、市值、股息率、估值和流动性，不能把一个市场的价格直接套到另一个市场。

## 4. 完整框架的组成

建议采用四层分析，加一个跨层的估值原型：

```text
通用公司分析层
  + 市场与上市结构层
  + 行业/赛道层
  + 重要公司侧重层（可选）
  + 与商业模式匹配的估值原型
```

### 4.1 通用公司分析层

所有公司都必须回答的基本问题，用于保证完整性和可比较性。

### 4.2 市场与上市结构层

处理 A股、港股、美股在会计、披露、币种、股权、交易和监管上的差异。它是跨市场框架必需的校准层，而不是行业分析的一部分。

### 4.3 行业/赛道层

处理行业特有的需求方程、供给约束、专属 KPI、周期和估值习惯。例如银行必须看资产质量，光通信必须看端口速率和产品迭代。

### 4.4 重要公司侧重层

只有对用户重点研究的公司才增加，处理该公司独有的产品、客户、管理层、事件、经营变量和证伪条件。它不能取代通用层，也不能为了得出想要的结论而改变公共规则。

### 4.5 估值原型

估值方法按主要盈利和现金流机制选择，而不是仅按市场或行业名称选择。成长、周期、银行、稳定分红、资产、未盈利和多元控股公司需要不同的主估值方法。

## 5. 所有层都必须遵守的规则

1. **分析对象唯一**：明确经营公司和所分析的上市证券，不混淆母子公司、A/H股、ADR 或不同股份类别。
2. **数据时点一致**：每次分析都有数据截止日、最新财报期和预测期间。
3. **币种与单位一致**：原币展示为主；跨市场比较必须说明汇率日期、股本口径和是否经过换算。
4. **认识类型分离**：事实、管理层指引、第三方预测、来源观点、分析假设、系统判断和个人决定分别展示。
5. **缺失不能变中性**：没有数据就是“待补”，口径冲突就是“冲突”，不能自动填零或计算平均分。
6. **主营决定行业模板**：主营一级/二级赛道选择默认行业分析；主题标签只能增加待验证暴露，不能改变主营归类。
7. **结论必须可证伪**：核心判断必须有支持证据、反证条件和下一次复核时间。
8. **估值必须看到路径**：不能只显示一个 PE、PEG、目标价或历史分位。
9. **价格不证明价值**：上涨、下跌、回撤和资金行为不能单独证明基本面好坏。
10. **研究不等于交易**：公司研究状态、证券估值状态和用户买卖决定是三个不同对象。

## 6. 信息与判断的边界

页面必须让用户看出一段内容属于哪一类：

| 类型 | 定义 | 例子 |
| --- | --- | --- |
| 已观察事实 | 已发生且有时间、口径和来源的数据或披露 | 某季度收入、公告的回购数量 |
| 管理层指引 | 公司对未来经营的正式表述 | 下一财年资本开支区间 |
| 第三方预测 | 券商或行业机构对未来的预测 | 2027 年利润预测 |
| 来源观点 | 某来源对原因、趋势或价值的解释 | 行业机构认为库存周期将改善 |
| 分析假设 | 为情景推演主动设置的输入 | 产品份额、毛利率、退出倍数 |
| 系统判断 | 基于证据和假设得出的可复核结论 | 基准情景可兑现但当前价格已计入较高增长 |
| 用户决定 | 用户结合资金和组合做出的行动 | 观察、计划建仓、暂不交易 |

来源数量多不等于结论必然正确。多家机构给出相同盈利预测，仍然只是多份预测，不会自动变成事实。

## 7. 通用公司分析层

通用层适用于绝大多数 A股、港股和美股公司。每个维度都需要显示结论、证据、缺口、风险和下一步，而不是只给分数。

| 维度 | 必须回答的问题 | 主要内容 |
| --- | --- | --- |
| 公司身份与边界 | 实际经营主体是谁，上市证券代表什么权益？ | 控股结构、主要子公司、股份类别、少数股东 |
| 商业模式 | 公司向谁提供什么，怎样收费和确认收入？ | 产品、客户、合同、渠道、分部和收入确认 |
| 收入与利润驱动 | 增长来自量、价、份额、结构、产能还是并购？ | 经营驱动方程、增长持续时间、约束条件 |
| 行业需求与周期 | 最终需求来自哪里，当前处于什么阶段？ | 渗透率、库存、资本开支、价格、政策和周期 |
| 市场空间与份额 | 行业空间中哪些可由公司服务和获得？ | TAM、SAM、SOM、份额桥、行业利润池和上下校验 |
| 竞争与护城河 | 为什么公司能保住份额和回报？ | 成本、品牌、网络效应、认证、技术、渠道、监管牌照 |
| 财务表现 | 历史增长、盈利和回报如何？ | 收入、毛利、营业利润、净利润、ROE、ROIC |
| 盈利质量 | 利润是否可持续并转成现金？ | 扣非、经营现金流、自由现金流、应收、存货、一次性项目 |
| 资产负债表 | 公司能否承受逆风和继续投资？ | 净现金、负债期限、利息、商誉、或有负债、融资需求 |
| 管理层与治理 | 决策者是否可靠并与股东利益一致？ | 控制权、激励、关联交易、承诺兑现、审计和信息披露 |
| 资本配置 | 留存利润和外部融资创造了什么回报？ | 研发、资本开支、并购、回购、分红、稀释和再投资回报 |
| 预测与情景 | 不同经营假设产生什么结果？ | 悲观、基准、乐观的收入、利润、现金流和资产负债变化 |
| 估值与预期 | 当前价格隐含了什么，安全边际在哪里？ | 主估值、辅助估值、反向估值、敏感性和预期收益 |
| 催化剂 | 哪些事件会改变盈利或市场预期？ | 财报、产品、价格、政策、订单、产能、回购和资本动作 |
| 风险与证伪 | 什么可能造成永久损失或推翻命题？ | 需求、份额、成本、杠杆、治理、监管、地缘和技术替代 |
| 市场状态 | 当前证券的市场行为如何？ | 收益、回撤、波动、流动性和估值历史位置，仅作辅助 |

### 7.1 通用财务分析

财务分析不是把报表数据重新排列，而是回答：增长是否真实、利润是否可持续、现金是否能收回、资产负债表是否安全、增量资本是否创造价值，以及这些价值是否真正归属于每股股东。

默认观察最近五个完整财年和最近十二个季度；资料不足时至少覆盖三个完整财年。季度比较同时展示同比、环比和滚动十二个月，并标记季节性、并购、处置、会计政策和币种变化。

#### 7.1.1 通用关键财务指标

| 维度 | 核心指标 | 主要用途 | 需要警惕 |
| --- | --- | --- | --- |
| 规模与增长 | 收入、毛利、营业利润、归母净利润、扣非/调整后利润、稀释 EPS 的同比、环比和 CAGR | 判断增长来自业务规模还是会计项目 | 低基数、并表、汇率、一次性收益、利润增长但每股不增长 |
| 盈利能力 | 毛利率、营业利润率、净利率、分部利润率 | 判断定价权、产品结构和经营杠杆 | 降价换份额、费用资本化、产品结构恶化 |
| 费用结构 | 销售、管理、研发费用率，SBC/收入 | 判断增长投入、规模效应和真实用人成本 | 通过削减必要投入抬高短期利润，或排除大量 SBC |
| 现金质量 | 经营现金流、自由现金流、经营现金流/净利润、自由现金流率 | 判断利润能否转成可支配现金 | 现金流长期落后利润、依赖预收或延长付款 |
| 营运资本 | 应收、合同资产、存货、预付、应付；DSO、DIO、DPO、现金转换周期 | 判断回款、库存、渠道和供应链压力 | 应收/存货长期快于收入，坏账或减值上升 |
| 资产负债 | 现金、总债务、净债务、流动比率、速动比率、净债务/EBITDA、利息覆盖 | 判断偿债、融资和逆风承受力 | 短债长投、利息资本化、表外承诺、再融资依赖 |
| 资本效率 | ROE、ROA、ROIC、增量 ROIC、资产周转率 | 判断存量和新增资本是否创造价值 | 高 ROE 主要来自高杠杆、低权益或周期高点 |
| 资本开支 | 资本开支/收入、资本开支/折旧、维护性与扩张性资本开支 | 判断增长所需投入和自由现金流可持续性 | 把扩产当作需求，将必要资本开支排除在 FCF 外 |
| 股东回报 | 分红率、股息覆盖、回购收益率、净回购收益率、股东收益率 | 判断现金是否真实回到股东 | 一边回购一边通过 SBC/增发扩大股本 |
| 每股价值 | 稀释 EPS、每股自由现金流、每股净资产、稀释后股数变化 | 判断公司增长是否转为每股增长 | 总利润增长但稀释后每股价值停滞 |
| 会计质量 | 非经常性损益、投资收益、公允价值变动、补助、减值、资本化支出 | 区分持续经营与一次性项目 | 经常出现的“非经常”、减值延后、调整口径频繁改变 |

这些指标没有一套适用于所有行业的固定阈值。判断必须同时参考公司历史、同口径同行、商业模式、周期阶段和管理层指引。

每个派生指标必须保留指标定义、分子、分母、期间、币种、是否年化、是否使用平均余额、原始报表口径和调整项。同名 ROE、自由现金流或调整后利润口径不一致时，先显示差异，不能直接排名。

#### 7.1.2 增长与利润路径

增长分析应形成下面的利润桥：

```text
收入增长
  × 毛利率变化
  - 销售/管理/研发投入变化
  = 营业利润变化
  ± 利息、投资收益、公允价值、汇率和一次性项目
  - 税费及少数股东损益
  = 归母净利润变化
  ÷ 稀释后股本
  = 稀释每股收益变化
```

至少需要回答：

- 收入增长来自销量、价格、份额、产品结构、并购还是汇率；
- 毛利率变化来自定价、原料、产品结构、良率还是产能利用；
- 营业利润增长是否依赖费用率下降，下降是否可持续；
- 归母利润是否受少数股东、税率、利息或非经营项目影响；
- 总利润增长是否被增发、可转债、期权或 SBC 稀释。

单季同比、环比和滚动十二个月应并列观察。低基数、季节性和并购口径没有处理时，不输出“增长加速”结论。

#### 7.1.3 盈利能力与经营杠杆

毛利率、营业利润率和净利率必须分别解释：

- 毛利率主要反映售价、产品结构、直接成本、良率和供应链；
- 营业利润率还包含销售、管理和研发投入，适合观察规模效应；
- 净利率还受资本结构、税率、投资收益和一次性项目影响，不能单独代表主营竞争力；
- 分部利润率比公司综合利润率更适合分析多业务公司；
- 固定成本较高的公司需要同时展示产能利用率和经营杠杆的正反两面。

利润率提高并不自动等于质量改善。如果来自削减研发、少计减值、费用资本化或短期供给紧张，应降低持续性判断。

#### 7.1.4 盈利质量与现金流

通用非金融公司至少计算：

```text
自由现金流 = 经营现金流 - 资本开支
经营现金转换率 = 经营现金流 ÷ 归母净利润
自由现金流率 = 自由现金流 ÷ 收入
```

使用要求：

- 负利润、极小利润或强季节性期间，现金转换率显示“不适用”，不计算异常百分比；
- 优先看三至五年累计现金转换，而不是单一季度；
- 能区分时，分别展示维护性和扩张性资本开支；不能可靠区分时使用总资本开支并说明；
- 预收款改善现金流需要检查履约义务，延长应付改善现金流需要检查供应商压力；
- SBC 较高的公司需要把自由现金流与 SBC、净稀释和每股自由现金流并列展示，不能把未扣除股权激励经济成本的现金流直接称为股东可得收益；
- 银行、保险等金融机构不使用通用自由现金流公式。

利润明显高于经营现金流时，应追踪应收、合同资产、存货、资本化研发、供应链融资和收入确认；现金流高于利润时，也要判断是经营改善、预收增加，还是一次性营运资本释放。

#### 7.1.5 营运资本与现金转换周期

对适用的非金融公司计算：

```text
应收周转天数 DSO = 平均应收相关余额 ÷ 收入 × 期间天数
存货周转天数 DIO = 平均存货 ÷ 营业成本 × 期间天数
应付周转天数 DPO = 平均应付相关余额 ÷ 营业成本 × 期间天数
现金转换周期 CCC = DSO + DIO - DPO
```

页面要同时显示绝对金额、占收入比例和周转天数，避免只看一个比率。重点检查：

- 应收增长是否持续快于收入，账龄和坏账准备是否恶化；
- 合同资产是否反映未验收或回款条件变化；
- 存货增长来自备货、扩产、产品迭代还是滞销；
- 应付增加来自采购增长还是延迟付款；
- 现金转换周期变化是季节性、议价能力还是风险信号。

周转指标必须使用平均资产负债表余额并保持分子分母口径一致。银行、保险、部分平台和地产公司应使用各自行业指标，不强行套用 CCC。

#### 7.1.6 资产负债表与偿债能力

非金融公司重点观察：

- 现金及等价物、受限现金、总债务和净债务；
- 短期债务占比、债务到期分布、固定/浮动利率和币种错配；
- 流动比率、速动比率、净债务/EBITDA、EBIT/利息费用；
- 租赁负债、担保、诉讼、回购承诺和其他表外义务；
- 商誉、无形资产、资本化研发和潜在减值；
- 再融资、可转债、优先股、增发和潜在稀释。

当 EBITDA 为负、接近零或受周期高点扭曲时，净债务/EBITDA 显示“不适用”；金融机构使用监管资本、流动性和资产质量指标，不使用这一比率替代。

#### 7.1.7 资本效率与杜邦拆解

通用非金融公司使用：

```text
ROE = 归母净利润 ÷ 平均归母权益
ROA = 净利润 ÷ 平均总资产
ROIC = 税后经营利润 NOPAT ÷ 平均投入资本
增量 ROIC = NOPAT 增量 ÷ 投入资本增量
```

所有分母优先使用期初期末平均值，并记录 NOPAT、投入资本、现金扣除和租赁负债的具体口径。分母为负、接近零或受重大并购影响时，不输出正常百分比。

ROE 应通过杜邦关系解释：

```text
ROE ≈ 净利率 × 资产周转率 × 权益乘数
```

这样可以区分高 ROE 来自高利润率、高周转还是高杠杆。投资分析更关注 ROIC 是否长期高于资本成本，以及新增投入是否仍能获得类似回报；仅有历史高 ROE 不能证明未来增长创造价值。

#### 7.1.8 资本配置与每股价值

资本配置分析需要把留存利润的去向全部解释：

- 维护性资本开支；
- 扩张性资本开支；
- 研发投入；
- 并购和少数股权投资；
- 偿债和增加现金储备；
- 分红；
- 回购；
- 股权激励、增发和其他稀释。

除总收入和总利润外，必须展示稀释后每股收益、每股自由现金流和稀释后股数。回购评价使用**净回购**：实际回购减少的股份需要扣除 SBC、期权行权和新增发行造成的稀释。

```text
股东收益率 = 股息率 + 净回购收益率
```

高股东收益率仍需检查债务、资本开支和分红覆盖，不能通过借债分红或高价回购制造表面回报。

#### 7.1.9 A股、港股和美股财务口径

| 市场 | 必须并列展示或调整的内容 |
| --- | --- |
| A股 | 归母净利润与扣非归母净利润；政府补助、投资收益、公允价值、资产处置；研发资本化；股本变化和限售/再融资影响 |
| 港股 | 报告利润与调整后利润的桥接；持续/终止经营；投资物业、金融资产等公允价值；配股、供股和股份奖励造成的稀释 |
| 美股 | GAAP 与 non-GAAP 的完整桥接；SBC、重组、无形资产摊销；基本/稀释股数；回购与净稀释；租赁负债 |
| ADR | 经营主体报表币种、交易币种、ADS 比例、每 ADS 指标、存托费用及股份转换影响 |

跨市场比较以报告口径为起点；任何调整都要保留原值、调整项和调整后结果。不能只采用管理层最有利的调整后利润。

#### 7.1.10 按商业模式加载专属财务指标

| 公司类型 | 通用指标之外必须增加 | 不适用或需谨慎使用 |
| --- | --- | --- |
| 银行 | 净息差、存贷款增速、存款成本、不良/关注率、拨备覆盖、信用成本、核心一级资本充足率、ROE、分红覆盖 | 通用 FCF、净债务/EBITDA、CCC |
| 保险 | 保费、承保综合成本率、新业务价值、内含价值、合同服务边际、投资收益、偿付能力 | 普通制造业毛利率、通用 FCF |
| 证券 | 经纪/投行/资管/自营结构、正常化 ROE、净资本、杠杆和风险资产 | 单年投资收益外推、普通企业净债务 |
| 周期/资源 | 产量、售价、单位现金成本、EBITDA、维持资本开支、净债务/EBITDA、中周期利润 | 峰值 ROE、峰值 PE、单年利润 CAGR |
| 软件/SaaS | ARR、净收入留存、递延收入/RPO、毛利率、销售效率、SBC/收入、FCF 率 | 只看调整后利润或忽略稀释 |
| 平台/互联网 | 活跃用户、交易额、变现率、获客与留存、分部利润、SBC、云/AI资本开支 | 用 GMV 代替收入，用收入代替平台利润池 |
| 重资产/公用事业 | 利用率、维护/扩张资本开支、折旧、ROIC、净债务、利息覆盖、项目回报 | 不扣资本开支的经营现金流估值 |
| 未盈利/创新药 | 现金消耗、现金跑道、研发投入、里程碑付款、潜在稀释、成功概率 | PE、利润现金转换率 |

行业档案可以继续增加指标，但不能删除数据截止、口径、缺失和会计质量检查。缺少同定义数据时应显示“不可用”，不能用另一行业指标自动替代。

#### 7.1.11 财务异常与证伪信号

以下情况至少进入重点复核：

- 收入增长，但应收、合同资产或存货连续更快增长；
- 净利润增长，但经营现金流和自由现金流长期不匹配；
- 毛利率或利润率突然改善，却无法由价格、成本、结构或利用率解释；
- 扣非/GAAP 利润与调整后利润差异持续扩大；
- 反复依赖投资收益、公允价值、补助、处置或减值转回；
- 资本开支持续高于折旧，却没有形成收入、利润或 ROIC 改善；
- 并购后商誉、无形资产和债务上升，协同效应未兑现；
- 回购金额很大，但稀释后股数没有下降；
- ROE 提高主要来自权益下降或杠杆上升；
- 短期债务、利息或表外承诺上升，而现金和经营现金流不足；
- 频繁改变调整后指标定义、分部口径或关键 KPI；
- 审计意见、内部控制、关联交易或管理层诚信出现异常。

异常信号是复核入口，不自动等同于财务造假或投资结论。页面需要给出对应报表、期间、原因假设和后续验证项。

#### 7.1.12 财务分析输出

财务模块不输出单一总分，至少分开给出：

1. 增长质量；
2. 盈利能力与持续性；
3. 现金转换质量；
4. 营运资本健康；
5. 资产负债表安全；
6. 资本效率；
7. 资本配置与每股价值；
8. 会计口径与数据可信度。

每项显示趋势、同业/历史比较、证据、异常、适用性和数据缺口。任何一项“不可用”都不能被其他高分抵消。

研究摘要只选取与该公司商业模式最相关的 8—12 个关键指标，详细财务区再展示完整指标。普通非金融公司通常优先显示收入增长、毛利率、营业利润率、稀释 EPS 增长、经营现金转换率、自由现金流率、净现金/净债务、ROIC 和稀释后股数变化；银行、保险、周期和未盈利公司用各自专属指标替换不适用项。

### 7.2 通用三情景分析

悲观、基准、乐观情景必须从底层经营变量出发：

```text
销量/用户/价格/份额/利用率/信用成本等
  → 收入
  → 毛利和营业利润
  → 净利润
  → 经营现金流和自由现金流
  → 资产负债表
  → 估值
```

不能只把最终利润机械调整正负 10%。每个情景都要显示假设来源、敏感变量和失效条件。

### 7.3 市场空间与公司可获得空间

市场空间分析是连接“行业很好”和“公司能赚多少钱”的核心环节。完整链条应为：

```text
终端需求
  → 总市场空间（TAM）
  → 公司可服务市场（SAM）
  → 公司可获得份额
  → 公司可获得市场（SOM）
  → 实际确认收入
  → 毛利、经营利润和自由现金流
```

这些环节不能互相替代。终端市场规模不是供应商收入，行业收入也不是目标公司的可服务市场，高市场份额更不等于高利润或高股东回报。

#### 7.3.1 四个核心概念

| 概念 | 回答的问题 | 必须明确 |
| --- | --- | --- |
| 总市场空间 TAM | 在给定产品、地区、客户和期间内，全部合格需求有多大？ | 数量/金额、年度/存量、地区、币种、含税与否、来源日期 |
| 可服务市场 SAM | 其中哪些需求是公司当前或规划产品真正能参与的？ | 产品适配、地区许可、客户认证、渠道、交付能力和时间 |
| 可获得份额 | 公司在可服务市场中合理能拿到多少？ | 当前份额、竞争、客户上限、产能、良率、价格和获取时间 |
| 可获得市场 SOM | 在一个具体情景下，公司可获得的收入机会有多大？ | `SAM × 可获得份额`，并与产能和客户采购自下而上校验 |

页面还应单独展示**行业利润池**：行业收入乘以可持续利润率后，有多少利润可以由参与者分享。某些行业市场规模很大但利润池很薄；有些公司收入份额不高，却因产品结构或成本优势获得更高利润份额。

#### 7.3.2 先固定市场口径

任何市场空间数字都必须附带：

- 产品或服务边界；
- 地区和客户范围；
- 基准年、预测年和预测期限；
- 销量、装机量、用户数、交易额还是收入金额；
- 当年新增量、年度消费量还是累计存量；
- 终端售价、厂商出货价、平台交易额还是供应商可确认收入；
- 名义金额还是固定价格，原币还是换算币种；
- 是否包含相邻产品、售后、软件、配件或重复环节；
- 数据来源、发布日期及其预测还是实际值属性。

如果两份研报给出不同市场规模，应先检查边界、年份、价格口径和价值链层级，而不是直接取平均。

#### 7.3.3 按商业模式选择测算方程

| 商业模式 | 市场空间常用方程 | 公司收入的主要约束 |
| --- | --- | --- |
| 标准化产品 | 终端数量 × 渗透率 × 单机用量 × ASP | 产品适配、渠道、份额、产能、良率 |
| 设备/项目 | 客户资本开支 × 设备占比，或项目数 × 单项目价值 | 招标、认证、订单、交付和验收 |
| 软件订阅 | 潜在客户数 × 付费率 × 客单价，或席位数 × 单席价格 | 获客、留存、扩张率、销售效率 |
| 平台/交易 | 活跃用户 × 使用频率 × 单次金额 × 变现率 | 网络效应、抽佣率、补贴、监管和竞争 |
| 资源/周期 | 可售产量 × 利用率 × 产品价格 | 资源、产能、成本曲线、库存和周期价格 |
| 银行/金融 | 可服务资产或交易规模 × 份额 × 利差/费率 | 资本、负债、风险偏好、信用成本和监管 |
| 医药/里程碑 | 患者数 × 渗透率 × 疗程价格 × 成功概率 | 临床、审批、支付、竞争和专利期限 |

同一公司有多个重要业务时，应按分部使用不同方程，再扣除内部交易和总部成本，不能用一个宏观市场增长率覆盖全部收入。

#### 7.3.4 常用测算方法与上下校验

研报常见的市场空间测算方法各自回答不同问题，应尽量交叉使用：

| 方法 | 计算起点 | 适合回答 | 主要局限 |
| --- | --- | --- | --- |
| 终端需求法 | 用户、设备、患者、门店或项目数量 | 最终需求天花板 | 容易漏掉价值链比例和公司可达性 |
| 单位价值量法 | 终端数量 × 单机/单项目产品数量 × 单价 | 某个零部件或环节的市场收入 | 技术路线、配置和 ASP 会变化 |
| 客户预算法 | 主要客户资本开支或采购额 × 品类占比 | 集中型 B2B 市场的近期需求 | 客户口径可能不完整，预算不等于收入 |
| 供应商汇总法 | 主要参与者相关收入或出货加总 | 当前实际市场及竞争格局 | 私营公司、分部披露和内部交易可能缺失 |
| 供给能力法 | 行业产能 × 利用率 × 良率 × 价格 | 供给上限和短期可交付空间 | 产能不等于需求，名义产能可能失真 |

任何单一方法都不应直接成为结论。终端需求法适合估计长期空间，客户预算和供应商汇总更适合近期验证，供给能力法用于检查模型是否超过实际交付上限。

**自上而下**从终端需求开始：

```text
终端需求量
  × 产品渗透率
  × 单位需求对应的产品数量或价值量
  × 适用地区/客户比例
  = 可服务市场
```

**自下而上**从公司实际能力开始：

```text
客户数量或产能
  × 客户平均采购/产能利用率
  × 良率或交付率
  × 公司 ASP
  = 公司可实现收入
```

两者差异本身就是重要结果：

- 自上而下显著高于自下而上，通常说明产能、认证、渠道或资本约束没有进入模型；
- 自下而上高于行业空间，通常说明市场边界、价值量或收入统计发生重复；
- 两者接近但利润差异很大，需要检查价格、产品结构、毛利率和资本开支。

#### 7.3.5 公司可获得份额的测算

公司份额不能只写“龙头有望获得 10%”。至少需要以下证据链：

1. **当前份额基线**：同一产品、地区、客户和期间下的公司收入或出货占比；
2. **份额变化来源**：新客户、客户内部份额提升、新产品替代、产能释放、竞争对手退出或并购；
3. **客户采购上限**：客户多供应商策略、单一供应商集中限制和采购周期；
4. **供给约束**：产能、良率、关键零部件、交付和售后能力；
5. **竞争反应**：同行扩产、降价、产品升级和客户认证；
6. **经济性约束**：为了获取份额是否需要牺牲价格、毛利、账期或资本回报；
7. **时间路径**：份额何时从当前水平变化到情景水平，而不是只给远期终点。

首先要说明“份额”具体指什么：

| 份额类型 | 分子 | 分母 | 主要用途 |
| --- | --- | --- | --- |
| 收入份额 | 公司同口径收入 | 行业同口径收入 | 估计收入地位和定价结果 |
| 出货份额 | 公司销量/出货 | 行业销量/出货 | 排除不同价格和产品结构影响 |
| 客户钱包份额 | 公司对某客户销售 | 该客户同品类总采购 | 判断客户内部位置和集中风险 |
| 新增市场份额 | 公司新增出货/订单 | 行业当期新增需求 | 判断边际竞争力和份额变化 |
| 利润池份额 | 公司可比经营利润 | 行业可比经营利润 | 判断公司获得多少行业经济价值 |
| 产能份额 | 公司有效产能 | 行业有效产能 | 只用于供给能力校验，不等于销售份额 |

不同份额不能混用。高端产品公司的收入份额可能高于出货份额；价格战中的出货份额上升也可能伴随利润池份额下降。

份额应优先使用同口径的收入或出货数据。用产能、客户名单、招标排名或“核心供应商”推断时，必须标为代理指标，不能显示成已确认市场份额。

可用下面的份额桥解释变化：

```text
期初份额
  + 新客户/新产品获得
  + 原客户内部份额提升
  - 客户流失/产品淘汰
  - 产能、良率或供应限制
  = 期末可获得份额
```

#### 7.3.6 从收入空间走到利润和现金流

公司投资价值不能止于 SOM：

```text
公司可获得收入
  × 可持续毛利率
  - 销售、研发和管理投入
  - 税费
  = 经营利润和净利润

经营利润
  - 营运资本增加
  - 维持与扩张资本开支
  = 自由现金流
```

需要重点检查：

- 获取份额是否依赖降价；
- 新市场是否具有更低毛利或更长账期；
- 产能扩张是否在需求兑现前消耗大量现金；
- 市场空间是否已经被客户议价或上游成本重新分配；
- 公司获得的是收入份额、利润份额还是仅有名义订单。

#### 7.3.7 增长来源分解

公司收入增长应尽量拆为：

```text
行业市场增长
  + 公司份额变化
  + 产品结构/ASP变化
  + 并购影响
  + 汇率影响
```

其中行业增长和份额提升具有不同风险：前者依赖需求周期，后者依赖竞争优势；ASP 上升可能来自产品升级，也可能只是短期供给紧张；并购和汇率不应被误认为内生增长。

#### 7.3.8 证据强度与常见错误

市场空间和份额的每个输入应标为：

- 公司或监管正式披露；
- 客户/供应商交叉验证；
- 可信行业统计；
- 第三方预测；
- 代理指标推算；
- 分析假设。

常见错误包括：

- 用终端产业规模直接作为零部件公司的 TAM；
- 把累计装机量当作每年新增市场；
- 同时计算整机和其中零部件造成重复；
- 将全球 TAM 直接分配给只能服务部分地区或客户的公司；
- 把产能等同于销量，把订单等同于收入；
- 用公司总收入除以只覆盖某产品的行业规模；
- 假设份额提升但不考虑竞争对手、客户多供和降价；
- 用市场规模增长直接推导利润同比增长；
- 只给市场规模终值，不给年度路径和预测误差；
- 引用多份同源研报，把重复预测误认为独立验证。

### 7.4 竞争格局与持续竞争优势

竞争分析要回答的不只是“谁是龙头”，而是：公司在什么市场与谁竞争、靠什么获胜、获得的优势能持续多久、竞争对手如何绕过，以及优势最终能否转化为每股现金流。

完整链条为：

```text
客户需求与竞争市场
  → 竞争维度和竞争对手
  → 公司相对优势
  → 进入/扩张壁垒
  → 份额、价格、利润率和资本回报
  → 优势持续时间与侵蚀路径
  → 股东可获得的现金流
```

#### 7.4.1 先定义真正的竞争市场

市场份额和壁垒只有在竞争市场边界一致时才有意义。必须明确：

- 客户要解决的具体问题；
- 产品或服务类别、性能档位和价格带；
- 地区、客户类型、销售渠道和适用期间；
- 直接竞争者、相邻竞争者和潜在进入者；
- 替代产品、客户自研/自制和不购买方案；
- 竞争发生在产品、项目、客户、平台还是生态层面。

例如“全球通信设备”通常不是分析高速光模块公司的有效竞争市场；需要缩小到具体速率、距离、客户类型、技术路线和时间窗口。反之，只选公司最强的细分产品又会高估整体竞争地位。

#### 7.4.2 竞争对手分层

| 类型 | 定义 | 需要分析 |
| --- | --- | --- |
| 直接竞争者 | 向同类客户提供可直接比较的产品 | 价格、性能、份额、产能、利润率和客户关系 |
| 间接替代者 | 用不同产品或技术解决相同问题 | 替代成本、性能边界、渗透速度和生态支持 |
| 潜在进入者 | 尚未形成规模但具备资金、技术、渠道或客户基础 | 进入时间、认证、资本需求和可能的价格策略 |
| 客户自研/垂直整合 | 客户将供应商价值环节内部化 | 自研能力、经济性、供应安全和外购保留比例 |
| 供应商前向整合 | 上游进入公司的产品或服务环节 | 技术邻近性、客户关系和渠道能力 |
| 跨界平台 | 借助数据、生态或捆绑能力进入 | 补贴能力、捆绑销售和生态迁移成本 |

同行比较不能只选估值最接近或名字最相似的公司。每个可比对象要说明业务重叠、地区、客户、产品层级和财务口径；不真正竞争的公司只能作为估值或技术参照。

#### 7.4.3 市场结构与竞争强度

行业/赛道至少观察：

- 参与者数量、CR3/CR5 和可得时的 HHI；
- 收入份额、出货份额、利润池份额及其三至五年变化；
- 新增市场份额与存量市场份额；
- 行业进入、退出、并购和产能变化；
- 价格变化、促销、返利、账期和客户多供应商策略；
- 供需缺口、产能利用率和库存；
- 产品迭代速度和旧产品淘汰周期；
- 主要客户与供应商的集中度。

高集中度不自动等于竞争温和：少数公司也可能激烈价格战；低集中度也不一定没有壁垒，区域、渠道或客户认证可能形成局部优势。

#### 7.4.4 公司在哪些维度竞争

不同赛道的竞争维度权重不同，至少从下表选择真正影响客户决策的项目：

| 竞争维度 | 可观察证据 | 可能形成的财务结果 |
| --- | --- | --- |
| 价格与总拥有成本 | 报价、降价、客户节省、维护成本 | ASP、毛利率、客户获取速度 |
| 性能与功能 | 性能参数、稳定性、兼容性、产品组合 | 高端占比、价格溢价、份额 |
| 质量与可靠性 | 故障、退货、质保、良率、客户认证 | 售后成本、续购、毛利率 |
| 技术迭代 | 研发投入、产品节奏、量产时间、专利/工艺 | 新产品收入、生命周期和研发回报 |
| 成本与规模 | 单位成本、采购、产能利用、自动化、学习曲线 | 成本优势、价格防御、ROIC |
| 交付与供应安全 | 交期、产能、地域、备份供应链 | 客户份额、预付款、库存风险 |
| 渠道与服务 | 网点、销售效率、实施、售后和本地化 | 获客成本、客户覆盖、留存 |
| 品牌与信任 | 品牌溢价、复购、合规、安全和服务记录 | 价格、份额、获客效率 |
| 数据、网络与生态 | 用户/开发者、互操作、第三方供给和数据积累 | 留存、交叉销售、边际成本 |
| 监管、牌照与资源 | 许可、配额、矿权、特许经营、资本要求 | 进入限制、资产回报和政策风险 |

不能把公司投入当成结果。研发费用高不等于技术领先，产能大不等于成本领先，客户数量多也不等于客户黏性强。

#### 7.4.5 壁垒的类型与验证

壁垒是竞争者进入或扩张时必须跨越的结构性障碍，不是公司当前领先的同义词。

必须区分**行业共同壁垒**和**公司特有优势**：牌照或高资本门槛可能保护所有存量参与者，却不能解释目标公司为何优于同行；反过来，执行效率可能形成阶段性公司优势，但不一定阻止竞争者进入。

| 壁垒类型 | 可能的形成机制 | 必须寻找的验证证据 | 常见失效路径 |
| --- | --- | --- | --- |
| 技术/IP | 专利、工艺诀窍、复杂集成、研发积累 | 性能差距、量产记录、复制时间、研发产出 | 技术路线变化、专利到期、人才流失 |
| 成本/规模 | 采购规模、固定成本摊薄、自动化、学习曲线 | 同口径单位成本、毛利和资本效率 | 新工艺、低成本地区、价格战、过剩产能 |
| 客户认证/切换成本 | 重新测试、停机风险、迁移成本、流程嵌入 | 认证周期、续购、流失率、客户内部份额 | 标准化、客户多供、自研或强制迁移 |
| 网络效应 | 用户或供给增加提升其他参与者价值 | 留存、双边密度、边际获客改善 | 多归属、补贴竞争、互操作标准 |
| 数据/算法 | 独特数据持续改善产品或风控 | 数据独占性、模型效果、闭环速度 | 数据可购买、监管限制、通用模型替代 |
| 品牌/信任 | 长期质量、服务、安全和心智 | 价格溢价、复购、低获客成本 | 品牌事故、代际变化、渠道迁移 |
| 渠道/生态 | 稀缺渠道、开发者、互补产品和服务体系 | 覆盖、活跃度、交叉销售、伙伴依赖 | 渠道去中介、平台规则变化、伙伴流失 |
| 监管/牌照/资源 | 法定许可、资本门槛、稀缺资源和特许权 | 牌照范围、资源年限、监管资本和续期 | 政策放开、价格管制、特许权到期 |
| 资本与时间 | 大额前置投入、长建设期、复杂交付 | 达产时间、融资能力、爬坡损失 | 资本过剩、补贴进入、轻资产替代 |

每条壁垒判断都必须形成以下证据卡：

```text
壁垒命题
  → 客户为什么在意
  → 竞争者为何难以复制或绕过
  → 已观察到的份额/价格/利润/回报结果
  → 预计持续时间
  → 最可能的侵蚀路径
  → 可观察证伪条件
```

只有机制描述而没有经营或财务结果的，标为“待验证壁垒”；只有高利润而无法解释机制的，标为“暂时优势/原因待核”。

#### 7.4.6 持续竞争优势的财务验证

壁垒最终应在长期数据中留下痕迹，常见验证包括：

- 份额稳定或提升，同时没有持续牺牲价格和账期；
- 毛利率、营业利润率或单位经济性长期优于可比公司；
- ROIC 长期高于资本成本，且增量 ROIC 没有快速下降；
- 客户留存、续购、净收入留存或客户内部份额较强；
- 研发和资本开支能持续转为新产品收入、降本或现金流；
- 在需求下行、价格战或供应冲击中表现出更强韧性；
- 取得份额后能保留利润，而不是全部让利给客户或供应商；
- 稀释后每股自由现金流能够随企业价值增长。

这些结果也可能由周期、缺货、补贴、会计处理或高杠杆造成，因此必须与机制证据和完整周期同时验证。

#### 7.4.7 价值创造与价值获取

一个产品为客户创造很大价值，不代表供应商能保留这部分价值。需要分析：

```text
为客户创造的经济价值
  → 客户愿意支付的价格
  → 客户、公司、供应商和渠道之间的价值分配
  → 公司毛利和营业利润
  → 再投资需求
  → 股东自由现金流
```

重点检查五种力量：现有竞争者、潜在进入者、替代品、客户议价权、供应商议价权；同时考虑互补者、平台规则和监管。客户或供应商高度集中时，公司即使技术重要，也可能无法获得对应利润池。

#### 7.4.8 动态竞争与情景分析

竞争分析不能假设其他参与者静止。悲观、基准、乐观情景至少考虑：

- 竞争者扩产、降价、并购或退出；
- 新产品提前或延后；
- 客户增加供应商、自研或垂直整合；
- 上游关键供应商涨价、短缺或前向整合；
- 技术标准、监管或渠道规则变化；
- 市场从供不应求转为供给过剩；
- 公司为守份额付出的毛利、费用和资本代价。

份额假设必须与竞争者份额、行业总量和产能约束相加后合理。不能让所有公司在各自模型中同时大幅提升份额。

优势持续期还必须约束估值：明确壁垒只能维持三至五年时，长期预测、终值增长率和退出倍数不能默认公司永久保持当前超额利润。

#### 7.4.9 竞争证据来源与强度

优先使用：

1. 公司和竞争对手的正式披露；
2. 客户、供应商、监管机构和招投标等可核验资料；
3. 同口径市场份额、价格、出货和财务数据；
4. 产品规格、认证、专利、开发者和渠道等可观察证据；
5. 有方法说明的行业研究；
6. 访谈、渠道和媒体线索。

管理层自称“领先”“唯一”“深度绑定”只能作为来源观点。客户名单、供应关系、市场份额和成本优势没有同口径证据时，必须标记为未验证。

#### 7.4.10 竞争与壁垒的常见误判

- 把高行业增速当成公司竞争优势；
- 把当前份额第一当成不可挑战的壁垒；
- 把高毛利当成壁垒，而不检查周期、缺货或会计口径；
- 把大规模资本开支当成规模优势，而不检查利用率和 ROIC；
- 把客户集中描述为绑定，却忽略议价和单一客户风险；
- 把认证周期当永久切换成本，却忽略客户多供和标准化；
- 把专利数量当技术领先，却不看产品、量产和商业价值；
- 把市场宣传和研发费用当品牌或创新成果；
- 只研究现有同行，不研究替代技术和客户自研；
- 只分析份额，不分析获得份额的价格、账期和资本代价；
- 只看企业价值增长，不看稀释后每股价值；
- 用一个“护城河分数”抵消正在发生的份额或现金流恶化。

#### 7.4.11 竞争分析输出

竞争模块不输出单一“护城河分数”，至少分开给出：

1. 竞争市场和对手边界；
2. 市场结构与竞争强度；
3. 公司当前竞争位置；
4. 各项优势命题及证据强度；
5. 各项壁垒的持续时间；
6. 客户、供应商、替代和进入者压力；
7. 优势对应的财务结果；
8. 最可能的侵蚀路径和证伪条件。

每项优势建议使用下列统一格式：

| 优势命题 | 客户价值 | 复制/绕过难点 | 经营证据 | 财务证据 | 持续期 | 侵蚀路径 | 证伪条件 | 置信度 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 待填写 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 |

### 7.5 风险、压力测试与证伪

风险分析不是罗列所有可能的坏消息，而是识别哪些不确定性会通过什么路径损害收入、利润、现金流、资产负债表、估值或股东权利，并判断这种损害是否可逆。

完整链条为：

```text
风险事件或条件变化
  → 公司/证券暴露
  → 经营与财务传导
  → 盈利、现金流、资产或股本影响
  → 估值与预期变化
  → 预警触发/命题证伪
  → 复核、降级或重建分析
```

#### 7.5.1 先区分四类对象

| 对象 | 含义 | 示例 |
| --- | --- | --- |
| 不确定性 | 结果范围尚不明确，但不一定只向下 | 新产品渗透速度、利率路径 |
| 经营风险 | 可能损害公司业务、财务或长期价值 | 需求下降、份额流失、成本上升 |
| 证券风险 | 来源于具体上市证券和市场结构 | ADR/VIE、流动性、股份类别、持续稀释 |
| 组合/执行风险 | 来源于用户仓位、相关性、资金和交易行为 | 单股过重、杠杆、期限错配 |

公司研究页重点分析前三类。组合和执行风险可以引用公司分析，但必须留在个人投资层，不能反向改变公共公司结论。

#### 7.5.2 风险结果的严重性

风险不能只按股价波动大小分类，至少区分：

1. **短期经营波动**：订单、价格或费用的暂时变化，核心竞争力未必受损；
2. **盈利路径下修**：未来收入、利润率或现金流低于原情景，但公司仍可持续经营；
3. **核心命题失效**：需求、份额、壁垒、管理层或估值前提不再成立；
4. **永久资本损失**：破产、重大稀释、欺诈、资产永久减值、技术淘汰或股东权利受损；
5. **证券价格与流动性风险**：基本面未变但估值、汇率或流动性造成大幅波动。

价格下跌本身不能证明核心命题失效，价格稳定也不能证明风险不存在。必须回到风险事件和传导证据。

#### 7.5.3 风险分类

| 类别 | 主要问题 | 典型风险 |
| --- | --- | --- |
| 需求与宏观 | 客户是否还需要、买得起并愿意购买？ | 衰退、利率、资本开支下调、消费降级、政策收缩 |
| 行业与周期 | 行业供需是否逆转？ | 库存、过剩产能、价格战、商品价格、周期顶部 |
| 竞争与技术 | 公司是否失去份额或被替代？ | 新进入者、客户自研、技术路线变化、标准化、专利到期 |
| 产品与执行 | 公司能否按时、按质、按成本交付？ | 研发延迟、良率、质量、产能爬坡、项目验收失败 |
| 客户与渠道 | 收入是否过度依赖少数客户或渠道？ | 客户流失、降价、账期拉长、渠道库存、平台封禁 |
| 供应链与运营 | 关键投入和运营是否稳定？ | 单一供应商、原料涨价、物流、网络安全、安全生产、灾害 |
| 财务与流动性 | 公司是否有足够现金跨过逆风？ | 短债、利率、汇率、契约、再融资、现金消耗、表外义务 |
| 会计与披露 | 报表是否真实、可比和及时？ | 收入确认、资本化、减值、关联交易、审计和内控异常 |
| 资本配置 | 管理层是否会破坏每股价值？ | 高价并购、过度扩产、借债分红、低价增发、高价回购 |
| 治理与关键人 | 控制权和激励是否保护普通股东？ | 实控人占用、利益冲突、关键人离职、多重投票权 |
| 法律与监管 | 经营许可或成本是否改变？ | 反垄断、诉讼、税务、环保、数据、药品/金融监管 |
| 地缘与国家 | 跨境经营是否被限制？ | 出口管制、制裁、关税、资产冻结、本地化要求 |
| 市场与上市结构 | 证券本身是否存在额外损失路径？ | 流动性、退市、ADR/VIE、配股、供股、股份转换 |
| 估值与预期 | 即使公司不错，价格是否过度乐观？ | 盈利不及预期、风险溢价上升、退出倍数下调 |
| 数据与模型 | 判断是否建立在错误或过期输入上？ | TAM重复计算、份额误判、预测同源、口径改变 |

分类用于避免遗漏，不用于给每家公司机械生成同样数量的风险。只保留有实际暴露、证据或合理传导路径的条目。

#### 7.5.4 风险台账的最小内容

每项实质风险至少记录：

| 字段 | 需要回答的问题 |
| --- | --- |
| 风险命题 | 哪个具体条件或事件可能发生？ |
| 影响对象 | 影响经营公司、具体证券还是两者？ |
| 暴露范围 | 哪些产品、客户、地区、资产、负债或股东权利受影响？ |
| 传导路径 | 如何进入销量、价格、成本、费用、资产、现金流或股本？ |
| 时间尺度 | 何时可能发生，影响持续多久？ |
| 发生可能性 | 低/中/高或区间，并说明证据；不伪造精确概率 |
| 影响程度 | 对收入、利润、FCF、净资产、流动性、稀释或估值的范围 |
| 速度 | 是缓慢恶化还是可能突然发生？ |
| 可逆性 | 能否通过时间、现金、替代方案或经营调整恢复？ |
| 关联风险 | 是否会与需求、汇率、融资或其他风险同时发生？ |
| 现有缓释 | 公司有哪些已验证的对冲、备份、保险、合同或现金能力？ |
| 剩余风险 | 考虑缓释后仍由股东承担什么？ |
| 预警指标 | 哪些领先指标要求提前复核？ |
| 证伪条件 | 哪个事实会推翻核心命题或情景假设？ |
| 证据和缺口 | 当前依据、相反证据和仍缺什么？ |
| 复核安排 | 上次复核、下次复核和触发后动作 |

风险可能性和影响可以分级，但不能依靠相乘得到一个精确“风险分”。低概率、极高损失的尾部风险不能因乘积较小被隐藏。

#### 7.5.5 毛风险、缓释措施与剩余风险

需要分别展示：

```text
毛风险
  - 已验证且在压力下仍有效的缓释措施
  = 剩余风险
```

管理层表示“可控”、签署意向协议、尚未投产的备份产能或未经压力验证的保险，不能直接当作有效缓释。缓释措施还要检查成本和副作用，例如多元供应可能降低短缺风险，却提高采购成本和营运资本。

#### 7.5.6 风险量化方法

能量化时优先使用以下方法，而不是主观打分：

| 方法 | 回答的问题 | 示例 |
| --- | --- | --- |
| 单变量敏感性 | 一个变量变化会造成多大影响？ | ASP -5%、汇率 ±5%、毛利率 -2pct |
| 盈亏平衡分析 | 变量恶化到什么程度会使利润、现金或契约触线？ | 最低利用率、最高信用成本、最低商品价格 |
| 情景压力测试 | 多项相关风险同时发生会怎样？ | 需求下降 + 降价 + 库存减值 + 融资成本上升 |
| 反向压力测试 | 什么组合会使投资命题或偿债能力失效？ | FCF 转负、现金跑道不足、资本充足跌破约束 |
| 流动性跑道 | 公司能支撑多久？ | 可用现金 ÷ 压力情景现金消耗 |
| 稀释分析 | 融资或股权激励如何影响每股价值？ | 新发行股份、可转债、SBC、供股 |
| 估值压力 | 盈利和倍数同时下修时损失多大？ | EPS 下修 20% 且 PE 从 30×降至20× |

单变量敏感性不能代替情景压力测试，因为需求、价格、利润率、库存和融资往往在逆风期同时恶化。

#### 7.5.7 风险集中与相关性

需要识别同一个底层风险是否重复出现在多个表面指标中，以及多个风险是否由同一冲击共同触发：

- 客户集中：同时影响收入、价格、应收和库存；
- 产品集中：同时影响技术替代、毛利和资本开支回收；
- 地区集中：同时影响需求、汇率、税务和监管；
- 供应商集中：同时影响成本、交付、良率和客户关系；
- 融资集中：同时影响利息、再融资、资本开支和稀释；
- 单一管理层/关键人：同时影响研发、客户、治理和资本配置。

风险台账避免重复计数，但压力情景要体现相关风险同时发生。组合层还需检查多家公司是否暴露于同一客户、行业、利率或地缘冲击。

#### 7.5.8 预警、证伪与永久损失触发

| 层级 | 含义 | 触发后的动作 |
| --- | --- | --- |
| 预警指标 | 可能恶化，需要提高复核频率 | 补证据、更新情景，不自动改变结论 |
| 情景偏离 | 实际结果超出基准假设范围 | 重算盈利、现金流和估值 |
| 核心证伪 | 支撑投资命题的关键关系不再成立 | 降级或重建研究命题 |
| 生存/权利约束 | 流动性、契约、监管或股东权利受到实质威胁 | 最高优先级复核，不能被其他优势抵消 |

好的证伪条件必须具体、可观察并与命题直接相关，例如“连续两个报告期份额下降且不是主动退出低毛利业务”。“行业不及预期”“股价跌破某点”过于模糊，不能单独作为基本面证伪。

#### 7.5.9 估值风险与基本面风险分离

需要分别展示：

- **基本面风险**：盈利和现金流本身恶化；
- **估值风险**：盈利基本兑现，但市场给予的倍数下降；
- **双重风险**：盈利下修与估值压缩同时发生；
- **流动性风险**：交易深度、资金可达性或市场事件放大价格变化。

高质量公司仍可能有很高估值风险；低估值公司也可能因为盈利不可持续、资产减值或治理而并不便宜。历史回撤和波动只能说明市场表现，不能替代上述拆分。

#### 7.5.10 不同市场的证券风险

| 市场 | 需要额外检查 |
| --- | --- |
| A股 | 实控人和关联交易、股权质押、限售解禁、再融资、退市规则、政策和交易制度 |
| 港股 | 控股股东、配股/供股、低流动性、关联交易、股份合并、私有化和A/H结构 |
| 美股 | 诉讼与集体诉讼、SBC和稀释、多重投票权、监管、指引依赖和回购价格 |
| ADR | VIE/境外控股权利、存托费用、审计、跨境监管、制裁、退市和转换安排 |

经营公司相同不代表证券风险相同。多地上市公司需要共享经营风险，同时为每只证券保留独立风险条目。

#### 7.5.11 按商业模式增加风险

| 公司类型 | 优先风险 |
| --- | --- |
| 银行 | 信用成本、资产质量、挤兑/流动性、资本充足、净息差、期限错配和监管 |
| 保险 | 承保、准备金、利率、投资资产、偿付能力和灾害尾部风险 |
| 周期/资源 | 商品价格、成本曲线、过剩产能、资源和维持资本开支 |
| 软件/SaaS | 留存、获客效率、竞争降价、SBC、云成本、数据安全和平台依赖 |
| 平台/互联网 | 监管、网络效应反转、内容/商户生态、变现率、补贴和数据合规 |
| 制造/硬件 | 客户集中、产品迭代、良率、库存、供应链、质量和扩产回报 |
| 创新药 | 临床失败、审批、支付、专利、竞争管线、现金跑道和融资稀释 |
| 公用事业/重资产 | 利率、债务、项目延期、利用率、维护资本开支和监管定价 |

这些只是风险提示，不是自动生成结论；必须结合公司实际暴露和证据。

#### 7.5.12 风险证据与监测频率

风险证据优先级一般为：

1. 财报、公告、监管、法院、审计和合同等原始资料；
2. 客户、供应商、债权人和竞争对手的正式披露；
3. 可复现的价格、产量、库存、信用和行业数据；
4. 有方法说明的研究材料；
5. 媒体、访谈和渠道线索。

监测频率按风险速度决定：突发流动性、监管、诉讼和安全事件需要事件触发；经营和财务风险通常按月度、季度或财报期；长期技术替代和行业结构按关键里程碑复核。更新频率高不代表证据等级高。

#### 7.5.13 常见风险分析错误

- 把年报“风险因素”整段复制，未说明公司实际暴露和财务影响；
- 只列风险名称，没有传导路径、触发指标和时间范围；
- 把股价回撤、波动率或做空比例直接当基本面风险；
- 只给概率，不给损失范围、速度和可逆性；
- 认为没有历史案例就等于低概率；
- 把管理层计划当作已经生效的缓释措施；
- 对相关风险逐项相加，或反过来假设它们彼此独立；
- 只测盈利下修，不测现金、债务、稀释和股东权利；
- 只看基本面，不看高估值下的倍数压缩；
- 用正面因素或高总分抵消欺诈、流动性和核心证伪风险；
- 风险已经触发后仍保留旧概率和旧估值；
- 把所有不确定性都写成风险，导致真正重要风险被淹没。

#### 7.5.14 风险分析输出

风险模块至少输出：

1. 三至五项核心风险；
2. 需要持续观察的次要风险；
3. 每项风险的暴露、传导、时间、可能性、影响、速度和可逆性；
4. 毛风险、缓释措施和剩余风险；
5. 单变量敏感性、综合压力和反向压力结果；
6. 预警指标、情景偏离、核心证伪和生存约束；
7. 经营公司风险与具体证券风险；
8. 风险间的相关性和集中暴露；
9. 数据缺口、相反证据和下一次复核；
10. 与上一分析快照相比新增、升级、降级或解除的风险。

页面不输出可被其他维度抵消的风险总分。任何涉及生存能力、股东权利、重大欺诈或核心命题失效的风险都应单独置顶。

### 7.6 商业模式与单位经济

商业模式模块要先解释交易如何发生，再讨论增长和估值。至少需要形成下面的闭环：

```text
客户问题与购买者
  -> 产品/服务与交付方式
  -> 合同、定价和收入确认
  -> 获客、履约、服务和资本成本
  -> 单位经济与回收周期
  -> 规模扩大后的利润、现金流和再投资需求
```

对适用公司至少回答：

- 付费者、使用者和决策者是否为同一主体，采购周期和切换成本如何；
- 收入是一次性、订阅、按量、佣金、利差、保费、项目制还是多种模式组合；
- 合同期限、续约、最低采购、价格重议、退货、质保和验收条款如何影响收入确认与现金回收；
- 单位收入对应的直接成本、获客成本、履约成本、维护资本和营运资本是多少；
- 销量增长是否要求同比例增加销售人员、设备、库存、信贷或资本；
- 哪个稀缺资源限制增长：客户需求、认证、产能、良率、供应、数据、牌照、资金还是人才；
- 单位经济改善来自真实效率、产品结构、提价和复购，还是来自暂时补贴、低计成本或资本化支出。

按商业模式加载适用指标，例如 SaaS 的 ARR、留存、CAC、LTV 和回收期，平台的 GMV、抽佣率和补贴，制造业的单价、单位成本、良率、产能利用率和单线回报，银行的生息资产收益率、负债成本、信用成本和资本消耗。没有可靠分子、分母和同期口径时，单位经济显示为不可得，不能用行业平均值自动代入。

### 7.7 管理层、治理与资本配置

三者相关但不能合并成“管理层优秀”一个结论：

| 对象 | 必须回答的问题 | 主要证据 |
| --- | --- | --- |
| 管理层能力 | 是否理解业务关键约束并能稳定执行？ | 历史经营结果、关键项目、危机处理、人才与组织变化 |
| 管理层可信度 | 指引、承诺和解释是否与后续事实一致？ | 历次指引与实际、口径变化、错误承认、信息披露及时性 |
| 治理结构 | 控制权、董事会、审计和激励是否保护普通股股东？ | 股权和投票权、独立董事、审计意见、关联交易、监管与诉讼 |
| 利益一致性 | 决策者是否承担与股东相近的收益和损失？ | 持股、薪酬、SBC、减持、质押、回购和业绩条件 |
| 资本配置 | 留存利润、负债和新股融资被投向哪里，回报如何？ | 研发、资本开支、并购、处置、分红、回购、融资和增量 ROIC |

资本配置要建立逐年资金去向表，并分别评价维持经营、内生增长、并购、偿债、分红和净回购。回购必须同时检查价格、回购后稀释股数、SBC 和融资；并购必须检查收购倍数、商誉、整合目标、后续减值和实际增量回报。治理严重缺陷属于独立风险，不能被增长或低估值抵消。

### 7.8 预测兑现与校准

预测模块不仅保存未来数字，还要保存“当时是谁、基于什么口径、在什么日期预测了什么”，并在实际结果发布后校准。

#### 7.8.1 用信息预处理和本地大模型整理多份研报预测

信息预处理已经形成来源绑定的信息记录，因而可以作为跨研报预测研究的证据底座。它先保留每一份研报中的预测、观点和原文证据；本地大模型再基于被选中的记录和原文片段，生成**预测整理草稿**，协助完成指标识别、口径映射、冲突解释和驱动归纳。草稿不是来源事实，也不是系统最终预测。

完整链路应当是：

1. **来源预测**：每份研报独立保留机构、分析师（可得时）、发布日期、报告版本、覆盖公司/证券、原币/单位、会计口径、预测期间、数值、评级/目标价及证据定位；
2. **预测整理草稿**：本地大模型只可根据已选来源提出“这可能对应哪项指标、哪些数值可比、哪些冲突待核验、共同的业绩驱动和分歧来自何处”；每一项都必须回链到来源记录和原文，无法映射时输出“待人工确认”；
3. **标准化预测样本**：经过规则或人工确认后，把可比的来源预测按指标、财年、币种、单位、GAAP/调整后口径、归属口径和基本/稀释每股口径分组；原始预测不被覆盖；
4. **多研报汇总观察**：仅对同组、有效、可追溯且去重后的样本计算中位数、均值、最高/最低、样本数、离散度和相对上次快照的修订方向。这是由第三方预测计算出的派生观察，不是新的第三方事实；
5. **自建情景**：研究者可以引用来源预测、管理层指引和经营驱动建立悲观、基准、乐观情景；情景的数值和权重仍标为自建假设，不能以“多份研报汇总”名义伪装成共识。

“多研报汇总”默认只能称为**已纳入样本的预测汇总**。只有当数据范围、授权和覆盖规则证明样本接近所定义的机构覆盖全集时，才可称“市场一致预期/共识”；当前零散研报或用户导入材料不能这样命名。

为避免重复和伪精确，汇总规则必须明确：同一机构同一模型链只取截至快照日的最新有效版本；转载、摘要、联合署名、同源数据库和无法判明独立性的报告不重复计数；只有完全相同的公司主体、预测期间、币种单位和会计口径才能计算统计量。货币换算、GAAP 与 non-GAAP、归母与合并利润、基本与稀释 EPS、自然年与错配财年不能由模型猜测，不能可靠映射就分组展示或标为不可比。

本地大模型可以提升阅读和整理效率，但不得：

- 编造研报没有给出的收入、利润、EPS、目标价、份额或驱动；
- 以语义相似为由合并不同财年、不同口径或不同公司主体的数字；
- 因多份来源“看起来一致”而把预测升级为事实；
- 在生产环境实时调用大模型，或在没有原文/证据定位时输出可参与汇总的数字。

页面上至少应同时呈现“来源明细、纳入/排除及原因、标准化口径、汇总统计、主要分歧、预测整理草稿、实际兑现与校准”。这样用户既能快速看未来业绩区间，也能回到任一研报判断汇总是否可靠。

| 预测对象 | 必须保留 | 实际发布后复盘 |
| --- | --- | --- |
| 管理层指引 | 发布日、区间、期间、口径、条件和原文来源 | 是否落在区间、是否修改口径、提前修订次数 |
| 第三方预测 | 机构、分析师、发布日期、适用期、口径和报告 | 收入/利润/EPS 误差、方向偏差、修订提前量 |
| 自建情景 | 假设版本、负责人、证据、上下限和敏感性 | 哪个经营假设偏离、模型偏差和应否修改 |

同一期间的预测必须使用发布时可见的信息进行回测，不能用最新预测覆盖历史版本。应显示绝对误差、百分比误差、连续高估/低估偏差和关键驱动偏差；样本太少、实际口径变化或并购重述时标记不可比。预测校准影响后续情景权重和估值区间置信度，但不能把历史命中率直接当作未来必然概率。

## 8. 市场与上市结构层

### 8.1 跨市场统一口径

比较 A股、港股和美股时，至少统一：

- 财年和报告期间；
- 报表币种、证券交易币种和汇率日期；
- 归属于普通股股东的利润；
- 基本股本、稀释后股本和潜在稀释工具；
- 每股收益和 ADR 换算比例；
- 总市值、企业价值和净现金/净负债口径；
- GAAP、非 GAAP、经调整利润之间的差异；
- 分红税费、股份类别和投票权；
- 一次性项目、并购和会计准则差异。

### 8.2 各市场重点

| 市场 | 必须额外关注 | 常见误区 |
| --- | --- | --- |
| A股 | 实控人和股权质押、限售解禁、再融资、政府补助、关联交易、产业政策、价格涨跌限制 | 把概念标签当主营；忽略扣非与现金流；把政策利好直接当公司利润 |
| 港股 | 控股股东、关联交易、配股/供股、自由流通、流动性、港币与经营币种、A/H结构、南向资金 | 只因估值低就认为便宜；忽略流动性折价、治理和持续融资 |
| 美股 | US GAAP 与 non-GAAP 调整、股权激励、回购和稀释、多重投票权、季度指引、诉讼与监管 | 只看调整后 EPS；忽略 SBC、稀释、回购成本和指引变化 |
| 美股 ADR | ADR 比例、存托费用、VIE/境外控股结构、审计与跨境监管、退市和可转换风险 | 把 ADR 当作与本地普通股完全相同的法律权利 |

这张表只定义最低检查项。具体公司仍可能需要额外的市场或法律结构分析。

## 9. 估值原型

每家公司选择一个主估值原型，其他方法用于交叉验证。选择依据是主要盈利和现金流机制。

| 原型 | 适用对象 | 主要方法 | 必须同时检查 |
| --- | --- | --- | --- |
| 成长盈利型 | 已盈利且增长主要由产品、份额或渗透率驱动 | 逐年 Forward PE、DCF | 绝对 PE、利润路径、预测可信度、现金转化、退出倍数 |
| 稳定现金/红利型 | 增长较低但现金流和分红稳定 | 股息率、FCF 收益率、股利折现 | 分红覆盖、负债、资本开支和利润持续性 |
| 周期/商品型 | 盈利主要受价格、库存和产能周期影响 | 中周期利润、EV/EBITDA、PB/NAV | 成本曲线、周期位置、库存、产能和资产负债表 |
| 银行型 | 净息差、资产质量和资本约束主导 | PB-ROE、股息率 | 净息差、不良、关注、拨备、资本充足和信用成本 |
| 保险/证券型 | 承保、投资或资本市场周期主导 | 保险 P/EV；证券 PB-ROE/正常化利润 | 偿付能力、投资收益、权益市场、杠杆和风险资产 |
| 资产/公用事业型 | 长期资产、特许权或受监管回报主导 | DCF、EV/EBITDA、NAV | 利率、负债期限、资本开支、利用率和监管回报 |
| 未盈利/里程碑型 | 价值依赖研发、审批、产能爬坡或商业化 | 概率调整 DCF、现金跑道、可比 EV/收入 | 成功概率、资金需求、稀释和里程碑时间 |
| 多元控股/SOTP 型 | 多项业务或资产价值差异较大 | 分部估值加总、NAV | 控股折价、少数股东、税负、内部交易和重复负债 |

不能出现以下行为：

- 周期顶部用当期低 PE 证明便宜；
- 未盈利公司强行计算 PE；
- 同样的 PEG 忽略绝对 PE 差异；
- 只选能够给出最高价值的方法；
- 港股低估值不检查治理、流动性和持续融资；
- 美股只用 non-GAAP 利润而忽略 SBC 和稀释。

### 9.1 反向估值

除正向预测外，所有主要估值都应回答：

> 当前价格要求公司未来实现多少收入、利润、份额、回报率或自由现金流？

这样才能判断市场已经计入了什么，而不是只证明公司存在增长空间。

### 9.2 估值前置条件

开始估值前必须确认：估值基准日和价格、证券币种、基本与稀释股本、ADR 比例、归属普通股股东的利润、净现金/净负债、少数股东、联营投资、非经营资产、潜在稀释和主要会计调整。任一关键桥接项缺失时，不输出伪精确的每股价值。

企业价值到股权价值的桥接至少说明：

```text
企业价值
  + 非经营现金和可变现投资
  - 债务、租赁及类债务项目
  - 少数股东和优先权益
  ± 其他明确调整
  = 普通股股权价值
  ÷ 稀释后等价普通股股数
  = 每股价值
```

同一经营公司的 A股、H股或 ADR 必须按各自权利、比例、币种和股本计算，不共用一个未经换算的目标价。

### 9.3 预测期、终值和正常化

- 显式预测期应覆盖主要驱动回归稳定状态所需时间，而不是固定套五年；
- 收入、利润率、税率、资本开支、营运资本和股本必须彼此一致；
- 终值增长率、退出倍数和资本成本需要经济含义与敏感性，不使用单点默认值；
- 周期公司使用中周期价格、销量、成本和资本开支，不能把峰值利润永久化；
- 未盈利公司需要现金跑道、后续融资和稀释路径；
- 多元公司 SOTP 必须扣除总部成本、净负债、少数股东、潜在税负和控股折价，并防止重复计值。

### 9.4 相对估值与可比公司

可比公司应按业务组合、增长、利润率、资本强度、会计口径、周期位置、地区和股东权利筛选。展示 PE、EV/EBITDA、EV/收入、PB、FCF 收益率等指标时，要说明为什么适用，并解释估值差异，而不是机械采用同行均值。历史分位只能说明该证券相对自身历史的位置，不能证明绝对低估。

### 9.5 价值区间、预期收益与敏感性

估值输出至少包括悲观、基准和乐观情景的经营结果、估值方法、关键输入、股权价值、每股价值和基准日潜在回报。预期年化收益若包含盈利增长、估值变化、分红、回购、汇率或稀释，应逐项拆开。情景概率只有在有校准依据时才展示；否则保留三个独立区间，不制造加权目标价。

敏感性至少覆盖两个最重要的经营变量和两个估值变量。对高杠杆、未盈利或多地上市公司，增加利率、融资、稀释、汇率、ADR 比例或股东权利情景。

### 9.6 估值结论的最小输出

1. 估值基准日、证券、币种和价格；
2. 主估值原型及选择理由，辅助方法及差异解释；
3. 预测与估值输入的事实、指引、第三方预测和自建假设来源；
4. 企业价值到每股价值的完整桥接；
5. 三情景价值区间、反向估值和关键敏感性；
6. 与历史、同行和其他上市证券的可比性限制；
7. 数据缺口、模型风险、失效条件和下一次复核日期。

## 10. 行业/赛道层

### 10.1 每个行业档案应包含

| 模块 | 需要说明的内容 |
| --- | --- |
| 行业边界 | 包含什么、不包含什么，与相邻赛道如何区分 |
| 价值链 | 谁采购、谁生产、谁付费、收入在哪个节点确认 |
| 需求方程 | 终端需求如何转化为销量、价格、利用率或资产增长 |
| 市场空间 | TAM、SAM、年度路径、价值量和行业利润池 |
| 供给方程 | 产能、资源、技术、监管、良率或资本如何限制供给 |
| 竞争结构 | 份额、集中度、进入壁垒、替代品和议价权 |
| 周期位置 | 库存、价格、产能、资本开支和领先指标 |
| 专属 KPI | 指标定义、来源、频率、领先/滞后属性和财务映射 |
| 财务传导 | 行业变量如何进入公司的量、价、成本、费用、资产或信用损失 |
| 估值习惯 | 推荐的主原型、辅助方法、正常化方式和禁用方法 |
| 催化与风险 | 可观察事件、传导前提和反证条件 |
| 同行比较 | 应选择哪些可比公司，哪些差异需要调整 |

### 10.2 行业专属指标示例

- 银行：净息差、不良率、关注率、拨备、信用成本、存款结构、资本充足率；
- 保险：新业务价值、内含价值、偿付能力、承保利润、投资收益；
- 煤炭：产量、售价、单位成本、长协比例、库存、资源年限；
- 消费品牌：销量、提价、终端动销、渠道库存、单店效率、投放效率；
- 软件/SaaS：ARR、净收入留存、获客成本、回收期、递延收入、SBC；
- 半导体设备：客户资本开支、具体工艺、验证、订单、验收、交期和份额；
- 光通信：云资本开支、网络架构、端口速率、出货、ASP、良率、认证和替代路线；
- 创新药：临床阶段、终点、入组、成功概率、竞争管线、现金跑道和授权条款。

“景气度高”“渗透率提升”“供不应求”等没有定义、期间、来源和财务传导的表述，只能列为待验证叙事。

## 11. 重要公司侧重层

### 11.1 为什么需要

通用框架和行业档案保证可比较性，但无法完整表达重要公司的独特驱动。例如：

- 同属光通信，不同公司在客户、产品速率、良率和上游器件上的暴露不同；
- 同属互联网平台，广告、游戏、云、金融科技和回购对不同公司的重要性不同；
- 同属 AI 芯片，产品迭代、软件生态、供应链和出口限制可能决定完全不同的风险；
- 同属银行，客群、区域、负债结构和资产质量差异很大。

### 11.2 哪些公司进入重点档案

公司是否重要不应仅由市值自动决定。建议由用户明确选择，可能包括：

- 当前持仓或计划研究的公司；
- 长期观察池中的行业代表公司；
- 对组合风险或产业判断影响较大的公司；
- 需要长期跟踪专属经营指标的公司。

未进入重点档案的公司仍能完成通用层、市场层和行业层分析。

### 11.3 重点公司档案的功能

| 功能 | 内容 |
| --- | --- |
| 公司驱动树 | 少数关键变量如何从业务传导到收入、利润和现金流 |
| 专属 KPI | 只有该公司或极少数同业需要持续跟踪的指标 |
| 核心研究命题 | 2—5 条有期间、证据和反证的判断 |
| 产品/客户/地区 | 重要产品、客户集中、区域、渠道和供应链暴露 |
| 管理层记录 | 重要承诺、资本配置、并购、回购、融资和兑现情况 |
| 事件日历 | 财报、产品、审批、投产、客户、解禁和监管节点 |
| 专属风险 | 公司结构、会计、技术、治理或地缘风险 |
| 证伪条件 | 量化或可观察的触发条件、复核频率和影响范围 |
| 变化复盘 | 与上一次判断相比，事实、假设和结论发生了什么变化 |

### 11.4 重点公司示例

以下仅用于验证“侧重层”的表达能力，不代表当前结论：

| 公司 | 市场 | 通用与行业之外的侧重点示例 |
| --- | --- | --- |
| 中际旭创 | A股 | 800G/1.6T产品结构、客户集中、良率、海外交付、ASP降幅与降本、光互连替代路线 |
| 招商银行 | A股/H股 | 零售客群、存款成本、财富管理、房地产与信用卡资产质量、A/H估值差异 |
| 腾讯控股 | 港股 | 游戏、广告、金融科技、云与AI投入的分部价值，回购与股本变化，监管和投资资产 |
| NVIDIA | 美股 | 产品代际、数据中心客户集中、供应与先进封装、网络业务、毛利率、SBC、出口限制 |

重点公司档案只增加针对性，不降低公共证据和财务质量要求。

以中际旭创为方法示例，市场空间不应直接使用“全球 AI 基础设施规模”，而应逐层缩小：

```text
AI 集群节点或交换端口需求
  × 每个节点/端口对应的光连接数量
  × 可插拔光模块适用比例
  × 不同速率产品结构
  × 各速率 ASP
  = 光模块产品市场空间 TAM

TAM
  × 公司产品和地区可服务比例
  × 可进入客户采购比例
  = SAM

SAM
  × 基于客户多供、认证、产能、良率和竞争推算的可获得份额
  = SOM
```

最后还要用公司产能、历史出货、客户采购、收入结构和现金流自下而上验证。上述每个比例都是待取证的输入，不是因为公司是行业龙头就自动成立。

## 12. 研究深度、依赖与生命周期

### 12.1 三种研究深度

研究深度按问题和证据要求分级，不按页面长度分级。较深层级包含较浅层级，不能跳过阻断项后宣称“深度分析完成”。

| 层级 | 用途 | 最低内容 | 可以输出 | 不应输出 |
| --- | --- | --- | --- | --- |
| 基础 | 快速判断是否值得继续研究 | 公司/证券身份、主营与收入来源、最近财务趋势、行情估值观察、重大公告、核心风险和数据缺口 | 研究优先级、显著异常、待补资料 | 完整价值区间、确定性竞争优势、长期盈利结论 |
| 标准 | 形成可复核的公司与证券判断 | 通用分析全模块、至少三至五年财务、行业档案、同行、三情景、估值桥和风险台账 | 业务/财务/估值状态、主要命题及证伪 | 缺少关键股本、现金流、市场边界时的精确目标价 |
| 深度 | 重要公司、持仓或重大事件研究 | 分部模型、单位经济、TAM/SAM/SOM、客户/竞争/产能证据、管理层校准、详细估值和压力测试 | 带置信边界的价值区间、命题变化和监测计划 | 把渠道线索、单一研报或模型假设升级为事实 |

“基础层完成”只表示基础层必填输入可用，不表示公司值得投资；“深度层未完成”也不自动意味着公司质量差。

### 12.2 模块依赖

```text
公司与证券身份
  -> 财务期间、币种、股本和会计口径
  -> 商业模式、分部和行业边界
  -> 经营驱动、单位经济、市场空间和竞争
  -> 历史财务、治理与资本配置验证
  -> 管理层指引、第三方预测和自建情景
  -> 估值、反向估值与压力测试
  -> 风险、证伪、催化剂和监测计划
  -> 带截止日的研究快照
```

后置模块不能掩盖前置缺口。例如没有稀释后股本不能得到可靠每股价值；没有市场边界不能得到公司份额；没有现金、债务和融资承诺不能判断生存能力；没有分部口径不能对多元公司做可靠 SOTP。

### 12.3 研究生命周期

1. **建档**：确认经营公司、上市证券、主营行业、报告币种和研究深度；
2. **取证**：收集来源绑定的事实、指引、预测和观点，记录截止日、期间和口径；
3. **标准化**：处理财年、币种、股本、会计、分部和一次性项目差异；
4. **派生观察**：用明确公式计算增长、利润率、回报率、份额、估值等可复算结果；
5. **形成命题**：把证据与经营传导连接成可证伪判断，同时保留相反证据；
6. **情景与估值**：显式设置假设，推导财务结果、价值区间和当前价格隐含要求；
7. **风险审查**：检查生存、权利、治理、集中、估值和模型风险；
8. **冻结快照**：保存当时可见事实、假设、判断、缺口和下次复核点；
9. **监测与校准**：新公告、财报、价格、竞争动作或实际结果出现后，更新受影响模块而非全文静默覆盖。

### 12.4 信息所有权边界

| 层级 | 可以包含 | 不可以包含 |
| --- | --- | --- |
| 来源信息层 | 原文档、已观察事实、管理层指引、第三方预测、来源观点及来源元数据 | 系统替来源下结论、把多来源一致当作已证实事实 |
| 派生观察层 | 可复算公式、口径、输入、输出和异常标记 | 隐藏调整、缺失值补零、不可复现的模型判断 |
| 分析层 | 研究命题、自建假设、情景、系统判断、反证和置信边界 | 改写原始来源，或把判断回写成来源事实 |
| 用户决策层 | 用户笔记、关注、持仓引用和交易计划 | 反向修改公共事实、行业规则或其他用户的分析 |

现有“信息处理”只负责来源绑定的信息记录，不因投资分析需要而自动承担系统结论、评分或交易判断。投资分析可以引用这些记录；多份研报的本地大模型整理只能先形成可回溯的草稿，经过口径确认后才可生成预测汇总观察，并须在独立的派生观察和分析层完成验证与推导。

### 12.5 状态优先级与完成规则

模块状态按以下优先级判定，前一状态未解除时不能被后一状态覆盖：

1. 对象或口径错误；
2. 阻断事实缺失或来源不可用；
3. 关键来源冲突或不可比；
4. 关键事实过期；
5. 已具备所选研究深度的最低证据；
6. 已复核并冻结为快照。

完成度按必填项逐项判断，不计算能让重要缺口被平均掉的总百分比。非阻断缺口可以带着明确影响进入快照；阻断缺口必须让相应结论保持“不可得”。来源恢复、财报重述或证券结构变化后，受影响的派生观察、判断和估值自动进入待复核，而不是继续沿用旧完成状态。

## 13. 需要具备的功能

### 13.1 公司与证券范围确认

- 搜索并选择具体上市证券；
- 显示对应经营公司、上市市场、币种和股份类别；
- 识别 A/H、ADR、多重上市和多重投票权；
- 在经营公司分析和证券分析之间切换；
- 防止把不同证券的价格、股本或利润口径混合。

### 13.2 分层研究导航

- 清楚显示当前加载的通用层、市场层、行业/赛道层和公司侧重层；
- 展示每一层的选择依据；
- 对缺失的行业档案或公司档案明确提示；
- 允许查看哪些结论来自公共规则，哪些来自行业或公司侧重。

### 13.3 商业模式与驱动树

- 展示产品、客户、渠道、地区和收入确认方式；
- 展示合同期限、定价、履约、续约、退货、质保和回款条件；
- 按商业模式展示单位收入、单位成本、获客、留存、回收期、资本和营运资金占用；
- 将行业需求传导到公司销量、价格、份额、成本和现金流；
- 支持一家公司多个分部，但明确一个主要盈利驱动；
- 避免用一张泛化产业链图替代公司财务映射。

### 13.4 市场空间与份额测算

- 展示 TAM、SAM、SOM 的口径、年份、来源和计算链；
- 同时展示销量/用户等数量空间、收入空间和行业利润池；
- 支持自上而下与自下而上两种测算并解释差异；
- 展示当前份额、可获得份额、份额变化来源和时间路径；
- 用产能、客户或排名推断份额时明确标为代理指标；
- 将市场空间进一步传导到毛利、利润、营运资本和自由现金流；
- 在悲观、基准、乐观情景中分别改变市场增长、可服务比例和份额；
- 暴露边界不一致、重复计算和关键假设缺失。

### 13.5 财务与质量分析

- 默认展示五年年度、十二个季度和滚动十二个月趋势；
- 同时展示同比、环比、CAGR、利润率、周转率和每股指标；
- 展示收入到营业利润、归母利润、经营现金流和自由现金流的桥接；
- 区分报告利润、扣非利润、GAAP、non-GAAP 和分析调整值；
- 展示经营现金转换率、自由现金流率、DSO、DIO、DPO 和现金转换周期；
- 展示净债务、到期结构、利息覆盖、ROE、ROIC、增量 ROIC 和杜邦拆解；
- 展示资本开支、研发、并购、分红、净回购、SBC 和稀释后股数；
- 按商业模式选择通用、银行、保险、证券、周期、SaaS、平台、重资产或未盈利指标包；
- 识别一次性项目、并购、会计口径变化、股权稀释和异常趋势；
- 对负分母、极小分母、数据缺失和跨市场不可比明确显示“不适用/待补”。

### 13.6 管理层、治理与资本配置

- 分开展示管理层能力、指引可信度、治理结构和利益一致性；
- 追踪控制权、董事会、审计、关联交易、处罚、诉讼和股东权利变化；
- 比较管理层历次正式指引、承诺与后来实际结果；
- 建立研发、资本开支、并购、处置、偿债、分红、回购和融资的资金去向表；
- 对并购检查收购价格、商誉、整合目标和实际增量回报；
- 对回购同时检查价格、SBC、增发和稀释后股数；
- 治理或权利阻断项独立置顶，不被增长、估值或其他分数抵消。

### 13.7 行业/赛道研究

- 展示行业需求、供给、周期、竞争和专属 KPI；
- 说明行业数据如何传导到目标公司；
- 提供同行列表和可比性差异；
- 保留行业观点、事实和公司实际暴露之间的边界；
- 支持同一公司存在次要业务暴露，但避免重复计算。

### 13.8 竞争与壁垒分析

- 定义具体竞争市场、产品层级、客户、地区和期间；
- 区分直接竞争者、替代者、潜在进入者、客户自研和供应商前向整合；
- 展示 CR3/CR5、份额变化、价格、产能、库存和竞争强度；
- 按价格、性能、质量、成本、交付、渠道、品牌、网络、数据和监管拆解竞争维度；
- 为每项壁垒展示形成机制、客户价值、复制难点、经营证据和财务证据；
- 展示客户、供应商、替代品、进入者和互补者的价值分配；
- 区分当前优势、进入壁垒、持续竞争优势和股东价值获取；
- 记录优势持续期、侵蚀路径、竞争者动作和证伪条件；
- 对只有管理层表述、没有结果证据的壁垒标记“待验证”；
- 不使用一个护城河总分覆盖份额、利润率或现金流恶化。

### 13.9 同行比较

- 支持同市场和跨市场同行；
- 比较增长、利润率、现金流、资本效率、估值和关键行业 KPI；
- 显示币种、财年、会计和业务结构差异；
- 允许排除不可比公司并记录理由；
- 不只展示平均数，要显示目标公司为何高于或低于同行。

### 13.10 预测与情景

- 分开显示管理层指引、不同机构预测和自建假设；
- 以信息预处理的来源记录和原文证据作为研报预测的输入；允许本地大模型生成带证据链接的预测整理草稿，但不把草稿当作事实或自动通过；
- 对每份研报展示公司/证券主体、机构、报告版本、预测期、币种单位、会计与每股口径、原始数值及纳入状态；
- 将可比样本按统一口径分组，展示已纳入样本的中位数、区间、离散度和修订方向；样本覆盖不足时禁止标为“市场一致预期”；
- 展示同源去重、口径冲突、缺失数值和人工待核验项，不能计算的指标保持不可得；
- 展示预测的发布日期、适用年度、样本数、分歧和修订方向；
- 保留每个历史预测版本，实际结果发布后按同口径计算误差和驱动偏差；
- 分开校准管理层、机构和自建模型，不用最新版本覆盖历史判断；
- 建立悲观、基准、乐观三情景；
- 分别设置 TAM 增长、SAM 比例、公司份额、ASP 和利润率；
- 从经营变量推导收入、利润、现金流和资产负债变化；
- 对关键变量做敏感性分析；
- 显示哪些结果因数据不足无法计算。

### 13.11 估值与预期

- 根据商业模式选择主估值原型并解释理由；
- 同时展示主估值、辅助估值、历史位置和同行比较；
- 展示逐年 Forward 指标，而不只展示最远年份；
- 进行反向估值，解释当前市值隐含的经营要求；
- 分别计算不同上市证券的市值、每股价值和潜在回报；
- 显示汇率、股本、稀释、退出倍数和预测误差的敏感性。

### 13.12 研究命题与证据

- 维护少量核心命题，而不是无限累积摘要；
- 为每条命题展示支持、反对、冲突和过期证据；
- 区分事实、预测、观点和假设；
- 显示证据日期、适用期间和来源；
- 新证据出现时说明它改变了哪条命题。

### 13.13 风险与证伪

- 按需求、行业、竞争、执行、客户、供应链、财务、会计、治理、监管、地缘、证券、估值和模型分类；
- 区分经营公司风险、具体证券风险和个人组合风险；
- 显示风险事件、暴露、传导路径、时间、可能性、影响、速度和可逆性；
- 分开展示毛风险、已验证缓释措施和剩余风险；
- 支持单变量敏感性、盈亏平衡、综合压力、反向压力、现金跑道和稀释分析；
- 展示客户、产品、地区、供应商、融资和关键人的集中风险及相关性；
- 分开基本面风险、估值风险、流动性风险和双重压力；
- 定义预警、情景偏离、核心证伪和生存/权利约束；
- 根据风险速度设置事件、月度、季度或里程碑复核；
- 显示风险相对上一快照的新增、升级、降级和解除；
- 冲突证据和永久损失风险优先显示，不能被正面材料或总分抵消。

### 13.14 催化剂与事件日历

- 记录财报、产品、审批、产能、价格、客户、政策、分红、回购和融资节点；
- 说明事件影响哪项经营假设；
- 区分已经发生、公司指引和外部预期；
- 事件过后复盘实际结果与原假设偏差。

### 13.15 研究快照与变化追踪

- 保存每个数据截止日下的分析状态；
- 对比前后两次的事实、预测、假设、估值和结论；
- 显示结论升级、降级或失效的原因；
- 支持回看当时可见的信息，避免用未来信息解释过去决定；
- 对过期内容明确标记而不是静默覆盖。

### 13.16 数据覆盖与研究缺口

- 分别显示公司、财务、行业、预测、估值、治理和市场数据覆盖；
- 明确缺失、过期、冲突、来源异常和口径不可比；
- 告诉用户缺口影响哪个判断；
- 给出下一步需要补充的资料或验证问题；
- 不把缺口显示成“没有风险”。

### 13.17 用户研究与交易边界

- 用户可以记录关注原因、个人判断和待验证问题；
- 用户决定应明确标记为个人内容；
- 公司分析可以被持仓或交易计划引用，但不自动生成交易动作；
- 同一公司分析可以服务不同用户和不同证券，个人仓位不能反向改变公共事实。

## 14. 事实数据需求与可得性

本节描述形成分析所需的事实输入，不等同于接口或数据库设计。可得性结论基于 2026-08-04 对当前仓库数据所有者的检查，以及对 `300308.SZ`、`00700.HK`、`NVDA.US` 的生产只读样本核验；上游状态会变化，后续仍需按来源健康和数据日期复核。

### 14.1 分类规则

可得性状态：

| 状态 | 含义 |
| --- | --- |
| V 已验证可得 | 当前产品路径和代表性样本均能返回可用数据，仍需保留来源和日期 |
| P 部分可得 | 仅部分市场、期间或字段可得，或代理来源可用但不足以支撑完整结论 |
| N 需要新增来源 | 外部通常存在可靠来源，但当前产品没有稳定、结构化的获取路径 |
| M 文档提取 | 主要存在于财报、公告、电话会或研究材料中，需要逐份提取和口径校验 |
| U 不可靠或不可得 | 公司未披露、来源授权受限、定义不一致或当前无法形成可信序列 |

认识类型：`F` 已观察事实，`G` 管理层指引，`E` 第三方预测，`X` 代理变量，`A` 自建假设，`D` 由事实按明确公式计算的派生观察。`D` 不是来源事实，`A` 不是预测共识。

“首选来源”表示最终事实应尽量锚定的来源；“当前可得性”表示本项目今天已经具备的能力，两者不能混为一谈。第三方聚合数据即使当前可用，也应在关键结论处用公司或监管原始披露交叉验证。

可得性必须落到“事实要求 × 经营公司/上市证券 × 报告期或交易日 × 来源”判断，不能只给某个数据源一个永久的全局状态。接口成功但关键字段为空、只有旧期间、单位不明或口径不可比，仍然属于部分可得或不可得。

### 14.2 财务三表的来源决策

财务数据区分“运行时主结构化源”和“法定复核源”。前者用于形成可计算的统一报表序列；后者用于核验重大差异、重述、附注和关键判断。任何聚合源都不替代法定披露。

| 市场 | 主结构化源 | 法定复核源 | 选择理由 | 不采用的自动方案 |
| --- | --- | --- | --- | --- |
| A股 | 东财 | 公司定期报告、交易所/CNINFO | 现有路径和字段映射已存在，能服务 A 股财务分析 | 不切换到 Yahoo |
| 港股 | 东财 | HKEXnews 年报/中报/业绩公告 | 东财港股 F10 已有财务分析入口，预期可提供更接近完整三表和本地化字段；与 A股统一，直接访问稳定性也优于当前 Yahoo 试验 | 不把 Yahoo 作为港股三表自动主源或自动回退源 |
| 美股 | Yahoo（本地经代理，生产可直连） | SEC EDGAR 的 10-K、10-Q、20-F、6-K 和公司 IR | 用户已指定 Yahoo；其全球代码和季度聚合口径适合美股统一入口，本地代理解决开发环境访问限制 | 不用东财替代美股三表，也不自动切换来源 |

港股选择东财是产品源选择，不是对数据准确性的预设。实施前必须对至少三类港股公司（普通经营公司、金融公司、红筹/多币种公司）验证利润表、资产负债表、现金流、财报期、币种、公告日和历史深度；任一关键字段缺失时标为缺口并以 HKEX 原文核验，不能静默切换到 Yahoo。

### 14.7 财务与估值派生指标的最小输入

派生指标不需要另找一个“指标来源”，而应优先从可追溯事实复算。只有下面的最小输入齐全且口径一致时，才输出对应指标：

| 派生指标 | 最小事实输入 | 关键口径 | 缺失处理 |
| --- | --- | --- | --- |
| 收入/利润增长、CAGR、毛利率和营业利润率 | 同口径利润表、报告期、重述版本 | 单季/累计、并表、币种、持续经营 | 任一期关键值缺失则该比较不可得 |
| OCF、FCF 和现金转换率 | 经营现金流、资本开支、归母利润 | 金融公司不适用通用 FCF；维护/扩张无法拆分时使用总资本开支并说明 | 现金流量表缺失则不可得，不以 EBITDA 替代现金流 |
| DSO、DIO、DPO 和现金转换周期 | 期初期末应收/存货/应付、同期收入和营业成本 | 使用平均余额、期间天数和一致的相关科目范围 | 缺期初、成本或科目口径时不可得 |
| ROE、ROA、ROIC 和增量 ROIC | 归属利润或 NOPAT、平均权益/资产/投入资本、税率 | 平均余额、商誉、租赁、在建工程和超额现金调整 | 投入资本无法定义时不输出 ROIC |
| 净债务、杠杆和利息覆盖 | 现金及受限资金、各类有息/类债务、利息和利润 | 租赁、担保、表外承诺与短长期拆分 | 只看到总负债不能计算净债务 |
| 稀释 EPS、每股 FCF 和每股净资产 | 归属普通股股东的分子、稀释等价股数 | ADR 比例、期权/RSU/可转债和股份类别 | 稀释股本缺失则每股指标不可得 |
| 市值、EV、PE、PB、EV/EBITDA 和 FCF 收益率 | 同日价格、稀释股本、净债务、少数股东及相应财务分母 | 基准日、币种、TTM/Forward、正常化和企业/股权分子匹配 | 不从已有倍数反推缺失的股本或财务值 |
| 股息、净回购和股东收益率 | 实付分红、回购、增发/SBC、基准市值 | 宣告与实付、注销与库存股、税前/税后 | 只有回购公告而无实际股数变化时不可得 |
| 银行 PB-ROE 与资产质量 | 平均净资产、归属利润、净息差、不良/关注、拨备、信用成本、资本充足 | 银行口径、风险加权资产和监管分类 | 缺资产质量或资本数据时不因低 PB 输出便宜 |
| 保险 P/EV 与新业务价值 | 内含价值、新业务价值、偿付能力、投资和承保结果 | 公司披露方法、假设变更和权益归属 | 不能用普通账面净资产替代内含价值 |
| Forward 指标与预测误差 | 带发布日期的预测、同日价格/市值、后来同口径实际值 | 预测期间、币种、基本/稀释、GAAP/non-GAAP | 来源、版本或实际口径缺失时不可得 |

### 14.8 当前产品数据能力结论

| 能力 | 当前结论 | 产品需求含义 |
| --- | --- | --- |
| A/H/美股证券识别 | 当前代码规则覆盖 `dddddd.SH/SZ/BJ`、`ddddd.HK` 和 `TICKER.US` | 可作为统一入口，但仍要补股份类别、币种、ADR 和同一经营主体映射 |
| 三地日线与估值观察 | 生产样本均返回 Xueqiu 日线，包含价格及若干 PE/PB/PS/PCF 字段 | 可支撑市场状态和估值观察；来源失败要显式，不新增股票 K 线替代源 |
| 市值与股本 | A股样本有市值；港股和美股样本市值为空，当前股本能力主要偏 A股 | 港美 EV、每股价值和跨市场比较应标为阻断，不从价格或 PE 反推股本 |
| 正式三大财务报表 | A股东财路径可返回多期数据，但部分公司存在现金流量表等单表为空；港股东财为已选待验证来源；美股 Yahoo 已接入（本地经代理、生产可直连），当前仅有部分公司和期间的 Yahoo→SEC 核验样本 | A股先逐表显示覆盖状态；港股按东财验证；美股继续验证生产直连、字段和历史深度并以 SEC 抽样对账，任何市场都不能因另一张报表存在就宣称三表完整 |
| 公司公告 | A股、港股样本通过 CNINFO 返回；美股样本通过 Eastmoney 返回 | 列表可用，但美股关键事实应补 SEC EDGAR 原始文件，港股应能回到 HKEX/公司原文 |
| 公司研报与预测 | 当前公司研报聚合和结构化预测路径限定 A股，来源包括 Eastmoney、Sina 和匹配知识文档；信息预处理可保存来源绑定预测记录 | 可用本地大模型形成带证据的多研报整理草稿，并在口径确认后汇总已纳入样本；不能称完整一致预期，港美仍需新来源或文档导入 |
| 公司业务、分部、治理、指引 | 主要散落于财报、公告、研报和知识文档，没有稳定结构化事实集 | 先按 M 状态逐份提取并保留证据，不把信息处理结果直接升级为系统判断 |
| 行业空间、份额和专属 KPI | 取决于行业协会、商业研究和公司/同行披露，尚无统一行业档案数据 | 必须按赛道建立来源清单和口径，无法用一个通用行情源解决 |
| 汇率与宏观 | 已有部分官方宏观序列，但尚未与公司报表和证券估值形成统一换算基准 | 跨市场比较先显示原币；换算视图必须绑定日期和汇率来源 |

### 14.9 来源优先级、冲突与缺失规则

事实来源优先级一般为：监管/交易所法定披露与审计财报，公司正式经营披露，交易所行情和官方统计，客户/供应商/竞争对手正式披露，有方法说明的第三方数据库或研究，媒体和渠道线索。优先级高不代表绝对正确；财报重述、监管更正和同口径多源差异都要保留版本。

每条事实至少记录：对象、指标定义、值、单位、币种、期间、是否累计、会计口径、发布时间、数据截止日、原始来源、来源类型和质量状态。派生观察还要记录公式、输入事实、调整项和计算时间；预测和指引还要记录预测者、发布日期、适用期和条件。

冲突处理规则：

1. 不自动平均冲突值；
2. 先检查期间、币种、累计/单季、基本/稀释、公司/分部和重述版本；
3. 能解释的差异保留口径映射，不能解释的差异保持“冲突”；
4. 低优先级来源不能静默覆盖高优先级原始披露；
5. 来源事实缺失时，可以建立明确标记的代理变量或情景假设，但不能把它回写成事实；
6. 每个缺口必须绑定受影响模块、被阻断结论、补充来源和复核负责人。

## 15. 页面应呈现的核心结果

不建议使用一个总分。页面至少应分别展示：

1. **资料完整度**：完整、部分、待补、冲突、过期；
2. **业务质量判断**：优势、弱点、持续性和不确定性；
3. **竞争位置判断**：市场边界、相对位置、壁垒证据、持续期和侵蚀风险；
4. **财务质量判断**：增长、利润、现金、资产负债、资本效率和每股价值；
5. **盈利路径判断**：恶化、不稳定、可兑现、可能超预期；
6. **估值状态**：无法估值、缺少安全边际、合理、有一定安全边际；
7. **风险状态**：核心风险、压力损失、剩余风险、预警/证伪状态和永久损失可能性；
8. **市场状态**：价格、回撤、波动和流动性，仅用于辅助；
9. **下一步研究**：最需要补的证据、最近催化和复核日期。

顶层可以保留“资料待补、证伪复核、等更好估值、持续观察、优先研究”等研究工作流状态，但必须明确它们不是买卖评级。

## 16. 页面功能分区建议

不讨论具体界面实现时，页面至少需要这些功能区：

1. **研究摘要**：公司、证券、市场、主营赛道、估值原型、数据截止日和关键结论；
2. **业务与驱动**：商业模式、分部结构、驱动树和竞争优势；
3. **市场空间与份额**：TAM、SAM、SOM、份额桥、利润池和上下校验；
4. **财务质量**：关键财务指标、利润桥、现金转换、营运资本、资产负债、资本效率和每股价值；
5. **管理层、治理与资本配置**：可信度校准、控制权、激励、关联交易、资金去向和增量回报；
6. **市场差异**：A股、港股、美股或 ADR 的特有结构和风险；
7. **行业/赛道**：需求、供给、周期、行业 KPI 和同行；
8. **竞争与壁垒**：竞争市场、对手矩阵、优势命题、财务验证、持续期和侵蚀路径；
9. **重点公司档案**：专属 KPI、研究命题、管理层记录和事件日历；
10. **预测与估值**：来源预测、自建情景、反向估值和敏感性；
11. **风险与证伪**：核心风险、传导路径、压力测试、剩余风险、冲突证据、触发条件和复核动作；
12. **证据与缺口**：原始来源、信息类型、覆盖状态和待补问题；
13. **变化与复盘**：历史快照、假设变化、预测修订和结论变化；
14. **个人研究区**：用户笔记、关注状态和对外部交易计划的引用。

## 17. 典型边界场景

### 17.1 同一公司 A/H 两地上市

- 经营分析共用；
- A股和H股分别计算股本、市值、股息率和估值；
- 解释流动性、投资者结构、汇率和股东权利差异；
- 不能只因 H股折价就输出更值得买。

### 17.2 中概股 ADR

- 经营公司、境外控股主体和 ADR 权益分层展示；
- 处理 ADR 比例、存托费用、VIE、审计和跨境监管；
- non-GAAP 结果必须与 GAAP、SBC 和稀释共同展示。

### 17.3 周期顶部低 PE

- 通用层识别利润和现金流很好；
- 行业层识别价格、库存和产能处于高位；
- 估值使用正常化盈利而不是当前峰值；
- 结论可以是“当前盈利强，但中周期安全边际不足”。

### 17.4 未盈利创新公司

- 通用层仍检查治理、现金、竞争和稀释；
- 行业层使用里程碑、成功概率和商业化指标；
- 估值明确为概率调整或现金跑道；
- 无法估值时保持“区间极宽/资料待补”，不回退到 PE。

### 17.5 多业务公司

- 确认主要盈利驱动；
- 各重要分部加载适合的行业分析；
- 使用 SOTP 时处理总部成本、净负债和少数股东；
- 防止同一价值在多个分部重复计算。

## 18. 需求优先级

### 第一优先级：没有就不能形成完整分析

- 经营公司与上市证券分离；
- 通用公司分析；
- A股、港股、美股市场差异；
- 主营行业/赛道档案；
- 竞争市场、竞争对手、壁垒机制、财务验证和侵蚀路径；
- 财务质量和现金流；
- 与商业模式匹配的关键财务指标、异常识别和每股价值分析；
- TAM、SAM、SOM、公司份额和利润池测算；
- 三情景、估值原型和反向估值；
- 核心命题、证据、风险、证伪和数据缺口；
- 风险台账、相关性、压力测试、预警、核心证伪和永久损失识别；
- 三地法定披露、财务报表、股本与证券权利的事实覆盖；
- 事实数据字典、来源、口径、时效、可得性和“缺失阻断结论”规则；
- 基础、标准、深度三种研究层级及模块依赖和完成规则；
- 数据截止日和历史快照。

### 第二优先级：显著提高研究效率和深度

- 跨市场同行比较；
- 重点公司档案；
- 预测分歧和修订；
- 催化剂日历；
- 前后分析变化和复盘。

### 第三优先级：与个人投资流程连接

- 用户关注、笔记和研究任务；
- 与持仓、集中度和交易计划关联；
- 研究结果被个人计划引用，但继续保持事实、判断和行动分离。

## 19. 待讨论决策

### 19.1 本稿已经确定的产品选择

- 重点公司可以由持仓、关注和研究频率提出候选，但是否进入重点档案由用户确认；
- 行业档案默认使用主营二级赛道，专属 KPI 确有差异时再挂载更细、可版本化的研究子赛道；
- 一个重要分部只有在对收入、利润、资产、资本开支、风险或估值任一项具有实质影响且能避免重复计值时，才单独加载行业档案；
- 顶层分别显示研究工作流、业务质量、财务质量、估值和风险状态，不设置一个综合总分；
- 跨市场默认展示原币，同时允许统一币种比较；任何换算都绑定汇率来源和日期；
- 财务三表的主结构化源确定为：A股东财、港股东财、美股 Yahoo；美股 Yahoo 本地经代理访问、生产环境可直连并缓存；法定原文分别作为重大差异、重述、附注和关键判断的复核源，不设置自动源切换；
- 公司页只读引用个人持仓和交易计划，个人数据不改变公共研究事实；
- 来源信息、派生观察、分析判断和用户决定由不同对象承载，来源信息处理不负责生成投资结论。

### 19.2 仍需用户确认的范围选择

以下问题会实质改变数据成本、第一阶段范围或产品责任，暂不自行假定：

1. 第一阶段是优先把 A股做成“标准/深度可用”，再补港美正式财报，还是从第一阶段就要求三地同时达到“标准层”；
2. 是否接受购买或接入有授权的商业数据，用于完整一致预期、行业 TAM/份额和部分专属 KPI；若不接受，这些能力将以公开披露和手工研究为主，覆盖不可能稳定齐全；
3. 系统是否可以基于明确证据生成“分析判断草稿”，还是只能展示事实、派生指标和用户亲自写的判断；
4. 是否允许用户上传或本地导入有使用权的研报、电话会和行业材料，作为港美预测及行业数据的重要补充；
5. 第一批用于验收的行业与重点公司组合，需同时覆盖至少一个 A/H/美股、一个多地上市、一个金融或周期公司，以及一个未盈利或多元公司。

## 20. 需求验收标准

在讨论完成后，这套需求应满足：

- 能明确区分经营公司和具体上市证券；
- 同一套通用分析可以覆盖 A股、港股和美股，同时保留市场差异；
- 能按基础、标准和深度三种层级判断完成状态，且后置结论受前置事实约束；
- 银行、周期、成长、稳定现金、未盈利和多元控股公司不会被强制使用同一估值；
- 商业模式能够落到合同、定价、单位经济、增长约束和财务传导；
- 通用公司能够看到增长、利润率、现金、营运资本、偿债、资本效率和每股价值，金融及其他特殊行业使用适配指标；
- 管理层能力、可信度、治理、利益一致性和资本配置不会被合并成一个模糊评分；
- 行业专属指标能够解释行业如何进入公司财务，而不是只显示标签；
- 每项竞争优势和壁垒都能说明市场边界、客户价值、复制难点、经营/财务证据、持续期和证伪条件；
- 普通公司无需重点档案也能形成完整基础分析；
- 重要公司可以增加专属驱动、KPI、命题和风险，同时保持跨公司可比性；
- 事实、预测、观点、假设、系统判断和个人决定不会混在一起；
- 每项事实需求都能说明来源、交叉来源、频率、认识类型、当前可得性和缺失影响；
- 港股或美股正式财报、股本等关键数据缺失时，相应财务与估值结论保持不可得；
- 管理层、第三方和自建预测保留历史版本，并能与后来实际结果按同口径校准；
- 估值能从经营假设走到财务预测、企业价值、股权价值和具体证券每股价值；
- 每个重要结论都有数据截止日、证据、反证和复核时间；
- 每项核心风险都能说明暴露、传导、损失范围、速度、可逆性、缓释、剩余风险和触发动作；
- 缺失、冲突、过期和不可比不会被总分掩盖；
