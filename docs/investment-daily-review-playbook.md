# A股优先的98家公司观察池：每日研究与策略复盘流程

> 策略生效：2026-10-27。本文用于**按需人工触发的每日复盘**，不是定时任务，也不代表2026-10-27已经完成当天的98家公司新闻核验、定价或可交易买卖建议。

## 1. 投资目标与市场预算

- 目标：持有20–30家公司，参考组合25个席位；覆盖多种商业模式，绝不为了补齐一个行业而购买缺乏竞争优势或估值失当的股票。
- 研究主场：A股。当前主观察池98家公司，**首选研究证券为A股78家、美股15家、港股5家**。多地上市公司只计一次，A/H/ADR不自动等价。最新数量始终以 `config/investment-universe.json` 为准。
- 25席位研究预算：**A股21、美股3、港股1**（示例而非实际资产或必须满足的比例）；资金权重参考A股84%、美股12%、港股4%，只用于设计和穿透风险统计。A股与海外资金池分别持有和交易，**不得假设可以自由移仓**。
- 最大观察公司数100；当前备选清单 `docs/archive/investment-universe-deferred-2026-10-27.json` 不纳入每日覆盖。被移出并非评级下降、利空或卖出建议。
- 需单独衡量AI算力资本开支、半导体周期、中国消费、商品价格、利率、监管和外汇等共性因子。美股数量少不等于总风险少；A股光模块、存储、PCB也可能高度同向。

## 2. 研究资产与隐私边界

| 资产 | 性质 | 是否公开前端消费 |
|---|---|---|
| `config/investment-universe.json` | 长期研究主数据：公司/赛道/首选上市证券/研究层级 | 是 |
| `config/investment-daily-report.json` | **公开、非个性化**每日来源核验与研究候选快照 | 是，需重新构建前端 |
| `docs/宽基式优质公司组合_细分赛道与98家观察池_2026-10-27.md` | 历史初版研究快照 | 否 |
| `docs/archive/investment-universe-deferred-2026-10-27.json` | 移出主观察池的历史备选；原ID保留 | 否 |
| 每天在对话里给投资者的实际调仓建议 | **私人组合决策**：持仓、资金账户、成本、数量、税费、价格容忍度 | **不得写入公开JSON或网页包** |

**最重要：** 对于“将持仓A换成B”的个人操作，必须重新确认当次实际持仓、交易市场、资金池、成本和同一风险因子敞口；不允许从公开观察池或历史持仓猜测当前仓位。如果无法核对，仅列出“值得比较的候选替换”，不是立即操作指令。

## 3. 每次人工发起后按顺序执行

1. **冻结快照**：读取当前98家公司、ID和最新一份每日报告，记录交易所所在时区的最新交易日；A股收盘日和美股收盘日分别记录，不把北京时间“今天”混为美股交易日。
2. **证据优先**：按公司公告、交易所披露、SEC/港交所、财报、业绩说明会、投资者关系材料、可核验行业数据及有来源的新闻排序。新闻与传闻标注“尚待一手资料验证”。行情/K线遵循仓库 `AGENTS.md` 的**仅雪球**约束；无对应日期价格不构造PE或收益率。
3. **事件覆盖**：对98家先作增量检查，逐家记录检查日期、来源链接，报告 `checkedCompanyIds` 和 `coverage.checks` 必须一一对应。无法可靠获取来源的公司写 `unavailableCompanyIds` 并解释原因，不允许将“没有新消息”当成“已核验没有变化”。只有98家都完成证据检查才能使用 `complete`；否则 `partial`。
4. **重点加深**：对重大财报/指引变化、客户/竞争/供应链变化、估值进入安全边际的公司以及个人当前持仓，深入检查分部利润、盈利质量、资本回报和市场预期。
5. **评价价值**：按公司本业使用可比较估值方法，区分银行、保险、资源周期、成长制造业、软件与REIT。记录同一上市证券的价格日期、货币、保守价值区间、盈利假设、安全边际及交易权利缺口。
6. **形成研究动作**：`consider_buy`（买入候选）、`consider_add`（增持候选）、`research_hold`、`consider_trim`、`consider_exit`、`watch`、`insufficient_data`。**新增/增持候选必须有当日或标注日期的价格、保守价值区间与可点击来源**，否则降级为 `watch` / `insufficient_data`。
7. **比较换仓机会**：只对明确的“两家公司”比较预期回报、永久损失风险、现金流、估值、交易成本和共同风险因子。公开档案必须标注 `portfolioPositionConfirmed=false`，不能说“已确认卖出持仓”；个人实际换仓仅在对话里核对资金账户后提出。
8. **估值区间变化**：先跑 `npm run snapshot:valuation-bands`，它采集当日区间快照并与上一份对比。**输出必须按归因读**：`filing` 是公司披露了新报告，`model` 是我们改了默认倍数（**不是**公司变化），`price_source` 是行情源故障（**不是**估值变化），`unattributed` 需人工查清。把 `model` 项当成公司新闻是最容易犯的错。
9. **落盘、校验、展示**：更新 `config/investment-daily-report.json`；若确有公司名单/赛道更新，另改 `config/investment-universe.json` 并保持稳定ID。执行 `npm run check:all && npm run build:web`，网页 `/investment-universe.html` 展示最后一份报告；不自动部署、不自动买卖。
10. **复盘留痕**：复制 `docs/investment-daily/TEMPLATE.md` 为 `docs/investment-daily/YYYY-MM-DD.md` 并填写。不能用同名文件静默覆盖旧日证据、不能重复报道没有实质性变化的新闻。校验：`npm run check:daily-notes`。

## 4. 投研判断的最低证据条件

每条有方向性的建议至少包含：
- 最新一手事实、发表日期及公开原文URL，明确**哪些已经核验，哪些是传闻或推断**。
- **市场预期 → 最新事实/边际变化 → 未来净利润或自由现金流变化 → 估值可能如何重定价**。
- 财务质量、行业景气与竞争优势的失效条件；至少一种不利情景及对应的风险传导路径。
- 价格及估值观察的**同一证券、时间点和币种**。没有源数据时写“缺失”，不能补数字、不能把ADR直接当作A/H股估值。
- 动作与确定性分离：研究判断即使是“可考虑买入”，也不等于“现在可以交易”。需要账户资金/流动性/仓位/税费确认。

## 5. 每日JSON接口契约

`config/investment-daily-report.json` 中的：
- `status`: `not_reviewed` / `partial` / `complete`；
- `reportDate`: `YYYY-MM-DD`；`generatedAt`: ISO时间戳；`universeAsOf`: 必须与观察池版本日期一致；
- `coverage.checkedCompanyIds`: 已检查公司ID；`coverage.checks`: 同公司ID的逐项证据，示例 `{"companyId":"co-0001","checkedAt":"2026-10-27","sources":[{"title":"公司公告标题","url":"https://example.com/filing","publishedAt":"2026-10-27","kind":"issuer"}]}`；`coverage.unavailableCompanyIds`: 无法获取可靠来源的ID；
- `materialChanges`: 公司ID、事件日期、具体变化、预期差、潜在利润与估值影响、不确定性、一手来源；
- `assessments`: 公司ID、`action`、判断日期、投资逻辑、预期差、风险、待验证点、证据、估值（买/加必填）；
- `rotationComparisons`: 两家公司的**假设性**替换比较和来源，不能公开真实个人持仓；
- `gaps`: 当前证据缺失、交易可达性与需要复核的问题。

**估值区间变化的归因约定**（P3-1 起）：区间变化不进公开 JSON，而是写在
`docs/investment-daily/YYYY-MM-DD.md` 的「估值区间变化」一节，每条必须标
`filing` / `model` / `price_source` / `unattributed` 之一。理由：公开 JSON 是
当日快照，而"为什么变"需要跨日对比才能确定；把归因写进快照会诱使读者把
我们自己的参数调整读成公司新闻。

所有对外链接须使用HTTPS；判定 `complete` 需要98家公司全部有逐条检查证据；若缺失则如实标记 `partial`。

## 6. 固定每日答复结构

每次在聊天中请按以下顺序报告，尽可能使用公司公告原文链接：

1. **本次更新概况**：时间截止点、A股/美股交易日、实际核查数量、无法核查公司。
2. **新增的关键事实（只报增量）**：公司、发布日期、变化、相对预期差、对盈利与估值的影响。
3. **当下值得研究的新增/增持候选**：不超过5家，分别给出价格/保守价值估计、理由、风险、安全边际、交易条件；缺少关键数据就不能判“可买”。
4. **当前持仓的持有/减仓/退出复核**：必须确认个人真实持仓与资金账户，不依赖共享JSON。
5. **替换对比**：从哪个已确认的持仓切至哪只候选、两者未来收益差、机会成本、交易摩擦和同因子暴露，资金不可互通时不得给出直接移仓指令。
6. **还要验证什么**：清晰标识证据缺失、尚未证明的行业叙事、需要下一期财报验证的问题。
7. **变更记录**：新增/移出观察池、研究等级变化及其来源；没有新事实可以明确输出“无实质变化”，不编造动作。
