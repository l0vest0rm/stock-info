### 故障与恢复

- 研报发现生成期间重启隔离后端：同一 UUID/checkpoint 续接，没有重新输入/发送。
- 投资默认强度执行触发五分钟只读重开：由 SDK 判断 cursor 安全性，重新打开原
  conversation，随后完成同一执行。恢复不使用主机自行推进的 cursor。
- 研报 JSON 曾被 Markdown 转义和 URL 转换破坏：改从 SDK 原始 DOM 文本解析。
  修复后只从经过校验的原完成凭据重新物化，6 篇成功入库，没有再次调用模型。
- 较低强度的真实投资/宏观回答缺少章节，被原业务校验拒绝；未放宽校验。
  修正业务拒绝后仍显示运行中/反复投影的问题：保留 SDK 成功事实，业务状态独立
  标记失败，相同 revision 不再反复写入；显式恢复后才允许重新物化。
- 取消只停止本地后续动作；真实 API 返回 `providerRequestRetracted:false`，不声称
  撤回已提交请求。早期发送结果不确定的会话保留，没有自动重新发送。
