# 宏观目录与来源接入 TODO

## 目标

将 [宏观指标分类体系](./宏观指标分类体系.md) 的九类、60 项定义落到现有两表宏观模块：修正目录身份和展示测度边界，补齐 FRED/BLS 美国高频层与固定 IMF WEO 年度国际比较层，并保留未验证的地区高频指标为可诊断未映射状态。

本 TODO 不接入 DBnomics IFS/WDI/OECD 可变快照，不新增数据库表，不部署生产。所有开发完成后由协调者统一验证；开发过程中只做必要的编译/静态检查，不以局部测试宣布完成。

## 稳定前置契约

```text
metric_id       = 九类、60 个原始经济概念之一
definition_id   = 同一 metric 的频率、季调、覆盖范围、来源/发布批次差异
indicator_id    = 一个地区 + metric_id + definition_id 的具体原始序列
display measure = 基于原始序列和同一 asOf 的查询期计算结果
```

WEO 仅接受 `IMF/WEO:YYYY-MM` 固定发布批次，目录的 `source_batch_key` 必须保存验证过的官方发布日期。该批次仅写入已结束年度，绝不写入其预测期。FRED 只能在配置 `FRED_API_KEY` 时通过 API 写入带 `realtime_start` 的版本化观察。
