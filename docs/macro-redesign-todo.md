# 宏观通用目录页面重构 TODO

## 目标与完成定义

将 `/macro.html` 建设为**数据驱动的宏观指标浏览器**，而非中美固定双列表格。首次建设完成后，新增国家/地区、新分类、新指标或新统计口径时，只新增目录元数据、来源映射和原始观测值；不得再修改页面、通用 API、数据库物理表或静态指标常量。新来源需要新增采集适配器属于允许的数据接入工作，但不得借此改写展示框架。

页面必须支持：

1. 动态国家/地区多选、分类筛选与指标搜索；
2. 单地区概览和多地区对比两种视图，比较列由所选地区动态生成；
3. 每项具体序列展示当前值、同比、环比、统计期、发布日期、新鲜度和缺失状态；
4. 迷你趋势与按需加载的详情趋势图；
5. 原始值、首次发布、修订版本和 `asOf` 回放保持无前视一致性。

完成时，宏观物理表仍只有 `macro_indicators` 和 `macro_data`。`macro_data` 永远严格为 `(indicator_id, period_day, published_at, value)` 四个数值字段；派生值、国家/分类/指标文字、来源、质量状态均不得写入历史事实表。

## 已确认的领域契约

- **通用指标（metric）**：跨国家/地区可比较的经济概念，例如 CPI 或政策利率；由 `metric_id` 标识。
- **具体序列（series / indicator）**：一个地区、一个通用指标、一个统计定义的原始观测序列；由 `indicator_id` 标识。不同地区或口径绝不覆盖同一序列。
- **统计定义（definition）**：季调、覆盖范围、原生量纲等决定可比性的口径；不相同就创建新的具体序列。
- **当前值**：默认 `asOf=now` 下、统计期最新且当时已发布的原始值；必须同时显示统计期与发布时间。
- **同比/环比**：查询时计算的展示测度，绝不落库。每个具体序列必须声明计算方式、基期规则和不适用原因。原生同比率不得再计算“同比的同比”；利率等比率通常显示百分点变化而不是相对百分比。
- **趋势**：同一 `asOf` 下按窗口取得的同口径时间序列；概览只能获取有限摘要，完整历史只能在用户打开详情后按需读取。

## 两表目录策略与边界

项目规则要求未经单独授权不得新增表，且既有宏观设计已经确认两表模型。因此本轮不增表：`macro_indicators` 承担可运营的目录元数据，`macro_data` 保持窄事实表。

为避免未来扩展改代码，`macro_indicators` 必须能够提供或推导下列数据驱动元数据：地区代码/显示名/排序，分类代码/显示名/排序，通用指标代码/显示名/说明/排序，具体统计定义、频率、单位与格式，季调状态，原生测度语义，同比/环比计算规则、基期与显示格式，趋势默认窗口，以及来源与新鲜度策略。少量地区、分类、指标元数据在小目录表中重复是接受的代价；接入校验必须拒绝同一身份下彼此冲突的目录声明。

若将来要求完全规范化的地区、分类或指标维度表，必须先取得“新增数据库表”的明确批准，并另行设计迁移；它不属于本 TODO。

旧市场雷达的 JSON 历史、事件、预警和回测表属于已退休功能，不迁移到新事实表；新目录只允许由已验证来源重新回填。另一方面，已经进入 `macro_data` 的原始发布/修订记录必须由后续目录演进迁移完整保留，不能因扩展国家、分类或指标而丢失。

## 稳定接口契约

```text
GET /api/macro/catalog
  -> regions[] / categories[] / metrics[] / series[] / capabilities
  -> 全部数据从目录派生；不得返回 CN/US、8 类或 60 项的编译期假设。

GET /api/macro/overview?regions=...&categories=...&asOf=...
  -> 一个 concrete series 一项：current、yoy、mom、freshness、availability、trend 摘要。
  -> 派生测度必须返回 value、basePeriod、method 和 status/reason。

GET /api/macro/series?ids=...&measure=level|yoy|mom&from=...&to=...&asOf=...
  -> 限定具体序列与时间窗口；先应用 asOf 的版本选择，再计算测度。
```

`catalog` 只传目录和可见能力；`overview` 不得读取完整历史来取得最新值；`series` 只由详情或可见趋势窗口触发。所有筛选、排序、列数和文案均取 API 元数据，前端不得再用地区、分类或指标常量推断。
