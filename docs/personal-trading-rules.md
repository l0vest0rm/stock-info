# 个人股票交易规则（执行版）

> 状态：执行中并持续验证；版本：3.7；最后更新：2026-08-01
>
> 适用范围：本人可交易的 A 股、港股、美股普通股票与 ETF。本文只记录当前下单、持有和复盘时应遵守的规则，不构成对他人的投资建议。
>
> 使用方式：只有标为“已确认”或“实施中”的内容可用于执行；“待确认”只用于记录和研究，不得把它当作已验证的交易优势。形成过程、回测、敏感性测试、已撤回方案和完整版本记录见[研究与决策归档](personal-trading-rules-research.md)。

## 1. 规则状态与优先级

| 状态 | 含义 |
| --- | --- |
| 已确认 | 由个人账户、目标或风险偏好直接决定的约束，立即执行。 |
| 实施中 | 已有明确执行路径和有限证据，但仍须保留样本外记录；不能解释为普遍有效。 |
| 待确认 | 尚无足够个人决策或证据支持；只记录，不据此自动下单。 |

发生冲突时，固定按以下优先级处理：**紧急退出与逻辑证伪** → **集中度复核** → **组合回撤防守** → **资产桶轮动** → **普通计划性执行时间**。低层规则不得覆盖高层规则。

## 2. 已确认的目标、边界与账户规则

- 目标是以滚动 1--3 年为主要评估窗口，追求较高收益；全部可投资金融资产的最大回撤风险目标为 40%以内。
- 40%是合并组合的风险目标和复盘红线，不是单只股票允许下跌的幅度，也不保证未来不会穿透。
- 不使用融资、杠杆、做空或期权；投资资金须与应急资金及未来 1--3 年确定用途的资金分开。
- 每笔交易均须说明类别、逻辑、集中暴露和退出条件；现金和不操作都是有效选择。

### 2.1 两个资金池

| 资金池 | 占总投资资产 | 可投资范围 | 必守边界 |
| --- | ---: | --- | --- |
| 国内资金池 | 90% 以上 | A 股、港股通范围内港股 | 不假设可调往国际证券账户。 |
| 国际资金池 | 不到 10% | 美股、非港股通港股及账户实际支持标的 | 不依赖国内资金补仓或补充现金。 |

- 两个资金池分别管理现金、建仓计划和流动性；同时按合并后的可投资金融资产管理回撤和集中度。
- 国内资金池不预设 A 股与港股通的比例；新资金以公司未来 1--3 年的预期收益、下行风险和研究确定性分配，不为维持市场比例而交易。
- 同一公司的 A/H 股或其他上市股份合并为同一公司风险，不作为分散持仓。港股通还须检查资格、交易日、额度、结算汇率、分红税费及被调出后的可买入性。

## 3. 组合与集中度

### 3.1 当前资产桶（实施中）

当前完整资产集合为股票、低信用风险人民币利率债、现金及货币类；黄金当前目标权重为 0%。初始配置为：

| 资产桶 | 初始权重 | 执行含义 |
| --- | ---: | --- |
| 成长股票 | 50% | 成长型个股或可交易的成长指数工具；仍受估值和集中度约束。 |
| 红利股票 | 20% | 红利型个股或可交易的红利指数工具；与成长桶合计为 70% 股票。 |
| 人民币利率债 | 20% | 低信用风险人民币利率债；不用信用债冒充防守资产。 |
| 现金及货币类 | 10% | 流动性和计划内再平衡资金，不因短期收益低而预先投入股票。 |

这是一项已有第一轮历史回测、尚未完成样本外验证的当前配置；不得据此提高 70%股票总仓，也不得将历史表现视为未来保证。详细数据、代理选择和局限见[研究与决策归档的 2.1 节](personal-trading-rules-research.md#21-整体资产配置第一轮数据讨论)。

### 3.2 资产桶月度轮动（实施中，仅限合格指数化工具）

1. 建仓日使用 50/20/20/10 初始配置。
2. 从建仓后的下一交易日起，在每月第一个交易日，比较前一交易日为止的成长桶与红利桶 20 日涨幅；相对强者占股票桶的 80%，弱者占 20%。股票总仓始终为 70%，即为成长 56%/红利 14%，或相反。
3. 价格下跌**不**自动把现金或债券划入股票；不设 10%、20%等跌幅加仓档位。
4. 轮动仅能作用于有明确、可交易、且能代表成长/红利桶的 ETF 或指数化工具。它不能直接对单一公司或主动股票篮子下单。
5. 每次轮动前必须通过集中度、基本面和回撤复核；组合回撤达到 30%后暂停自动轮动，先完成书面防守复核。实际工具、成本、税费、交易时间和跟踪误差若明显偏离回测代理，则只做纸面记录，不下单。
6. 每次记录信号日期、成交日期、两桶 20 日涨幅、轮动前后权重及交易成本。

### 3.3 已确认的集中度纪律

以下比例均按两个资金池合并后的**可投资金融资产总额**计算；同一公司合并计算，赛道、行业与主题/共同风险因子均按全部仓位重复计入，不可拆分抵扣。

| 口径 | 买入或加仓后的主动上限 | 被动越线处理 | 再平衡触发线 |
| --- | ---: | --- | ---: |
| 单一个股 | 15% | 未到触发线可持有，但不得继续增加该个股暴露。 | 20%，降回不高于15% |
| 单一赛道 | 20% | 未到触发线可持有，但不得继续增加该赛道暴露。 | 25%，降回不高于20% |
| 单一行业 | 25% | 未到触发线可持有，但不得继续增加该行业暴露。 | 30%，降回不高于25% |

- 每笔买入、加仓或再平衡前，均按预计成交后权重检查三层上限；超限时不执行增持，或先同步降低同层暴露。
- 被动越线仅指价格、分红再投资或其他资产净值变化造成的比例变化；超过再平衡线后，在下一个可执行的计划交易时段降回主动上限。涨跌停、停牌或流动性不足时记录原因，恢复交易后首个可执行时段处理。
- 集中度再平衡不等于否定公司基本面；若同时出现逻辑证伪、治理/财务风险或流动性危机，按紧急退出处理。

### 3.4 持股数量与候选池（待确认）

不得把回测中“20只等权”或“10股成长/红利组合”的表现当成任意自选股的正式最优持股数。自 2026 年第三季度起，真实或纸面组合应预先登记并跟踪 6 股、10 股、15 股和 20 只等权对照；研究覆盖不足时，降低股票总仓或缩小可投资池，而不是提高单股比例。

## 4. 个股决策与交易执行

### 4.1 投资风格（已确认）

- 以价值投资为主：收益来自未来现金流、盈利增长和买入价格相对保守内在价值的安全边际，而非追逐短期趋势。
- “便宜”不能只看低估值或已跌幅；必须同时检查盈利质量、资产负债表、治理、竞争优势、行业周期和资本配置。
- 股价上涨本身不是买入理由；股价下跌本身既不是卖出理由，也不是自动加仓理由。
- 卖出依据限于逻辑证伪、内在价值下调、价格明显透支保守价值、仓位或相关风险超限，或显著更优的风险收益机会。

### 4.2 开仓与加仓（已确认）

首次买入前，交易记录必须回答：标的和收益来源、事实与估值假设、2--4项可观察的逻辑证伪条件、目标仓位和分批计划、交易后的集中暴露、退出方案、预计兑现窗口，以及使用的资金池和现金是否充足。

- 默认分 2--3 次建仓，每一笔数量和触发条件在首次买入前确定。
- 加仓必须同时满足：核心逻辑未被否定或得到更强验证、估值更具吸引力、集中度复核通过。
- 不以“摊低成本”“尽快解套”或连续急涨作为加仓理由。

### 4.3 卖出与止损（已确认）

| 情形 | 必做动作 | 执行时间 |
| --- | --- | --- |
| 财务造假可靠证据、审计/治理信任基础破坏、偿债或流动性危机、核心资产或经营资格永久丧失 | 原则上全部退出，不等回本。 | 开盘即可；盘中确认则立即执行。 |
| 买入前约定的核心验证指标明确失效 | 重估；没有足够安全边际则退出，否则按新的价值判断和集中度决定降仓。 | 当日或下一交易日 14:40。 |
| 竞争优势、盈利质量、行业景气或资本配置弱于预期 | 停止加仓，先降至原目标仓位的一半，五个交易日内完成复核。 | 下一次 14:40。 |
| 仅价格下跌、事实未变 | 继续持有；只有达到预设价值区间且组合风险允许时才按原计划分批买入。 | 不触发卖出。 |

- 买入后不得因亏损放宽、删除或改写证伪条件；不以成本或“回本”决定卖出。
- 对投资仓不使用统一的固定百分比止损；交易仓如保留，必须在入场前单独写明价格、趋势、事件或时间退出条件。

### 4.4 价格复核与周期/高波动股票（待确认的暂行纪律）

普通投资仓相对持仓加权成本下跌 10%时检查公告、财报、行业数据和原假设；下跌 20%时暂停加仓，并在两个交易日内重估保守价值、悲观情景和相关暴露；下跌 30%时从零重写持有理由，五个交易日内形成持有、减仓或退出结论。复核无可靠事实、关键数据不可验证或只能重复原叙事时，下一计划交易时段降至不超过总资产 2%的观察仓。

周期或高波动股票还必须：使用正常化或跨周期盈利估值；预先写明 3--5项周期指标及行业比较基准；在相对成本下跌 15%或相对持有期高点回撤 20%时停止加仓并更新周期判断。若下跌 20%且明显弱于窄行业、周期指标恶化或无法解释差异，降至不超过总资产 2%的观察仓；若下跌30%并有公司或行业恶化、或无法完成有效归因，则退出或最多保留 2%观察仓。

这些价格阈值是纪律性复核线，不是已证明有效的固定卖出/买回策略。行业与市场同步下跌时，不因单股跌幅机械卖出；仍须复核行业总仓、组合回撤和内在价值。

### 4.5 A 股计划交易时间（待确认的暂行纪律）

- 普通计划性买入、减仓和分批交易统一在 14:40 使用事先确定的限价单；14:50前未成交则撤单，不追价或临时改价。
- 未成交或部分成交时，剩余数量最早于下一交易日 14:40 重新确认后执行。
- 逻辑证伪、财务造假、治理风险等紧急退出不受该时间限制；仅因盘中涨跌产生的冲动，当日不交易。

## 5. 组合回撤与市场执行

### 5.1 回撤口径（已确认）

- 两个资金池按统一人民币口径合并；外币资产按当日收盘参考汇率换算。外部入金和出金不计作投资收益或亏损。
- 高水位为历史最高日收盘净值；回撤为 `当前收盘净值 / 历史最高收盘净值 - 1` 的绝对跌幅。
- 每周最后一个交易日记录合并净值、各资金池净值、高水位、回撤、股票仓位及现金仓位。

### 5.2 回撤复核（待确认的暂行纪律）

| 从高点回撤 | 必做动作 |
| ---: | --- |
| 10% | 预警：检查行业、地区和盈利驱动的隐性集中；不因回撤本身卖出。 |
| 20% | 全组合复核；逐笔重审最大回撤来源、内在价值、悲观情景和相关暴露，不对未验证逻辑加仓。 |
| 30% | 暂停临时新开仓，五个交易日内完成书面压力测试；只处理逻辑证伪、价值下调、仓位超限或相关性过高的持仓。 |
| 35% | 新增买入只限回撤前已研究、达到预设价值区间且通过集中度复核的标的；卖出资金暂不立即换股。 |
| 40% | 暂停新增买入并全面复盘；重新确认配置、内在价值、相关性和压力情景前不恢复交易，但不机械清仓。 |

任一资金池从自身高点回撤 20%也必须单独复盘。回撤行动的目标是防止无计划补仓和风险继续集中，而非在市场低点机械卖出。

### 5.3 三地市场

| 市场 | 执行要点 |
| --- | --- |
| A 股 | 考虑 T+1、涨跌停、题材炒作、流动性与财报质量；不建立依赖当日反悔卖出的计划。 |
| 港股 | 检查成交量、买卖价差、汇率、治理及港股通资格；流动性较差的小盘股降低仓位。 |
| 美股 | 单独管理美元敞口，关注财报、盘前盘后波动、估值与税务；高估值成长股应使用更严格仓位。 |

## 6. 禁止项与复盘

### 6.1 禁止项（已确认）

- 无交易计划时追涨、杀跌或补仓。
- 因亏损删除、修改或事后重写原始交易理由。
- 用借贷资金或短期必需资金承担权益风险。
- 把未经验证的消息、群聊观点或单一 KOL 意见当作事实。
- 为增加交易次数而交易。

### 6.2 固定复盘节奏

| 节奏 | 只处理的事项 |
| --- | --- |
| 每周 | 检查单股、行业和主题权重与集中暴露；核对财报、政策或宏观事件；更新待观察事实。 |
| 每月 | 复盘是否遵守原计划，统计错误类型而不只看盈亏。 |
| 每季 | 对照公司业绩与原逻辑，评估地区、行业、货币与单股集中度，执行再平衡。 |
| 每年 | 计算滚动12和36个月收益、最大回撤及相对基准，区分选股、仓位和市场贡献。 |

## 8. 待确认事项

1. 成长、红利和债券桶的具体标的与现金下限；
2. 国际资金池中美股与非港股通港股的使用原则；
3. 评价 1--3 年收益的组合基准和期望超额收益；
4. 个股研究投入时间、能力边界及可覆盖的最大持股数；
5. 是否允许 ETF 以外的基金、REITs、可转债、期权或融资；
6. 交易仓是否保留；若保留，其资金上限、止损规则和最长持有期；
7. 价格复核线、回撤动作阈值和 14:40 时间纪律是否经样本外记录后继续保留。
