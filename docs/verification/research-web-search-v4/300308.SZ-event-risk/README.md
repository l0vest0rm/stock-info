## 结论

- `low`：适合快速发现单一显著事件，不适合作为完整风险包。
- `medium`：本轮速度/覆盖的最佳平衡。全部六条记录结构合格，且已覆盖当前最重要的两类事件和财报审计状态。
- `high`：适合需要独立监管来源、后续触发器更完整的人工深挖；不应设为每次常规点击默认档。

所有三档均以最新财报边界为起点，未把 2024 年报作为当前风险状态的默认主证据。注意：三份输出都没有产生 `unavailable` 记录；摘要中的“未检出”只是本次检索范围说明，不能当作不存在风险的证据。
