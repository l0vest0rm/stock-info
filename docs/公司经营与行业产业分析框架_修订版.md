# 第一部分：分析目标与底层逻辑

## 一、分析对象不是一个股票代码，而是一套经济系统

研究一家公司，需要同时理解三个层次：

1. **行业经济性**：行业需求如何形成，供给怎样扩张，产业链利润流向哪里，竞争是否会侵蚀回报。
2. **公司经营质量**：公司在产业链中的位置、竞争优势、增长方式、现金创造能力和资本效率。
3. **证券价值边界**：当前价格需要公司实现怎样的收入、利润率、资本回报和竞争优势持续期。

完整分析链条可以表示为：

\[
\boxed{
\text{终端需求}
\rightarrow
\text{产业链订单与供需}
\rightarrow
\text{公司销量或用户量}
\rightarrow
\text{价格与市场份额}
\rightarrow
\text{收入与利润率}
\rightarrow
\text{资本投入与营运资本}
\rightarrow
\text{自由现金流}
\rightarrow
\text{每股价值}
\rightarrow
\text{市场隐含经营要求}
}
\]

研究的重点不是简单判断“行业好不好”或“公司增长快不快”，而是回答：

- 行业是否允许参与者长期获得高于资本成本的回报；
- 产业链中的利润主要由哪一环节获取；
- 公司是否处于有利位置，并拥有可持续的差异化能力；
- 增长是否需要大量资本、降价、补贴或持续融资；
- 会计利润能否转化为可支配现金；
- 管理层是否持续提高每股价值；
- 当前价格隐含的经营结果是否具有现实可实现性。

## 二、公司质量与证券估值必须分开

公司经营质量主要由以下因素决定：

\[
\text{公司质量}
\approx
\text{竞争优势}
\times
\text{增长空间}
\times
\text{资本回报率}
\times
\text{现金转化能力}
\times
\text{治理质量}
\]

证券价值则取决于未来现金流及其不确定性：

\[
\text{企业价值}
=
\sum_{t=1}^{n}
\frac{FCF_t}{(1+WACC)^t}
+
\frac{TV_n}{(1+WACC)^n}
\]

因此，分析报告应明确区分：

- **经营事实**：已经披露或能够外部验证的数据；
- **经营解释**：数据变化背后的业务原因；
- **预测假设**：未来收入、利润率、资本投入等假设；
- **估值结果**：不同假设对应的价值区间；
- **未知项**：尚无足够证据判断的事项。

## 三、最终应形成的研究结论

一份完整的公司与行业研究，应至少形成以下结论：

1. 公司靠什么赚钱，价值链中谁向谁付费；
2. 行业的核心供需变量、利润池与周期阶段；
3. 公司相对竞争者的优势、劣势及可持续时间；
4. 收入与利润增长由哪些可量化因素驱动；
5. 利润是否转化为经营现金流和自由现金流；
6. 新增资本投入能否带来高于资本成本的回报；
7. 资产负债表能否承受需求下滑、价格下降或融资收紧；
8. 管理层的治理、激励和资本配置是否提高每股价值；
9. 当前估值隐含了怎样的增长、利润率和竞争优势持续期；
10. 哪些领先指标能够持续验证或证伪上述经营假设。

# 第二部分：研究资料与证据分层

研究质量首先取决于证据质量。建议按照下列优先级收集资料，并避免把管理层表述、媒体报道和分析假设混为已披露事实。

## 一、第一层：法定披露与监管文件

优先阅读：

- 年报、季报和半年报；
- 财务报表及附注；
- 审计报告和内部控制报告；
- 重大合同、并购、再融资、担保和诉讼公告；
- 关联交易、资金占用和同业竞争说明；
- 股权激励、股份回购、股份变动和高管薪酬文件；
- 监管问询函及公司回复；
- 股东会、董事会和监事会文件；
- 业务分部、地区、客户集中度及会计政策说明。

对于美股，10-K、10-Q、8-K、代理声明以及财务报表附注是主要来源。对于 A 股，应优先使用巨潮资讯、上交所、深交所和证监会披露。

法定披露中需要特别检查：

- 收入确认政策；
- 关键会计估计；
- 审计意见；
- 内部控制缺陷；
- 商誉和资产减值；
- 关联方及关联交易；
- 或有负债与承诺事项；
- 受限现金、担保与表外安排；
- 稀释后股数及潜在股份。

## 二、第二层：管理层交流

包括：

- 业绩说明会和电话会议；
- 投资者关系活动记录；
- 公司演示材料；
- 资本市场日；
- 管理层公开采访；
- 产品发布和战略说明。

管理层交流主要用于理解战略、业务逻辑和经营解释，但不能直接替代验证。应持续比较：

- 过去承诺与实际完成情况；
- 指引是否经常调整；
- 关键指标口径是否变化；
- 对不利变化是否提供可验证解释；
- 长期战略是否与资本投入和组织建设相匹配。

## 三、第三层：产业链与竞争对手交叉验证

包括：

- 客户与供应商财报；
- 竞争对手披露；
- 行业协会和监管数据；
- 价格、库存、产能、开工率和交付周期；
- 招投标、海关、渠道和终端动销数据；
- 专利、标准、认证、临床和监管文件；
- 产业链资本开支及扩产计划；
- 公司招聘、研发和产品迭代信息。

交叉验证的目的，是检查公司披露是否与产业链事实一致。例如：

- 公司称需求强劲，但客户库存持续上升；
- 公司称份额提升，但同行订单和行业统计并未支持；
- 公司称产品供不应求，但渠道价格和交付周期开始下降；
- 公司称新产品进入放量期，但认证、良率或客户导入仍未完成。

## 四、第四层：行业研究、卖方预测与市场定价

行业研究和卖方资料适合用于：

- 了解市场通行的行业口径；
- 获取产业链地图和关键指标定义；
- 比较市场一致预测；
- 识别机构普遍关注的变量；
- 评估当前价格隐含的经营要求。

这些资料不应作为唯一事实来源。所有关键数字都应尽量回到公司披露、监管资料或可追溯行业数据。

## 五、建议采用统一证据标签

| 标签 | 含义 | 使用方式 |
|---|---|---|
| **正式披露** | 公司或监管机构发布的法定文件 | 可作为财务和重大事项的主要事实来源 |
| **管理层表述** | 电话会、说明会、演示材料中的说法 | 需要与历史兑现和外部数据交叉验证 |
| **外部证据** | 客户、供应商、竞争对手及行业数据 | 用于验证公司叙事和行业位置 |
| **分析假设** | 对未来销量、价格、利润率等的判断 | 必须说明依据、敏感性和不确定性 |
| **未知项** | 尚缺少可靠信息的问题 | 不应填补或伪造，应列入后续跟踪 |

# 第三部分：公司分析的通用主干

## 一、商业模式与产业链位置

### 1. 公司卖什么，谁在付钱

需要按以下维度拆分收入：

- 产品与服务；
- 客户类型；
- 地区；
- 销售渠道；
- 直销、经销、平台或项目制；
- 一次性收入与经常性收入；
- 自营、订阅、广告、佣金、授权或服务费；
- 核心业务与非核心业务。

重点不是复述产品名称，而是画清楚资金流和价值流：

- 最终用户是谁；
- 采购决策者是谁；
- 实际付款者是谁；
- 公司解决了什么问题；
- 客户为何选择该公司；
- 客户替换供应商的成本有多高；
- 公司在产业链中承担何种功能和风险。

### 2. 收入与成本的基本公式

大多数商业模式都可以还原为：

\[
\text{收入}
=
\text{业务量}
\times
\text{单位价格或变现率}
\]

\[
\text{经营利润}
=
\text{收入}
-
\text{变动成本}
-
\text{固定成本}
\]

\[
\text{自由现金流}
=
\text{税后经营利润}
+
\text{非现金费用}
-
\text{营运资本增加}
-
\text{资本开支}
\]

具体研究时应明确：

- “量”是什么；
- “价”是什么；
- 单位成本由什么决定；
- 固定成本占比多高；
- 收入下降时利润会怎样变化；
- 维持现有业务需要多少资本；
- 扩大业务需要多少新增资本。

### 3. 单位经济性

不同公司应使用不同单位：

- 制造业：每件、每片、每台、每吨的收入、成本和利润；
- SaaS：每客户收入、获客成本、回收期和留存；
- 平台：每用户、每订单、每笔交易的收入和贡献利润；
- 零售：单店收入、坪效、客单价和投资回收期；
- 银行：每单位生息资产的收益、资金成本和信用成本；
- 保险：每单位保费对应的承保成本与投资收益；
- 工程项目：每个项目的合同额、毛利、回款和资本占用。

单位经济性应同时回答“能否盈利”和“规模扩大后是否变得更好”。

## 二、收入结构与增长驱动

### 1. 拆分增长来源

\[
\text{收入增长}
=
\text{销量或用户增长}
+
\text{价格变化}
+
\text{产品结构变化}
+
\text{市场份额变化}
+
\text{并购贡献}
+
\text{汇率影响}
\]

需要分别判断：

- 有机增长还是并购增长；
- 真实终端需求还是渠道备货；
- 销量增长还是提价；
- 份额提升还是行业整体扩张；
- 老客户扩张还是新增客户；
- 经常性增长还是一次性项目；
- 本币增长还是汇率换算增长。

### 2. 区分结构性、周期性与一次性因素

| 类型 | 典型表现 | 分析重点 |
|---|---|---|
| **结构性增长** | 渗透率提升、技术替代、人口或消费习惯变化 | 可持续时间、市场上限、竞争进入 |
| **周期性增长** | 价格上涨、库存补充、资本开支扩张 | 周期位置、供给响应、库存和价格领先指标 |
| **份额增长** | 公司增速高于行业 | 价格策略、产品力、渠道和竞争者反应 |
| **并购增长** | 收入随收购快速扩大 | 收购价格、整合、商誉、融资与增量回报 |
| **会计或口径变化** | 并表、确认时点或分类变化 | 可比口径、现金支持和一次性影响 |

### 3. 判断增长是否可持续

重点检查：

- 可服务市场而非笼统市场规模；
- 客户预算和采购周期；
- 产能、良率和交付能力；
- 渠道覆盖和销售效率；
- 新产品认证和导入节奏；
- 竞争者扩产与降价；
- 增长所需研发、营销和资本投入；
- 增量资本回报是否下降。

### 4. 常见增长红旗

- 应收账款和合同资产显著快于收入增长；
- 存货持续增加但终端动销没有改善；
- 通过延长账期、折扣或补贴换取收入；
- 并购贡献掩盖原有业务下滑；
- 新业务收入增长但单位经济性恶化；
- 订单快速增长但取消率、交付延期同步上升；
- 管理层将周期高点解释为永久结构性变化。

## 三、行业结构、产业链与利润池

### 1. 界定行业边界

应先回答：

- 公司真正参与的是哪个细分市场；
- 直接竞争者和替代品是谁；
- 客户采购预算归属于哪个类别；
- 技术或渠道变化是否会重新定义行业边界；
- 公司可实际服务的市场有多大。

笼统的行业总规模通常意义有限，更重要的是：

\[
\text{公司可实现收入上限}
\approx
\text{可服务市场}
\times
\text{可达到份额}
\times
\text{可实现价格}
\]

### 2. 供需结构

重点分析：

- 需求增速及其驱动；
- 供给增速和产能建设周期；
- 产能利用率；
- 库存位置；
- 交付周期；
- 行业资本开支；
- 新进入者和退出机制；
- 价格形成方式；
- 长协、现货、招标或监管定价；
- 供给弹性和需求弹性。

### 3. 产业链利润池

市场规模大不等于所有环节都能获得高回报。应逐环节分析：

- 谁掌握客户和流量；
- 谁控制关键技术、标准或牌照；
- 谁承担库存和资本开支；
- 谁容易被替代；
- 谁拥有定价权；
- 谁在供需紧张时获得超额利润；
- 谁在行业下行时承担主要损失。

建议绘制产业链表：

| 环节 | 主要参与者 | 核心资源 | 定价方式 | 资本强度 | 议价权 | 主要风险 |
|---|---|---|---|---:|---|---|
| 上游 |  |  |  |  |  |  |
| 核心制造/平台 |  |  |  |  |  |  |
| 下游渠道/客户 |  |  |  |  |  |  |
| 替代方案 |  |  |  |  |  |  |

### 4. 竞争结构

需要结合以下因素：

- 行业集中度和份额变化；
- 进入壁垒；
- 客户和供应商议价权；
- 产品差异化；
- 转换成本；
- 替代品；
- 固定成本和退出壁垒；
- 竞争者资本纪律；
- 技术代际与标准变化；
- 监管和政策。

### 5. 周期位置

周期行业应跟踪：

- 产品价格；
- 库存；
- 新增产能；
- 产能利用率；
- 订单和交付周期；
- 上下游资本开支；
- 竞争者扩产；
- 高成本产能退出；
- 价格与盈利是否处于历史高位或低位。

## 四、竞争优势及其持续时间

### 1. 竞争优势的可能来源

- 成本优势；
- 品牌与定价权；
- 网络效应；
- 转换成本；
- 规模经济；
- 数据和算法；
- 专利、标准或牌照；
- 渠道控制；
- 制造工艺与良率；
- 客户认证；
- 生态系统；
- 组织和执行能力。

### 2. 竞争优势必须有经营与财务证据

重点观察：

- 市场份额是否稳定或提升；
- 毛利率是否长期高于同行；
- 提价后客户是否流失；
- 客户留存率和复购率；
- 单位成本是否持续下降；
- 产品性能是否持续领先；
- 新产品导入速度；
- ROIC 是否持续高于资本成本；
- 行业下行期是否仍能保持现金流和份额；
- 竞争者增加投入后优势是否仍然存在。

### 3. 估计优势持续期

估值对优势持续时间非常敏感。分析时需要回答：

- 当前优势依赖单一产品还是系统能力；
- 是否容易被复制；
- 技术代际变化会否重置竞争格局；
- 客户是否正在自研或多元化供应；
- 公司维持优势需要投入多少研发和资本；
- 竞争者追赶需要多长时间；
- 监管是否会限制定价或市场份额。

### 4. 优势削弱的领先信号

- 份额下降；
- ASP 或毛利率下降；
- 客户集中度上升；
- 客户缩短合同期限；
- 研发效率下降；
- 关键人才流失；
- 新产品延期；
- 竞争者认证通过；
- 销售费用增加但增长放缓；
- 行业标准或技术路线改变。

## 五、管理层、治理与资本配置

### 1. 管理层执行力与诚信

应比较管理层历史表述与实际结果：

- 收入、利润率和资本开支指引的兑现度；
- 新产品、产能和客户导入进度；
- 并购后的整合表现；
- 不利信息披露是否及时；
- 指标口径是否频繁变化；
- 对失败是否承担责任并采取纠正措施。

### 2. 治理结构

重点检查：

- 控股股东和实际控制人；
- 董事会独立性；
- 审计委员会；
- 关联交易；
- 资金占用与担保；
- 管理层薪酬和考核；
- 股权激励条件；
- 审计机构、财务负责人变化；
- 控股股东质押；
- 继任计划。

### 3. 资本配置

公司取得现金后通常用于：

1. 维持现有业务；
2. 扩大核心业务；
3. 进入新业务；
4. 并购；
5. 偿还债务；
6. 分红或回购；
7. 保留现金。

分析标准应是每种用途能否提高长期每股价值。重点观察：

- 内部扩张的增量 ROIC；
- 并购价格和后续整合效果；
- 商誉及减值；
- 债务变化；
- 回购价格与稀释后股数；
- 股权激励造成的持续稀释；
- 现金是否长期低效闲置；
- 非核心投资是否偏离主业。

### 4. 治理与资本配置红旗

- 关联交易复杂且商业必要性不足；
- 控股股东资金占用或高比例质押；
- 审计意见异常或内控重大缺陷；
- 管理层频繁变更关键财务指标口径；
- 在行业高点大规模扩产或收购；
- 收购后长期无法兑现协同；
- 回购规模被股权激励稀释抵消；
- 股权激励目标过低或只追求收入规模。

## 六、利润质量、现金转换与营运资本

### 1. 利润表

需要分析：

- 收入增长及其来源；
- 毛利率；
- 经营利润率；
- 增量利润率；
- 研发、销售和管理费用；
- 股权激励；
- 折旧与摊销；
- 一次性损益；
- 税率；
- 少数股东损益；
- 稀释后每股收益。

利润增长应进一步分解为：

- 收入增长；
- 毛利率提升；
- 费用率下降；
- 税率变化；
- 股数变化；
- 资本化或会计估计变化；
- 非经常性收益。

### 2. 现金流

核心指标包括：

\[
\text{经营现金流转换率}
=
\frac{\text{经营现金流}}{\text{净利润}}
\]

\[
\text{自由现金流}
=
\text{经营现金流}
-
\text{资本开支}
\]

还需区分：

- 维持性资本开支；
- 增长性资本开支；
- 资本化研发或软件投入；
- 租赁、供应链融资和保理；
- 一次性营运资本变化。

### 3. 营运资本

重点观察：

- 应收账款和应收票据；
- 合同资产；
- 存货；
- 预付款；
- 应付账款和应付票据；
- 合同负债或递延收入；
- 坏账准备；
- 存货跌价准备；
- 现金转换周期。

典型异常包括：

- 应收增速长期高于收入；
- 存货增加而终端需求减弱；
- 经营现金流改善主要来自延迟付款；
- 合同资产快速增长；
- 票据、保理或供应链融资掩盖真实债务；
- “调整后利润”长期排除经常发生的成本。

### 4. 财务报表联动检查

任何重要判断都应同时查看三张报表：

- 收入增长是否得到应收、存货和现金流支持；
- 毛利率上升是否与产品结构、价格和成本一致；
- 资本开支是否转化为产能、收入和利润；
- 并购形成的商誉是否对应真实现金回报；
- 净利润增长是否伴随稀释后每股现金流增长。

## 七、资本效率与再投资能力

### 1. 核心指标

\[
ROIC
=
\frac{NOPAT}{\text{平均投入资本}}
\]

\[
\text{增量 ROIC}
=
\frac{\Delta NOPAT}{\Delta \text{投入资本}}
\]

\[
\text{可持续增长率}
\approx
\text{再投资率}
\times
\text{增量资本回报率}
\]

增长只有在新增资本回报高于资本成本时才创造经济价值：

\[
\text{经济利润}
=
(ROIC-WACC)
\times
\text{投入资本}
\]

### 2. 分析重点

- 历史 ROIC 是否稳定；
- 高 ROIC 是否由杠杆或低账面资本造成；
- 新增项目回报是否低于旧业务；
- 扩产和研发何时产生收益；
- 收入增长所需营运资本是否上升；
- 资本开支与折旧的关系；
- 公司是否有足够长的高回报再投资空间；
- 增量 ROIC 是否随规模扩大而下降。

### 3. 不同商业模式的资本效率

| 商业模式 | 主要资本投入 | 核心效率指标 |
|---|---|---|
| 制造业 | 厂房、设备、存货、应收 | 产能利用率、资产周转、增量 ROIC |
| SaaS | 研发、销售、股权激励 | CAC 回收期、留存、FCF 率、稀释 |
| 平台 | 技术、补贴、履约网络 | 单位贡献利润、获客效率、网络效应 |
| 零售 | 门店、库存、租赁 | 单店回收期、同店增长、库存周转 |
| 银行 | 监管资本 | ROE、信用成本、资本充足率 |
| 保险 | 偿付能力资本 | 承保利润、负债成本、投资回报 |
| 资源行业 | 矿权、设备、维持资本开支 | 成本曲线、储量寿命、全周期 FCF |

## 八、资产负债表与生存能力

### 1. 重点项目

- 现金及受限现金；
- 短期债务和长期债务；
- 净现金或净负债；
- 利率和到期结构；
- 利息保障倍数；
- 债务契约；
- 租赁负债；
- 商誉和无形资产；
- 养老金；
- 对外担保；
- 诉讼和监管赔偿；
- 可转债与潜在稀释；
- 表外安排和供应链融资。

### 2. 现金真实性

应确认：

- 现金是否受限；
- 是否位于难以调拨的子公司或地区；
- 是否与高息债务同时存在；
- 是否被质押；
- 是否需要维持日常经营或监管资本；
- 是否存在关联方资金往来。

### 3. 压力测试

至少测试：

| 情景 | 需要检查的结果 |
|---|---|
| 收入显著下降 | 毛利率、经营利润和经营现金流变化 |
| 产品价格下降 | 单位贡献利润和现金盈亏平衡点 |
| 应收回款放慢 | 流动性和新增融资需求 |
| 存货减值 | 资本和利润承受能力 |
| 行业低谷持续两年以上 | 现金是否足以覆盖债务、资本开支和固定成本 |
| 融资成本上升 | 利息保障、再融资和债务契约 |
| 重大客户流失 | 产能利用率、应收和库存影响 |

## 九、估值与市场隐含经营要求

### 1. 估值的核心用途

估值不是简单套用倍数，而是把经营假设转化为价值，并检验市场价格要求公司实现何种结果。

需要同时考虑：

- 收入增长；
- 长期利润率；
- 再投资率；
- 增量 ROIC；
- 资本成本；
- 竞争优势持续期；
- 终值假设；
- 净债务；
- 稀释后股数。

### 2. 正向估值

根据经营预测计算价值，常用方法包括：

- 自由现金流折现；
- 股利折现；
- 剩余收益；
- PE、EV/EBIT、EV/EBITDA、EV/收入；
- 市净率；
- 分部估值；
- 资产净值；
- 概率调整项目价值。

应给出多个经营情景，并明确每个情景的：

- 收入增长；
- 利润率；
- 资本投入；
- 现金流；
- 资本成本；
- 终值或退出倍数。

### 3. 反向估值

反向估值从当前价格出发，反推市场要求公司达到：

- 多高的收入增长；
- 多高的长期利润率；
- 多高的增量 ROIC；
- 多低的资本强度；
- 多长的竞争优势持续期；
- 多小的股权稀释；
- 多稳定的终值状态。

反向估值最重要的产出不是一个价格，而是：

> 当前估值依赖哪些关键经营假设，这些假设是否与行业结构、竞争格局和公司历史能力一致。

### 4. 敏感性分析

建议至少测试：

- 收入增速每变化 1—5 个百分点；
- 长期利润率每变化 1—3 个百分点；
- WACC 变化；
- 终值增长率或终值倍数变化；
- 资本开支和营运资本变化；
- 稀释后股数变化；
- 周期高点、中值和低点利润。

### 5. 估值常见错误

- 使用周期顶部利润计算低 PE；
- 用收入倍数而不连接长期利润率和资本回报；
- 忽略股权激励和潜在稀释；
- 终值占估值过高；
- 只选择最有利的同行；
- 将历史最高估值视为合理常态；
- 忽略净债务、租赁负债和少数股东；
- 用企业总增长代替每股价值增长。

## 十、经营风险、领先指标与验证机制

### 1. 风险必须连接财务影响

每个风险都应说明：

- 发生机制；
- 影响的收入、价格、成本或资本项目；
- 可能影响的时间；
- 领先指标；
- 可观察阈值；
- 是否会改变长期竞争地位。

主要风险类别包括：

- 终端需求；
- 价格和毛利率；
- 技术替代；
- 市场份额；
- 客户集中；
- 供应链；
- 产品质量与认证；
- 资本开支与产能；
- 资产负债表；
- 会计与治理；
- 监管、诉讼和地缘政治。

### 2. 建立领先指标体系

领先指标应尽量早于收入和利润变化，例如：

- 订单、在手订单和 book-to-bill；
- 价格、库存和交付周期；
- 客户资本开支；
- 产品认证和设计中标；
- 用户留存和使用量；
- 渠道库存和终端动销；
- 新店回收期和同店增长；
- 逾期、不良和信用成本；
- 临床入组和监管进度；
- 新增产能和行业资本开支。

### 3. 建立经营假设验证表

| 核心假设 | 支持证据 | 反面证据 | 领先指标 | 验证阈值 | 当前状态 |
|---|---|---|---|---|---|
| 行业需求保持增长 |  |  |  |  |  |
| 公司份额继续提升 |  |  |  |  |  |
| 毛利率可持续 |  |  |  |  |  |
| 新业务具备良好单位经济性 |  |  |  |  |  |
| 资本投入能够产生高回报 |  |  |  |  |  |

# 第四部分：行业与产业分析的通用方法

## 一、先确定行业的“量、价、成本、资本”

分析任何行业，先回答六个问题：

1. 行业的“量”是什么；
2. 行业的“价”是什么；
3. 单位成本由什么决定；
4. 增长需要投入多少资本；
5. 产业链利润主要流向哪里；
6. 哪些指标最早反映供需和竞争变化。

通用利润公式为：

\[
\text{行业利润}
\approx
\text{业务量}
\times
(\text{单位价格}-\text{单位变动成本})
-
\text{固定成本}
-
\text{资本成本}
\]

## 二、绘制产业链地图

至少应包含：

- 上游原材料、设备和关键技术；
- 中游制造、平台或服务商；
- 下游渠道、客户和终端用户；
- 替代方案；
- 关键标准与监管机构；
- 各环节集中度、资本强度和议价权；
- 价格与库存在哪个环节形成；
- 现金流和信用风险由谁承担。

## 三、识别行业阶段

| 阶段 | 常见特征 | 分析重点 |
|---|---|---|
| 导入期 | 技术路线不确定、规模小、投入大 | 产品验证、资金需求、技术胜率 |
| 高增长期 | 渗透率快速提升、竞争者增加 | 份额、单位经济性、供给扩张 |
| 成熟期 | 增速放缓、格局稳定 | 定价权、现金流、资本配置 |
| 周期上行 | 价格、利用率和订单上升 | 新增产能、库存和竞争者扩产 |
| 周期下行 | 库存、价格和利润下降 | 成本曲线、资产负债表、退出产能 |
| 衰退或替代 | 需求被新技术或新模式侵蚀 | 现金回收、转型能力、资产减值 |

## 四、行业对比应统一口径

同行比较至少需要调整：

- 产品和客户结构；
- 收入确认口径；
- 地区和汇率；
- 自营与平台模式；
- 资本化政策；
- 租赁和供应链融资；
- 杠杆；
- 税率；
- 股权激励；
- 周期位置。

## 五、行业研究的最终产出

行业章节应形成：

1. 行业边界与市场规模；
2. 产业链结构与利润池；
3. 供需、库存、价格与周期位置；
4. 竞争格局与份额变化；
5. 技术路线和替代风险；
6. 监管与政策；
7. 关键领先指标；
8. 公司相对同行的位置；
9. 行业变量如何传导至公司收入、利润和现金流。

# 第五部分：分行业关注要点

## 1. 科技与半导体行业

### 1. 半导体设计公司

例如 GPU、CPU、通信芯片、模拟芯片、MCU 设计企业。

#### 核心公式

\[
\text{收入}
=
\text{芯片出货量}
\times
\text{平均售价}
\]

#### 重点关注

- 产品代际与技术路线；
- 设计中标和客户导入；
- 出货量；
- ASP；
- 产品组合；
- 毛利率；
- 研发费用；
- 晶圆供应；
- 封装和先进封装能力；
- 客户集中度；
- 渠道库存；
- 下游真实需求；
- 出口管制；
- 股权激励和稀释。

#### 最重要的经营判断

- 高增长来自整个行业，还是公司获得份额？
- 当前产品优势能维持几个代际？
- 客户会不会自研芯片？
- 毛利率是否因为暂时供不应求而处于高位？
- 未来收入是否依赖少数超大客户？

#### 常见误判

- 把订单当成最终收入；
- 把设计中标当成确定出货；
- 用短期供给紧张时期的毛利率外推十年；
- 只看 AI 市场空间，不看客户采购能力和竞争者；
- 忽略代工、封装和 HBM 等供应约束。

---

### 2. 晶圆代工企业

#### 重点关注

- 晶圆出货量；
- 产能利用率；
- 制程节点结构；
- 晶圆平均售价；
- 良率；
- 折旧；
- 资本开支；
- 客户集中度；
- 先进制程收入占比；
- 海外工厂成本；
- 工艺推进；
- 产能建设周期。

#### 核心风险

晶圆厂具有高固定成本和高资本开支特征，因此产能利用率的小幅变化可能造成利润率较大波动。

估值不能只看当前利润，还要分析：

- 当前折旧是否充分；
- 未来扩产需要多少资本；
- 新工厂何时达到合理利用率；
- 先进制程的定价是否足以覆盖更高资本投入。

---

### 3. 存储芯片公司

#### 重点关注

- DRAM 与 NAND 供需；
- bit 出货量；
- ASP；
- 单位 bit 成本；
- 库存天数；
- 客户库存；
- 产能利用率；
- 资本开支；
- 技术节点转换；
- HBM 等高附加值产品占比；
- 长期协议与现货价格；
- 竞争对手扩产纪律。

#### 核心原则

不能用周期顶部利润乘一个低市盈率，就判断公司便宜。

更合理的是使用：

- 中周期利润；
- 中周期自由现金流；
- 资产重置价值；
- 不同供需情景下的盈利能力。

---

### 4. 半导体设备和光通信设备

#### 重点关注

- 新签订单；
- 在手订单；
- book-to-bill；
- 订单取消率；
- 交付周期；
- 产品结构；
- 客户资本开支；
- 服务收入占比；
- 客户认证；
- 市场份额；
- 毛利率；
- 应收账款和存货；
- 新一代产品进度。

设备企业特别需要区分：

- 真正不可替代的核心工艺设备；
- 客户扩产周期中的普通受益者；
- 依赖少数客户集中采购的供应商。

## 2. 软件与 SaaS 行业

### 核心公式

\[
\text{ARR增长}
=
\text{新增客户收入}
+
\text{老客户扩张}
-
\text{客户流失}
-
\text{降价影响}
\]

### 重点关注

- ARR；
- 有机收入增长；
- 净收入留存率 NRR；
- 毛收入留存率 GRR；
- 客户数量；
- 大客户数量；
- 每客户收入；
- RPO 和短期 RPO；
- 续费率；
- 毛利率；
- 销售费用率；
- CAC 回收周期；
- 自由现金流率；
- 股权激励；
- 稀释后股数；
- 产品使用量；
- AI 带来的增量收入与计算成本。

### 最重要的判断

#### 1. 增长来自新客户还是老客户扩张

老客户扩张通常说明产品嵌入客户流程、具备转换成本；完全依赖不断获取新客户，则需要检查获客成本是否越来越高。

#### 2. 经营杠杆能否兑现

很多软件公司能够长期讲“未来利润率会提高”，但需要验证：

- 销售费用率是否下降；
- 研发投入是否能够规模化；
- 股权激励是否长期过高；
- 自由现金流是否来自延迟付款或预收款；
- AI 推理成本是否侵蚀毛利率。

#### 3. 每股价值是否增长

软件公司最容易出现：

- 收入增长 20%；
- 股权激励和增发导致股数增长 8%；
- 每股经济价值增长远低于公司总收入增长。

### 常见估值

- DCF；
- EV/收入；
- EV/自由现金流；
- PE。

但 EV/收入必须与以下指标结合：

- 增长率；
- 长期利润率；
- 留存率；
- 自由现金流；
- 销售效率；
- 股权稀释。

单纯因为另一家公司交易在 15 倍收入，就认为 10 倍收入便宜，并不成立。

## 3. 互联网平台、电商和广告平台

### 核心公式

平台企业通常可以拆成：

\[
\text{收入}
=
\text{用户或交易规模}
\times
\text{使用频率}
\times
\text{变现率}
\]

电商平台：

\[
\text{收入}
=
\text{GMV}
\times
\text{综合变现率}
\]

广告平台：

\[
\text{广告收入}
=
\text{广告展示量}
\times
\text{单位广告价格}
\]

### 重点关注

- DAU、MAU；
- 用户时长；
- 用户留存；
- GMV；
- 订单数；
- 客单价；
- 活跃商家；
- 广告主数量；
- 广告加载率；
- CPM、CPC；
- 抽佣率；
- 履约成本；
- 补贴；
- 获客成本；
- 单位贡献利润；
- 内容成本；
- 网络效应；
- 监管风险。

### 核心判断

平台收入增长需要区分：

- 用户增长；
- 用户使用频率提高；
- 提高广告加载率；
- 提高抽佣率；
- 商业化效率改善；
- 通过补贴人为制造交易规模。

提高变现率可能带来短期利润，但也可能损害用户体验、商家生态和长期增长。

## 4. 消费品牌与零售行业

### 品牌消费品

#### 核心公式

\[
\text{收入增长}
=
\text{销量变化}
+
\text{价格变化}
+
\text{产品结构变化}
+
\text{渠道变化}
\]

#### 重点关注

- 销量；
- 提价；
- 产品结构；
- 市场份额；
- 渠道库存；
- 终端动销；
- 经销商库存；
- 复购率；
- 品牌搜索和心智；
- 促销强度；
- 毛利率；
- 广告营销效率；
- 原材料成本；
- 新品成功率。

#### 最关键的区分

必须区分：

- **sell-in**：公司向经销商发货；
- **sell-through**：经销商真正卖给消费者。

如果公司收入增长来自向渠道压货，而终端销量没有增长，未来可能进入去库存阶段。

### 零售企业

重点关注：

- 同店销售；
- 客流量；
- 客单价；
- 门店数量；
- 单店成熟周期；
- 坪效；
- 库存周转；
- 折扣和促销；
- 新店投资回收期；
- 租赁负债；
- 电商与实体渠道结构；
- 关店成本。

零售企业收入增长如果主要来自大量开店，但老店同店销售下降，增长质量通常较弱。

## 5. 工业制造、自动化和机械设备

### 核心公式

\[
\text{收入}
=
\text{订单量}
\times
\text{价格}
\times
\text{交付能力}
\]

### 重点关注

- 新订单；
- 在手订单；
- book-to-bill；
- 订单取消；
- 交付周期；
- 产能利用率；
- 售价与原材料成本；
- 毛利率；
- 应收账款；
- 存货；
- 预收款；
- 资本开支；
- 售后服务收入；
- 安装基数；
- 客户集中度；
- 下游资本开支周期。

### 关键判断

工业企业往往具有较强经营杠杆：

- 订单增加时，固定成本摊薄，利润增长快于收入；
- 订单下降时，利润可能比收入下降得更快。

因此，不能简单把景气高点的利润率长期外推。

### 特别重要的领先指标

- 新订单；
- book-to-bill；
- 客户资本开支；
- 库存；
- 交付周期；
- 原材料价格；
- 产能利用率。

## 6. 资源、能源、化工和其他周期行业

### 核心公式

\[
\text{利润}
=
\text{产量}
\times
(\text{产品价格}-\text{单位现金成本})
-
\text{资本开支}
\]

### 重点关注

- 产品价格；
- 行业供需；
- 产能投放；
- 产能利用率；
- 库存；
- 成本曲线位置；
- 单位现金成本；
- 储量；
- 储量寿命；
- 维持性资本开支；
- 扩张性资本开支；
- 对冲；
- 环保和复垦义务；
- 资产负债表；
- 竞争对手扩产纪律。

CFA 的商品分析框架强调，不同商品的生产周期、技术结构和产业链不同，供给对外部冲击的调整速度也会明显不同。参考：[CFA Institute：Introduction to Commodities and Commodity Derivatives](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/introduction-commodities-commodity-derivatives)

### 核心判断

周期行业最重要的不是预测一个精确价格，而是回答：

- 公司处于行业成本曲线什么位置；
- 即使价格处于低位，公司是否仍能产生现金；
- 行业高利润会不会吸引大规模新增产能；
- 公司会不会在周期顶部大额扩产或并购；
- 当前市值是按高点、中值还是低点盈利定价。

### 常见误判

- 在商品价格顶部使用 PE；
- 看到低 PE 就认为低估；
- 忽略维持产量所需资本开支；
- 把资源储量等同于可实现价值；
- 忽略税费、运输、品位下降和复垦成本。

## 7. 银行

银行不能完全套用普通制造业的分析方法。

对于银行，存款和债务本身就是经营原料，传统企业的净负债和 EV/EBITDA 口径并不适用。CFA 对金融机构的分析重点包括资产质量、资本充足性、盈利能力、流动性、管理水平以及利率和市场风险敏感性。参考：[CFA Institute：Analysis of Financial Institutions](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/analysis-of-financial-institutions)

### 重点关注

- 净息差；
- 生息资产收益率；
- 存款成本；
- 存款结构；
- 贷款增速；
- 不良贷款率；
- 关注类贷款；
- 逾期贷款；
- 拨备覆盖；
- 信用成本；
- 核心一级资本充足率；
- 流动性；
- 利率敏感性；
- 非息收入；
- 成本收入比；
- ROE；
- 每股净资产；
- 股息和再融资需求。

### 核心公式

银行长期估值主要取决于：

\[
\text{可持续ROE}
-
\text{股权资本成本}
\]

如果银行 ROE 长期低于股权资本成本，即使净利润增长，也可能难以创造价值。

### 估值方法

- 市净率；
- PE；
- 股利折现；
- 剩余收益模型。

市净率不能单独使用，必须与以下因素结合：

- 资产质量；
- 可持续 ROE；
- 资本充足率；
- 信用成本；
- 增长所需资本。

低市净率可能意味着低估，也可能意味着账面资产质量差、ROE 长期低于资本成本。

- 承保利润；

- 巨灾暴露；
- 再保险；
- 投资收益；
- 偿付能力。

### 寿险公司重点关注

- 新业务价值；
- 新业务价值率；
- 保单继续率；
- 退保率；
- 产品结构；

- 利差、费差和死差；
- 准备金；
- 资产负债久期匹配；
- 偿付能力；

### 主要风险

保险公司利润可能因以下因素被高估：

- 准备金不足；
- 使用过于乐观的投资收益率；
- 低估未来赔付；
- 资产与负债久期错配；
- 通过高保证收益产品扩大规模。

保险公司的核心不是单纯保费增速，而是：

> **承保质量、负债成本、准备金质量和投资资产质量。**

## 9. 医药与成熟制药公司

### 重点关注

- 核心产品收入；
- 适应症；
- 市场渗透率；
- 专利到期时间；
- 仿制药或生物类似药竞争；
- 医保和商业保险支付；
- 管线数量与质量；
- 临床成功率；
- 研发费用；
- 销售费用；
- 收购和授权依赖；
- 产品集中度；
- 监管风险。

### 核心问题

- 现有核心药品还有多少专利保护期？
- 专利悬崖造成的收入缺口能否被新产品填补？
- 新管线是否具有真正临床价值，而不只是数量多？
- 公司是依靠内部研发，还是不断高价收购？
- 药品定价和医保谈判是否会压缩收入和利润率？

成熟药企不能只看当前 PE，因为低 PE 可能反映未来核心药品专利到期后的利润下降。

## 10. 尚未盈利的生物科技公司

这类公司不能以传统 PE 分析。

### 重点关注

- 现金余额；
- 季度现金消耗；
- 现金可支撑时间；
- 临床阶段；
- 主要终点；
- 对照组设计；
- 安全性；
- 入组进度；
- 监管沟通；
- 竞争管线；
- 潜在市场；
- 商业化能力；
- 生产能力；
- 合作伙伴；
- 未来融资和稀释。

### 估值方法

通常使用：

\[
\text{概率调整价值}
=
\sum
\text{项目成功概率}
\times
\text{项目成功后的现值}
-
\text{未来研发和商业化投入}
+
\text{净现金}
\]

最大的风险通常不是短期利润下降，而是：

- 临床失败；
- 安全性问题；
- 监管不批准；
- 现金耗尽；
- 低股价下大规模增发。

## 12. 房地产与 REITs

### REITs 重点关注

- 租金增长；
- 同店 NOI；
- 新签租金差；
- 租约到期结构；

Nareit 将 FFO 定义为 GAAP 净利润剔除大部分房地产出售损益和房地产折旧后的指标，并将其作为 REIT 经营表现的补充指标。参考：[Nareit：Frequently Asked Questions About REITs](https://www.nareit.com/what-reit/frequently-asked-questions-about-reits)

房地产折旧可能显著降低会计净利润，但物业经济价值未必按会计折旧速度下降。因此 REIT 通常还需要分析：

- FFO；
- AFFO；
- NOI；
- NAV。

但 FFO 也不是现金流，需要继续扣除：

- 维护性资本开支；
- 租户装修；
- 租赁佣金；

- 销售额；
- 回款；
- 土地储备；
- 拿地成本；
- 项目毛利率；
- 预售监管资金；
- 净负债；
- 短期债务；
- 竣工交付；
- 存货减值；
- 土地和项目所在城市质量。

开发商最重要的是现金流和债务，而不是表面上的会计利润。

## 14. 工程、建筑和项目制公司

- 在手订单；
- 订单质量；
- 业主资信；
- 合同类型；

- 项目进度；
- 毛利率；
- 合同资产；
- 应收账款；
- 预收款；
- 经营现金流；
- 项目减值；
- 诉讼和索赔；
- 海外汇率和政治风险。

### 最大风险

在手订单不等于利润，更不等于现金。

需要检查：

- 订单是否能够执行；
- 项目是否可能延期或取消；
- 是否为低毛利订单；
- 原材料上涨能否转嫁；
- 回款是否可靠；
- 是否通过激进完工百分比确认收入。

## 15. 资产管理、券商和交易平台

### 资产管理公司

重点关注：

- AUM；
- 净流入；
- 投资业绩；
- 管理费率；
- 业绩报酬；
- 产品结构；
- 客户集中度；
- 被动产品竞争；
- 费用率；
- 市场上涨带来的被动 AUM 增长；
- 员工薪酬；
- 种子资金和表内投资风险。

必须区分：

- 市场上涨带来的 AUM 增长；
- 客户真实净申购带来的 AUM 增长。

### 券商和交易平台

重点关注：

- 交易量；
- 经纪费率；
- 客户资产；
- 融资融券；
- 投行业务；
- 自营风险；
- 利息收入；
- 资本充足率；
- 客户留存；
- 监管；
- 市场周期敏感性。

利润高增长可能只是资本市场活跃度暂时提升，而不一定是长期竞争力改善。

# 第六部分：行业估值方法适配

| 行业或商业模式 | 主要估值方法 | 重点经营变量 | 最常见误用 |
|---|---|---|---|
| 成熟制造、消费 | DCF、PE、EV/EBIT | 销量、价格、利润率、资本开支、ROIC | 使用单年周期高点利润 |
| SaaS 与软件 | DCF、EV/收入、EV/FCF | ARR、留存、获客效率、长期利润率、稀释 | 只看收入倍数，不看现金流和股数 |
| 平台互联网 | DCF、分部估值、PE | 用户、频率、变现率、单位贡献利润 | 将 GMV、流量等同于价值 |
| 半导体设计 | DCF、PE、EV/EBIT | 出货、ASP、产品代际、毛利率、研发 | 将短期高增长和供给溢价永久化 |
| 晶圆代工 | DCF、EV/EBITDA、资产价值 | 利用率、节点结构、良率、折旧、资本开支 | 忽略高资本强度和新厂爬坡 |
| 存储、化工、资源 | 中周期利润、DCF、资产价值 | 价格、成本曲线、库存、供给纪律 | 使用周期顶部 PE |
| 银行 | P/B、PE、剩余收益 | ROE、信用成本、资本充足率、资产质量 | 使用普通工业企业 EV 指标 |
| 保险 | P/B、内含价值、剩余收益 | 承保利润、准备金、偿付能力、负债成本 | 忽略准备金和资产负债匹配 |
| REITs | NAV、FFO、AFFO、股利折现 | NOI、出租率、资本化率、债务到期 | 只看会计净利润 |
| 房地产开发 | NAV、现金流、资产清算价值 | 销售回款、土地成本、债务、项目质量 | 只看合同销售额或账面利润 |
| 生物科技 | 概率调整 NPV、净现金 | 临床概率、市场空间、现金消耗、稀释 | 对未盈利企业直接使用 PE |
| 公用事业 | DCF、股利折现、P/B | 监管回报、资本开支、融资成本 | 将低自由现金流一概视为经营恶化 |
| 多元集团 | 分部估值 SOTP | 各业务独立现金流、净债务、总部成本 | 对所有分部使用同一倍数 |

## 一、相对估值的正确使用

同行倍数比较前，应调整：

- 增长率；
- 利润率；
- 资本回报率；
- 杠杆；
- 周期位置；
- 会计口径；
- 资本强度；
- 股权激励和稀释；
- 业务质量和竞争优势持续期。

相对估值只能说明市场如何给同类公司定价，不能单独证明该定价具有经济合理性。

## 二、估值应连接经营变量

任何估值倍数都隐含经营假设。例如：

- 高 PE 通常隐含更高增长、更长优势持续期或更低风险；
- 高 EV/收入必须由未来高利润率和高资本回报支持；
- 高 P/B 需要可持续 ROE 高于股权资本成本；
- 高 NAV 溢价需要资产增值、管理能力或再投资能力支持；
- 周期行业低 PE 可能只是利润处于高点。

## 三、每股口径不可忽略

分析总收入和总利润之外，还应持续跟踪：

- 稀释后股数；
- 每股收益；
- 每股自由现金流；
- 每股净资产；
- 回购与股权激励的净影响；
- 可转债、期权和限制性股票的潜在稀释。

# 第七部分：公司与行业研究报告模板

下面的结构可直接用于具体公司的经营与产业研究。

## 1. 研究范围与事实边界

- 公司名称、证券代码和主要上市地；
- 最新正式财报期；
- 最近年度报告期；
- 使用的法定披露和外部资料；
- 币种、单位和会计口径；
- 尚未正式披露但需要单独标注的信息；
- 关键未知项。

## 2. 公司概况与商业模式

回答：

- 公司卖什么；
- 客户、用户和付款者是谁；
- 产品、地区和客户收入结构；
- 定价模式与合同模式；
- 经常性收入比例；
- 成本结构和资本投入；
- 单位经济性；
- 产业链位置。

## 3. 行业与产业链

包括：

- 行业边界；
- 可服务市场；
- 上中下游结构；
- 利润池；
- 供需与库存；
- 价格形成；
- 产能和资本开支；
- 竞争格局；
- 技术路线；
- 政策与监管；
- 行业周期阶段。

## 4. 公司竞争地位

重点比较：

- 市场份额；
- 产品和技术；
- 成本、良率和交付；
- 品牌、渠道和客户关系；
- 转换成本；
- 研发投入与效率；
- 毛利率、ROIC 和现金流；
- 竞争优势持续期；
- 优势削弱的领先指标。

## 5. 增长、驱动与可持续性

将增长分解为：

- 销量或用户；
- 价格或变现率；
- 产品结构；
- 市场份额；
- 新客户和老客户扩张；
- 新产品；
- 产能；
- 并购；
- 汇率。

对每项驱动说明：

- 已验证证据；
- 持续时间；
- 所需资本；
- 竞争者反应；
- 领先指标；
- 主要反面证据。

## 6. 利润质量、现金转换与营运资本

至少分析：

- 收入、毛利率、经营利润和净利润；
- 经营现金流与自由现金流；
- 应收、存货、合同资产和应付；
- 维持性与增长性资本开支；
- 资本化项目；
- 非经常损益；
- 股权激励；
- 会计政策变化；
- 三张报表之间的联动。

## 7. 资本效率与资本配置

包括：

- ROIC 与增量 ROIC；
- 再投资率；
- 新产能、新产品和研发回报；
- 并购回报；
- 商誉；
- 债务、分红和回购；
- 稀释后股数；
- 每股价值变化。

## 8. 资产负债表与压力测试

包括：

- 可用现金；
- 净债务；
- 债务期限与利率；
- 利息保障；
- 受限现金；
- 担保、诉讼和表外义务；
- 商誉与减值；
- 悲观经营情景下的现金消耗；
- 再融资和稀释风险。

## 9. 估值与市场隐含经营要求

至少提供：

- 适用估值方法及其理由；
- 正向经营情景；
- 反向估值结果；
- 当前价格隐含的收入增长；
- 当前价格隐含的长期利润率；
- 当前价格隐含的增量 ROIC；
- 竞争优势持续期；
- 终值占比；
- 关键敏感性；
- 因数据不足无法判断的估值边界。

## 10. 核心风险与反面证据

# 第八部分：核心总结

公司与行业研究最终可以压缩为一条完整因果链：

\[
\boxed{
\text{行业需求与供给}
\rightarrow
\text{产业链利润池}
\rightarrow
\text{公司竞争位置}
\rightarrow
\text{销量、价格与份额}
\rightarrow
\text{利润率}
\rightarrow
\text{资本投入与营运资本}
\rightarrow
\text{自由现金流}
\rightarrow
\text{每股价值}
\rightarrow
\text{市场隐含经营要求}
}
\]

分析一家公司的核心，不是罗列大量财务指标，而是回答以下八个问题：

1. **公司在产业链中承担什么功能，凭什么获得利润？**
2. **行业供需、竞争和技术变化会把利润分配给谁？**
3. **公司的竞争优势是否有经营和财务证据，能够持续多久？**
4. **未来增长来自销量、价格、份额、新产品还是并购？**
5. **增长需要多少资本，增量回报是否高于资本成本？**
6. **利润能否转化为自由现金流，每股价值是否真正增长？**
7. **资产负债表能否承受行业低谷和经营判断偏差？**
8. **当前价格要求公司实现怎样的经营结果，这些要求是否符合行业规律和公司能力？**

行业分析的作用，是为这八个问题找到正确的量、价、成本、资本、利润池、领先指标和估值方法；公司分析的作用，则是判断公司在这些行业变量中的真实位置及其财务结果。
