# 宏观指标分类体系

## 1. 目的与不可变边界

本目录为 `/macro.html` 定义 **60 个可发布的宏观经济概念**，用于解释盈利、折现率、风险溢价和资金流。它不以“某来源当前恰好有数据”为分类依据；来源只决定一个概念能否被某地区实例化及其可回放边界。

必须区分三层：

- **宏观指标（metric）**：可由统计机构原始发布的经济概念，例如总 CPI 指数或政策利率。
- **具体序列（indicator / series）**：一个地区、一个来源、一个统计定义下的原始观测。不同频率、季调、覆盖范围或发布批次，必须是不同 `definition_id`。
- **展示测度（display measure）**：同比、环比年化、百分点变化、实际利率、期限利差、信贷脉冲和财政脉冲等，由原始观测按同一 `asOf` 查询时计算，绝不成为新的宏观指标或写入 `macro_data`。

`macro_data` 仍严格为 `(indicator_id, period_day, published_at, value)`。`published_at` 是该版本可被用户获知的时间，不得用同步时间、DBnomics 索引时间或页面请求时间代替。

| E | 财政与主权债务 | 财政立场、供债与偿债压力如何变化？ | 盈利、期限溢价 | 6 |

## 3. 60 个宏观指标

名称描述的是原始经济概念；各来源的原始水平、指数或已发布比率由具体序列的 `statistical_definition`、单位和频率说明。不得把“增长”“同比”或“环比年化”默认为所有来源都存在的相同原始序列。

### A. 增长、需求与领先调查（12）

| 编号 | 指标 | 说明 |
| --- | --- | --- |
| A01 | 实际 GDP | 总产出；季度本国口径与年度 WEO 口径是不同统计定义。 |
| A02 | 名义 GDP | 名义收入、税基和债务承受能力的基础。 |
| A03 | 工业产出 | 制造、采矿和公用事业实体活动。 |
| A04 | 实际居民消费支出 | 经价格调整后的居民需求。 |
| A05 | 零售销售 | 高频终端商品消费，不替代实际消费支出。 |
| A06 | 固定资本形成 | 企业、政府和住宅资本形成；不以“中国固定资产投资”替代。 |
| A07 | 制造业景气调查 | 制造业扩张/收缩扩散指数。 |
| A08 | 服务业景气调查 | 服务业扩张/收缩扩散指数。 |
| A09 | 新订单 | 调查中的前瞻需求分项。 |
| A10 | 库存销售比 | 主动补库、被动累库和去库存阶段。 |
| A11 | 产能利用率 | 产能约束、投资意愿和价格压力。 |
| A12 | 消费者信心 | 居民就业、收入和耐用品需求的领先调查。 |

### B. 就业与居民收入（6）

| 编号 | 指标 | 说明 |
| --- | --- | --- |
| B01 | 失业率 | 劳动力市场松紧的总览。 |
| B02 | 就业人数 | 就业水平或可明确定义的当期就业变动。 |
| B03 | 劳动参与率 | 劳动力供给是否退出或回流。 |
| B04 | 职位空缺数 | 职位空缺水平；不能把“数”误称为“率”。 |
| B05 | 名义工资/劳动报酬 | 劳动成本和名义居民收入。 |
| B06 | 实际可支配收入 | 扣除价格后的居民购买力；替代单独的“实际工资增速”。 |

### C. 通胀与成本（8）

| 编号 | 指标 | 说明 |
| --- | --- | --- |
| C01 | 总 CPI | 居民消费价格总指数；同比和环比年化是展示测度。 |
| C02 | 核心 CPI | 剔除预先声明的高波动项目后的价格指数。 |
| C03 | 核心服务价格 | 服务端、工资和内需相关的黏性价格。 |
| C04 | 住房/租金价格 | CPI 中住房或租金分项，不与房价指数混同。 |
| C05 | 终端需求 PPI | 必须定义生产阶段，默认不使用含义不明的“PPI”。 |
| C06 | 进口价格 | 外部成本传导和汇率冲击。 |
| C07 | 市场隐含通胀补偿 | 债券市场定价的通胀补偿。 |
| C08 | 居民/企业通胀预期 | 调查型预期，不能与市场隐含补偿合并。 |

### D. 利率、货币与信贷（6）

| 编号 | 指标 | 说明 |
| --- | --- | --- |
| D01 | 政策利率 | 货币当局直接设定或目标利率。 |
| D02 | 2 年期国债收益率 | 短中端政策路径定价。 |
| D03 | 10 年期国债收益率 | 长端无风险利率和期限溢价。 |
| D04 | 广义货币存量 | 流动性存量；增速由展示层计算。 |
| D05 | 私人部门信贷存量 | 居民和企业信贷余额；增速由展示层计算。 |
| D06 | 银行贷款标准 | 银行信贷供给和风险偏好的调查指标。 |

### E. 财政与主权债务（6）

| 编号 | 指标 | 说明 |
| --- | --- | --- |
| E01 | 财政总体余额/GDP | 一般政府净借贷/净放贷。 |
| E02 | 基础财政余额/GDP | 剔除利息支出后的财政余额。 |
| E03 | 政府总债务/GDP | 必须标注政府覆盖范围和债务口径。 |
| E04 | 利息支出/财政收入 | 利率变化对财政可持续性的压力。 |
| E05 | 国债净发行 | 影响债券供给、期限溢价和流动性。 |
| E06 | 结构性财政余额/潜在 GDP | 财政立场的可比较原始代理；财政脉冲为其变化的展示测度。 |

### F. 外部部门与汇率（8）

| 编号 | 指标 | 说明 |
| --- | --- | --- |
| F01 | 经常账户/GDP | 对外经常收支的综合结果。 |
| F02 | 实际出口量 | 商品和服务出口量，不用名义金额替代。 |
| F03 | 实际进口量 | 商品和服务进口量，不用名义金额替代。 |
| F04 | 官方外汇储备 | 对固定/管理汇率经济体尤其重要。 |
| F05 | 短期外债 | 存量风险；短债/外储覆盖率为展示测度。 |
| F06 | 实际有效汇率 | 贸易竞争力口径，优先于未说明的名义有效汇率。 |
| F07 | FDI 净流入 | 长期跨境资本流。 |
| F08 | 证券投资净流入 | 对利率、汇率和风险偏好敏感的跨境资本流。 |

### G. 房地产与居民资产负债表（5）

| 编号 | 指标 | 说明 |
| --- | --- | --- |
| G01 | 房价指数 | 住宅资产价格指数；同比为展示测度。 |
| G02 | 住宅成交/销售 | 成交量或销售量，必须声明统计范围。 |
| G03 | 住宅投资 | 住宅建设及相关资本形成。 |
| G04 | 新发放按揭利率 | 居民边际购房融资成本。 |
| G05 | 居民债务/可支配收入 | 居民杠杆；不用 GDP 分母替代可支配收入。 |

### H. 金融市场与风险（3）

| 编号 | 指标 | 说明 |
| --- | --- | --- |
| H01 | 宽基股票价格指数 | 原始价格指数；收益率为展示测度，行情仍遵守市场数据来源边界。 |
| H02 | 隐含波动率 | 市场定价的不确定性与尾部风险。 |
| H03 | 金融条件指数 | 利率、信用、股价和汇率的可复核综合指标。 |

### I. 全球商品与供给冲击（6）

| 编号 | 指标 | 说明 |
| --- | --- | --- |
| I01 | 布伦特原油价格 | 全球原油基准。 |
| I02 | 区域天然气价格 | 必须标注区域基准。 |
| I03 | 工业金属价格指数 | 制造、基建和全球需求敏感指标。 |
| I04 | 农产品价格指数 | 食品通胀、天气和供给扰动。 |
| I05 | 黄金价格 | 避险、美元和实际利率敏感资产。 |
| I06 | 全球航运运价 | 全球贸易和物流瓶颈；不与黄金共享指标 ID。 |

## 4. 来源分层与接入边界

| 层级 | 用途 | 可接入范围 | `published_at` 契约 |
| --- | --- | --- | --- |
| 美国高频层 | 经济周期、就业、通胀、利率、地产、风险 | FRED API 和 BLS 已验证系列 | FRED 必须使用 API 的 `realtime_start`；BLS 必须使用已验证的官方发布日历。公共 CSV 不能用于可回放历史。 |
| 年度国际可比层 | 中美及更多经济体的慢变量横向比较 | DBnomics 承载的固定 IMF WEO `WEO:YYYY-MM` 发布批次 | 使用可验证的 IMF 官方发布日；排除该批次的预测年份。 |
| 地区高频官方层 | 中国及其他经济体的本国当期监测 | 后续逐一接入一手发布机构 | 每个来源先验证发布日、修订和许可；不可用镜像或近似指标替代。 |

DBnomics 的 IFS、WDI、OECD 等可变快照即使有数值，也没有本项目所需的逐观测发布时间/修订版本，**不得**写入 `macro_data`。它们不能以 `indexed_at`、抓取时刻或同步时刻伪造 `published_at`。

WEO 仅补充本国高频口径，不覆盖它：A01、B01、C01、E01–E03、E06、F01–F03 可拥有年度 WEO `definition_id`；中国本国 GDP、就业、CPI、贸易和地产高频序列仍需一手来源。

## 5. 目录迁移原则

1. 60 个 `metric_id` 对应本文 A01–I06；数字 ID 是通用经济概念，不因来源或国家变化。
2. 现有 WEO 实际 GDP 序列必须迁回 A01 的独立 `definition_id`，不能作为新的抽象 `metric_id=10001`。
3. 被合并为展示测度的旧条目不再作为启用指标；已有原始事实不伪造转换值、不覆盖历史。
4. 被拆分的旧条目仅在来源和统计定义明确后建立新的具体序列；“A/B”或“或”的模糊名称不能继续启用。
5. 不能被 FRED、BLS、固定 WEO 或一手官方来源支持的指标保持可见但未映射，页面必须显示原因，不能用替代来源静默填补。

## 6. 统一观察口径与验收

页面可在查询时提供水平、同比、环比/年化、百分点变化、历史分位、变化率和首次/修订值；每项均以同一 `asOf` 先选择可见原始版本，再计算展示测度。

分类、来源映射和页面的完成条件是：

1. 目录正好有九类、60 个启用的通用指标定义，且不存在含“/”“或”的模糊指标名；
2. FRED/BLS/WEO 映射均保存真实来源、统计定义、频率、单位与发布时间策略；
3. WEO 预测期不会成为宏观页面的当前值；
4. 比较视图只比较同一 `metric_id` 下已声明可比性的具体序列；
5. `asOf` 回放不会看到当时尚未发布的观察或修订；
6. `macro_data` 仍只有四个数值字段，且没有新增表。
