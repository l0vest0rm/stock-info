# 宏观指标分类体系

## 1. 目的与边界

本文定义宏观研究和监测使用的通用指标目录，先统一**分类、指标含义和分析口径**，不绑定任何国家、地区、现有数据、数据源、接口或页面实现。

同一指标在不同经济体可有不同发布机构、统计定义和可得频率；这些差异属于后续“区域实例化”和数据接入工作，不能反向改变本目录的一、二级分类。

宏观指标用于解释和跟踪四类传导渠道：

```text
宏观变化
├─ 盈利：需求、产出、成本、利润率
├─ 折现率：名义利率、实际利率、期限溢价、融资成本
├─ 风险溢价：信用、财政、外部冲击、政策不确定性
└─ 资金流：货币供给、汇率、跨境配置、杠杆
```

## 2. 目录结构

第一版包含八个一级分类、六十项核心指标。目录优先覆盖能描述经济周期、通胀、政策反应和资产定价环境的指标；不把具体国家名称、证券代码或单一市场行情列为指标分类的一部分。

| 编号 | 一级分类 | 回答的核心问题 | 核心传导 |
| --- | --- | --- | --- |
| A | 经济增长与景气 | 经济是在扩张还是收缩，需求来自哪里？ | 盈利、风险溢价 |
| B | 就业与居民收入 | 劳动力市场是否紧张，居民收入是否支撑需求？ | 盈利、通胀 |
| C | 通胀与价格 | 价格压力来自需求、工资还是供给？ | 折现率、利润率 |
| D | 货币、利率与信贷 | 流动性和融资条件是在放松还是收紧？ | 折现率、资金流 |
| E | 财政与政府债务 | 政府部门是在扩张还是约束需求，偿债压力如何？ | 盈利、期限溢价 |
| F | 外部部门与汇率 | 外需、外汇缓冲和跨境资金是否稳定？ | 资金流、风险溢价 |
| G | 房地产与居民资产负债 | 房地产周期和居民资产负债表是否拖累内需？ | 盈利、信用 |
| H | 市场、风险与大宗商品 | 市场如何定价宏观风险，供给冲击是否在加剧？ | 风险溢价、通胀 |

## 3. 核心指标目录

### A. 经济增长与景气（10 项）

| 编号 | 指标 | 含义 |
| --- | --- | --- |
| A01 | 实际 GDP 增速 | 扣除价格影响后的总体产出变化，是增长的核心结果指标。 |
| A02 | 名义 GDP 增速 | 含价格影响的总收入/产出变化，连接税收、债务和企业收入。 |
| A03 | 工业产出/工业增加值 | 制造、采矿和公用事业活动，反映实体周期。 |
| A04 | 零售销售/消费支出 | 居民消费需求与终端销售变化。 |
| A05 | 固定资产投资 | 企业、政府和房地产资本形成强度。 |
| A06 | 制造业 PMI | 制造业景气扩张或收缩的高频调查指标。 |
| A07 | 服务业 PMI | 服务业景气扩张或收缩的高频调查指标。 |
| A08 | PMI 新订单 | 未来生产和需求的领先线索。 |
| A09 | 库存及库存销售比 | 判断主动补库、被动累库或去库存阶段。 |
| A10 | 产能利用率 | 现有产能的使用程度，连接投资意愿和价格压力。 |

### B. 就业与居民收入（6 项）

| 编号 | 指标 | 含义 |
| --- | --- | --- |
| B01 | 失业率 | 劳动力供求松紧和周期性压力的总览。 |
| B02 | 就业人数变动 | 新增或减少就业岗位的速度。 |
| B03 | 劳动参与率 | 劳动力供给是否退出或回流，避免只看失业率。 |
| B04 | 职位空缺率 | 企业招聘需求与劳动力市场紧张程度。 |
| B05 | 薪资增速 | 名义劳动成本和居民收入增长。 |
| B06 | 实际工资增速 | 扣除通胀后的购买力变化。 |

### C. 通胀与价格（8 项）

| 编号 | 指标 | 含义 |
| --- | --- | --- |
| C01 | CPI 同比 | 居民消费价格的总体年度变化。 |
| C02 | 核心 CPI | 剔除高波动项目后的基础通胀压力。 |
| C03 | CPI 环比年化 | 更及时地观察近期通胀动量。 |
| C04 | PPI | 上游或生产环节价格压力。 |
| C05 | 服务通胀 | 通常更黏性，常受工资和内需影响。 |
| C06 | 住房/租金通胀 | 居民通胀篮子中的重要滞后和黏性部分。 |
| C07 | 能源价格 | 运输、生产成本和短期通胀冲击来源。 |
| C08 | 通胀预期 | 家庭、企业或市场对未来通胀的预期，影响定价和工资行为。 |

### D. 货币、利率与信贷（9 项）

| 编号 | 指标 | 含义 |
| --- | --- | --- |
| D01 | 政策利率 | 货币当局的直接政策立场。 |
| D02 | 实际政策利率 | 政策利率扣除预期或当前通胀后的实际紧松程度。 |
| D03 | 2 年期国债收益率 | 对短中期政策路径的市场定价。 |
| D04 | 10 年期国债收益率 | 长期无风险利率与期限溢价。 |
| D05 | 收益率曲线利差 | 长短端利率差，反映增长、政策和期限溢价预期。 |
| D06 | 广义货币增速 | 经济体系中广义流动性的变化。 |
| D07 | 私人部门信贷增速 | 居民和企业融资扩张速度。 |
| D08 | 信贷脉冲 | 新增信贷相对经济规模的变化速度，侧重边际影响。 |
| D09 | 银行贷款标准 | 银行风险偏好与信贷供给收紧/放松。 |

### E. 财政与政府债务（6 项）

| 编号 | 指标 | 含义 |
| --- | --- | --- |
| E01 | 财政余额/GDP | 政府收支缺口相对经济规模。 |
| E02 | 基础财政余额/GDP | 剔除利息支出后的财政立场。 |
| E03 | 政府债务/GDP | 政府部门债务负担的存量尺度。 |
| E04 | 利息支出/财政收入 | 利率上升对财政可持续性的压力。 |
| E05 | 国债净发行/再融资规模 | 政府融资对债券供给和流动性的影响。 |
| E06 | 财政政策脉冲 | 财政立场相对上一时期的边际变化。 |

### F. 外部部门与汇率（7 项）

| 编号 | 指标 | 含义 |
| --- | --- | --- |
| F01 | 经常账户/GDP | 商品、服务、收入和经常转移后的对外收支。 |
| F02 | 出口增速 | 外部需求和本国出口竞争力变化。 |
| F03 | 进口增速 | 内需、投资需求和进口价格变化。 |
| F04 | 外汇储备 | 应对外部流动性压力和汇率波动的缓冲。 |
| F05 | 短期外债/外汇储备 | 外部流动性风险的关键覆盖率。 |
| F06 | 名义有效汇率 | 对主要贸易伙伴汇率的贸易加权变化。 |
| F07 | 跨境资本流动 | 证券、直接投资和其他资金的净流入/流出。 |

### G. 房地产与居民资产负债（6 项）

| 编号 | 指标 | 含义 |
| --- | --- | --- |
| G01 | 房价同比 | 房地产资产价格与抵押品价值变化。 |
| G02 | 房屋销售 | 购房需求和市场成交活跃度。 |
| G03 | 房地产投资 | 地产对总投资、就业和上游需求的贡献。 |
| G04 | 按揭利率 | 居民购房融资成本。 |
| G05 | 居民部门杠杆率 | 居民债务相对可支配收入或 GDP 的负担。 |
| G06 | 消费者信心 | 对收入、就业和耐用品消费意愿的调查信号。 |

### H. 市场、风险与大宗商品（8 项）

| 编号 | 指标 | 含义 |
| --- | --- | --- |
| H01 | 股票指数收益率 | 风险资产对增长和流动性预期的综合定价。 |
| H02 | 股市波动率 | 不确定性和避险需求的市场化度量。 |
| H03 | 金融条件指数 | 利率、信用利差、股价和汇率等金融环境的综合指标。 |
| H04 | 原油价格 | 全球能源成本、运输成本和地缘供给冲击。 |
| H05 | 天然气价格 | 区域能源供需和工业、居民成本压力。 |
| H06 | 工业金属价格指数 | 制造、基建和全球需求的敏感指标。 |
| H07 | 农产品价格指数 | 食品通胀、天气和供给扰动。 |
| H08 | 黄金价格或航运运价 | 前者侧重避险与实际利率，后者侧重全球贸易与物流；按研究目的择一或并列。 |

## 4. 统一观察口径

同一原始指标至少应支持以下视图；其中转换后的数值不能覆盖原始观测值：

| 口径 | 用途 |
| --- | --- |
| 水平值 | 观察绝对规模、目标区间或制度阈值。 |
| 同比 | 降低季节性影响，判断中期方向。 |
| 环比/环比年化 | 更早捕捉近期动量，但对噪声和季调更敏感。 |
| 历史分位或稳健 Z-score | 判断当前水平相对自身历史的极端程度。 |
| 变化率/加速度 | 区分“正在改善”与“仍处高位但开始回落”。 |
| 首次值与修订值 | 区分当时可得信息与事后修正后的信息。 |

每个指标还应标注领先、同步或滞后属性。该标签描述其通常的时间关系，不意味着它在所有经济体、所有周期中都稳定有效。

## 5. 后续实例化时的最小契约

将目录落到任一国家或地区前，逐项补齐以下元数据：

1. 指标 ID、名称、所属分类和定义；
2. 地域、发布机构、原始来源 URL 与授权边界；
3. 单位、季调状态、统计频率、观察期；
4. 发布时间、下次预计发布时间、首次值和修订版本；
5. 使用的转换方法及其基期；
6. 数据新鲜度、缺失状态和抓取失败原因；
7. 该指标通过盈利、折现率、风险溢价或资金流影响资产的说明。

在上述契约明确前，不以“当前无数据”删减指标，也不以单个来源的可得性改变宏观分类。

## 6. 从零开始的单表存储设计

### 6.1 结论

从零设计 **2 张表**，不复用、不引用、也不迁移任何已有表或已有数据：

1. `macro_indicators`：具体可取数序列的指标目录；同一 GDP 在不同国家/地区各有一行、各有独立整数 ID；
2. `macro_data`：唯一的大历史事实表，只保存指标 ID、统计期、发布时间和数值。

指标定义不使用 JSON 配置，也绝不在每条历史数据中重复。分类、名称、单位、频率的文本体积只存在于小型目录表，历史表的热路径保持全数字、定长且尽可能窄。

```text
60 个通用指标类型
        │
        ├─ GDP：国家/地区 A ── indicator_id = 101
        ├─ GDP：国家/地区 B ── indicator_id = 102
        └─ CPI：国家/地区 A ── indicator_id = 201
                                      │
                                      ↓
                    macro_data（唯一的大历史数据表）
```

### 6.2 `macro_data` 表结构（设计稿）

下列 DDL 是从零开始的目标结构，仅写入设计文档；本次不创建数据库表、不迁移旧数据。

```sql
create table macro_indicators (
  id integer primary key,                     -- 具体序列 ID，如“国家/地区 A 的 GDP”
  metric_id integer not null check (metric_id between 1 and 60),
                                                -- 通用指标类型；分类由其映射得出
  category_id integer not null check (category_id between 1 and 8),
  region_code text not null,                  -- 国家/地区代码，仅存在于小目录表
  definition_id integer not null default 0,   -- 统计口径；标准口径为 0
  name text not null,                         -- 具体序列名称，如“国家/地区 A 实际 GDP 增速”
  frequency text not null,                    -- daily, monthly, quarterly, annual
  unit text not null,                         -- percent, index, currency, persons
  enabled integer not null default 1 check (enabled in (0, 1)),
  unique (metric_id, region_code, definition_id)
);

create table macro_data (
  indicator_id integer not null,
  period_day integer not null,                -- 统计期起始日，YYYYMMDD
  published_at integer not null,              -- 本版本对外可用时间，Unix seconds
  value real not null,                        -- 原始数值；所有派生值均不落库

  primary key (indicator_id, period_day, published_at),
  foreign key (indicator_id) references macro_indicators(id) on delete restrict
) without rowid;

-- 仅服务“最近发布”看板；时间序列与 asOf 查询直接使用主键。
create index idx_macro_data_published
  on macro_data (published_at desc, indicator_id);
```

采用 `WITHOUT ROWID` 后，复合主键就是数据行的物理存储顺序和指标范围查询索引。`macro_data` 每行只有 4 个数值字段，不存 `TEXT`、JSON、分类、指标名、单位、来源、抓取时间、预期值、前值或重复主键；这使长期历史数据的行尺寸和索引尺寸保持稳定且尽可能小。

### 6.3 指标目录契约

`metric_id` 是按本文第 3 节目录顺序固定分配的 `1..60` 数字 ID；`A01` 至 `H08` 只作为文档展示代码，不进入历史数据表。`id` 则是一个可直接存储、查询的具体序列。比如“GDP”这个通用类型在多个国家/地区各拥有不同的 `id`，但共享同一个 `metric_id`。`category_id` 只保存在目录表，历史数值写入不会触碰该表。

- `id`、`metric_id` 都是小整数；数据表只保存 `indicator_id`，国家/地区、分类和指标名称永不重复写入历史行。
- `name`、`frequency`、`unit` 只存在于该表。`period_day` 只保存统计期起点，期长由 `frequency` 推导，无需每行存结束日期。
- `published_at` 同时充当版本顺序和“当时可见”的时间；因此不再保存冗余的 `vintage_at`、`revision_number` 与摄入时间。
- 不同国家/地区的同一通用指标直接新增 `macro_indicators` 行，因此历史表无须增加 `region_id` 或地区文本。若同一国家/地区出现不可比的新统计口径，使用新的 `definition_id` 和新的 `id`，不能覆盖原序列。

### 6.4 单表契约

| 场景 | 规则 |
| --- | --- |
| 新国家/地区的既有指标 | 增加一条带相同 `metric_id`、不同 `id` 和 `region_code` 的 `macro_indicators` 记录；不创建新历史表。 |
| 新通用指标 | 增加新的 `metric_id`、目录记录及对应数据行；不创建新历史表。 |
| 首次发布 | 插入一行；`published_at` 是首次可用时间。 |
| 后续修订 | 以更大的 `published_at` 新增一行，首次值永不更新或删除。 |
| 同步重试 | 命中复合主键时幂等忽略或覆盖同一数值，不能重复出行。 |
| 同比、环比、年化、Z-score | 查询时从原始 `value` 计算；不写入第二行或第二张表。 |
| 暂未发布 | 不插行，不以 `0` 或空值伪造数值。 |

默认图表查询取同一 `(indicator_id, period_day)` 下 `published_at` 最大的一行；历史回放则限制 `published_at <= asOf` 后再取最大值。因此单表仍可同时支持最新视图、修订对比和无前视回放。

### 6.5 极限性能边界

- 主键按“指标 → 统计期 → 发布版本”排列，覆盖单指标时间序列、修订历史和 `asOf` 查询；查询必须先限定指标 ID 和时间范围，禁止全表扫描。
- 所有筛选键与时间键均为整数；`YYYYMMDD` 保持自然时间排序且无日期字符串解析成本，`published_at` 使用秒级整数即可覆盖宏观数据发布精度。
- 正常图表只取时间窗口和每期最新版本；全量修订历史仅在详情或回测请求中按需读取，不能默认加载。
- `idx_macro_data_published` 仅用于按最新发布排序；若真实查询计划证明它未被使用则删除，不预先堆叠多余索引。
- 表仍只存已发布的数值。原始响应、日志、预期值、前值、质量标记和派生指标不是核心历史事实，默认不落库；若以后确有独立业务需求，须重新设计并经批准，不能反向膨胀本表。

### 6.6 边界

本设计只定义“宏观指标数值”的唯一存储表。事件日历、账户偏好、通知记录、抓取任务等不在本次范围；它们不构成本表的前置条件，也不影响本表只有一张的结论。

### 6.7 实施前验收

1. 物理表只有指标目录 `macro_indicators` 与历史事实 `macro_data` 两张；不存在按 GDP、CPI、地区、频率、历史或修订拆出的表；
2. `macro_data` 单行只有 `indicator_id`、`period_day`、`published_at` 和 `value` 四个数值字段；
3. 同一指标的首次发布与任意修订可在单表中完整保存和查询；
4. 国家/地区、指标类别、名称、单位和频率仅存在于 `macro_indicators`，不在任何数据行重复；
5. 新增指标只新增目录记录和数据行，不需改表或新建表；
6. 最新、全版本和 `asOf` 查询走复合主键；最近发布查询走唯一的辅助索引；
7. 不依赖任何现有表、数据、迁移或命名约定。

## 7. 依赖关系与验收

本目录是后续工作中的上游契约，依赖顺序如下：

```text
指标分类与定义（本文）
        ↓
区域实例化与来源口径确认
        ↓
观测值/修订版本的数据契约
        ↓
采集、存储、接口与展示
        ↓
信号、跨市场传导和回测
```

本文完成的验收条件：

- 分类不依赖某一国家、数据源或当前是否有数据；
- 八个一级分类覆盖增长、通胀、就业、货币信贷、财政、外部、地产居民和市场风险；
- 共列出六十项具有明确经济含义的核心指标；
- 为每项后续接入保留统一口径和元数据契约。
