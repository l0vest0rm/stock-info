# 宽基式优质公司组合：细分赛道与候选观察池（v1）

> 建立日期：2026-10-27；研究口径：A股、港股、美股与可访问的韩国市场。  
> **定位：先构建研究覆盖宇宙，不是今日买入清单，也不是已经完成的估值排名。** 证券代码/存托凭证/交易可达性须在交易前再核验；**没有在本稿中填入未经核实的即时价格、PE或预期盈利。**
>
> 宇宙规模：**11个一级行业、37个自定义细分赛道、98家不重复的经营公司**（多地上市只计一家）。目标实际股票持仓**20–30家，基准25家**。候选公司均为研究起点，不因纳入而认定“基本面优秀、估值便宜或值得立即买入”。

## 1. 目标与边界

1. **横向像宽基，纵向像精选基金。** 参考[GICS全球行业分类](https://www.msci.com/indexes/index-resources/gics)的11个一级行业做广度覆盖，但本稿的37个细分赛道是为投资研究定制的**工作分组，不等于官方GICS子行业，也不应覆盖仓库已核实的行业主分类**。
2. **一家经营公司只能有一个主赛道**，可同时拥有多个非排他性主题标签（AI资本开支、消费复苏、国产替代、利率敏感、商品价格等）；A/H/ADR 是不同上市证券，不重复计入公司数，不能直接假设交易权利、ADR换算、价格或税务等价。
3. **每个入选赛道一般持有1家，极少数允许2家**；不必把37条赛道买满。20–30只是一种集中而非真正复制沪深300或S&P 500的主动组合，无法消除个股风险。
4. **100家以内由AI持续观察，但交易资格靠数据与估值过关。** 不因行业覆盖空白而买入平庸公司，也不因公司好而忽略高估值。
5. **A股、港美股等资金池分别执行**。如果资金存在跨账户或跨市场转移限制，先给每个资金池单独设定行业与风险预算，统一做穿透风险统计，不假设能随意移仓。
6. **优先保持收益质量而非机械平均分散**：寻找长期竞争优势、资本回报率与合理价格，同时用行业/因子上限防止一次判断失误重创净值。

## 2. 一个可用的25只组合“席位预算”

这是**策略样例，不是已确认的买入名单或市场权重**；每个行业实际可为0，保留行业空位以等待性价比。以下权重仅指股票资产内部的100%，总资产层面的现金/债券另行规划。

| 一级行业 | 初始席位数 | 股票部分目标权重 | 选择思路 |
|---|---:|---:|---|
| 信息技术 | 6 | 23% | AI芯片、存储、光通信、PCB及软件合计，按风险桶再约束 |
| 通信服务 | 2 | 8% | 互联网平台与运营商有不同利润驱动 |
| 可选消费 | 3 | 12% | 汽车、家电、电商渠道 |
| 必选消费 | 2 | 10% | 品牌消费及稳定现金流 |
| 医疗保健 | 3 | 12% | 药品、器械、服务 |
| 金融 | 3 | 12% | 银行、保险、市场基础设施/支付择优 |
| 工业 | 3 | 11% | 自动化、电网及物流等，避免全部买AI配套 |
| 原材料 | 1 | 4% | 以成本优势和周期归一化利润择优 |
| 能源 | 1 | 4% | 油气或煤炭二选一，控制商品因子 |
| 公用事业 | 1 | 4% | 水电/电力或燃气，关注分红覆盖 |
| 房地产 | 0 | 0% | 先观察；若以后配置，须从其他席位腾挪 |
| **合计** | **25** | **100%** | **约束与收益并重，权重可根据估值与风险调整** |

建议作为**风控初始阈值**、而非市场规律：单家公司常态目标2%–6%，软上限6%，硬上限8%；单一细分赛道原则上不高于8%；同一一级行业原则上不高于25%；按**共同驱动**计算的AI数据中心建设/资本开支相关持仓合计暂以25%–30%为风险预算参考（可由投资者决定是否调整）；每季度或发生实质性事件时重新检查。达到上限不构成自动卖出信号；执行还要考虑价差、税费、交易资格和基本面。

**重要：** 中际旭创、新易盛、胜宏科技、沪电股份、美光、SK海力士、英伟达、台积电、伊顿等可能横跨不同赛道，仍与AI算力建设周期高度相关，必须在组合里把同因子风险合并计算。

## 3. 候选观察池（按“主营经济业务”先行归类）

- **候选顺序仅是研究入口，不是收益预期名次、实时估值排名或交易建议。**
- 复合业务公司在候选表中仅占一个主赛道；对其另一块业务只打主题/业务标签（如亚马逊的AWS、阿里巴巴的云、腾讯的游戏与云）。正式纳入前以分部收入/利润、业务模式及公司公告核实主赛道。
- 同赛道候选可以只选一家或暂不选；同赛道内商业模式不完全可比时必须细拆，不能直接按同一个PE比较。

## 5. AI观察池如何工作：广覆盖、少决策、只提示变化

建议将98家公司视为一张**分层可维护的研究清单**，而不是每天为98家公司撰写长报告：

1. **L0 身份与主业务（全体98家）**：规范公司ID、证券/上市地映射、唯一主赛道、主题标签、财报日历、最近资料日期和证据来源。
2. **L1 低频结构观察（全体98家）**：公司公告、财报及可靠行业新闻的增量去重；每周汇总真正变化，每季度刷新财务质量、估值位置、竞争地位。
3. **L2 深度跟踪（大约25–40家可调整）**：行业景气、客户/订单、分部利润、估值场景；优先现有持仓、同赛道最有胜率的替代品及接近买入条件的候选。
4. **L3 买入候选（约5–15家动态）**：有最新源证据、保守估值/安全边际、可验证的投资命题、明确权重及失效条件；**不自动交易**。
5. **持仓层（20–30家）**：每天监测重大事件；季度结合财报复核投资命题、组合集中度和风险因子；必要时发起人工复核。

**变更触发：** 重大业绩/指引差异、盈利质量恶化、竞争格局变化、政策/客户丢失、资本结构恶化、估值进入安全边际、核心管理层变动；只输出“新事实—与旧预期差—影响路径—证据/不确定性—是否需要人工行动”，避免仅凭股价涨跌产生重复提醒。

## 6. 行业内择优与换仓规则

先做**不可妥协的排除检查**：无法可靠披露、重大治理/财务造假疑虑、股东权益不可清晰确认、商业模式缺乏可验证收入与现金流、财务杠杆可能导致永久性损失、证券不可实际交易的标的，不能仅凭故事进入买入层。

随后同赛道对候选执行**六维研究卡**，这是分析优先次序，不宜当作跨行业机械评分：

| 维度 | 建议关注内容 |
|---|---|
| 护城河与竞争格局 | 定义相关竞争市场、可持续份额/定价权、替代威胁 |
| 财务质量 | 周期中枢利润、现金流、资本回报；银行保险换专用口径 |
| 中长期成长 | 市场规模、份额与利润池、公司兑现能力、增长可见性 |
| 管理层与资本配置 | 并购、回购、分红、资本开支、治理与股东权益 |
| 估值与安全边际 | 基准/悲观/乐观情景、与市场预期差、买入价格区间 |
| 永久损失风险 | 资产负债、技术淘汰、政策与股东权利、极端压力测试 |

**替换顺序建议：** 新候选的未来风险调整后回报必须明显好于原持仓，且交易税费、流动性、仓位上限和同因子暴露允许，才考虑换仓。不能简单把“今年跌幅小”“新闻热度高”当成优质公司证明，也不要因为仓位需要补齐某个行业就降低准入标准。
