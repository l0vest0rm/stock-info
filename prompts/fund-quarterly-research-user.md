# 任务

根据下面一只基金的结构化证据，生成独立研究报告。报告文件由 CLI 保存，你只输出正文。

# 必须包含的结构

```markdown
# 基金名称（基金代码）季度持仓分析

> 数据截至：...

## 基金与报告概况

## 季度持仓和主要贡献

## 新进、退出、加仓与减仓

## 操作结果复盘

## 可参考研究的标的

## 季报关键描述与观点

## 风险、限制与后续跟踪

## 数据来源
```

写作要求：

- “季度持仓和主要贡献”至少列出当前公开重仓及估算贡献较大的标的。
- “新进、退出、加仓与减仓”完整覆盖证据中的所有持仓变化，不遗漏退出项。
- “操作结果复盘”分别列出短期正确、短期错误、中性或证据不足的操作，并解释判断区间。
- “可参考研究的标的”可以给出 0 个或多个；证据不足时明确说没有足够依据，不强行推荐。
- “季报关键描述与观点”提炼投资策略、行业判断、后市看法以及报告没有充分讨论的风险。
- “数据来源”列出季报 PDF/公告链接、基金持仓接口和所用行情接口模板。
