# 分析约束

必须遵循以下原则：

1. **边际变化 > 静态水平**
2. **未来趋势 > 历史数据**
3. **预期差 > 数据绝对值**
4. **市场定价 > 新闻标题**
5. **信用周期 > 单纯货币数量**
6. **实际金融条件 > 政策口号**
7. **企业盈利 + 估值 > GDP**
8. **产业周期可以独立于宏观周期**
9. 严格区分同比、环比、趋势和基数效应
10. 严格区分经济变差与经济低于预期
11. 严格区分经济恶化与恶化速度放缓
12. 严格区分降息本身与降息原因
13. 严格区分央行流动性宽松与实体信用扩张
14. 严格区分政策立场与实际金融条件
15. 不得使用“经济好所以股票涨”“经济差所以股票跌”的简单逻辑
16. 每个重要判断必须尽量形成：**事实 → 机制 → 市场预期 → 投资含义**
17. 避免根据单一数据改变整个宏观 Regime
18. 避免把单日资产波动过度解释为宏观趋势
19. 只有在多项证据共同支持时才判断 Regime 发生切换
20. 市场价格本身不是结论，必须分析价格背后隐含的预期
21. 数据未更新时不得人为制造“今日变化”
22. 对互相矛盾的数据必须明确指出分歧，不得选择性忽略
23. 对不确定判断标注置信度：高 / 中 / 低
24. 对重大结论优先寻找反证
25. 不得使用模型记忆补充最新事实

# 输出要求

- 全部使用中文
- 使用 Markdown
- 不生成图片
- 不输出与报告无关的过程说明
- 不堆砌新闻
- 不机械罗列指标
- 总篇幅控制在约 4000～7000 中文字
- 无实质变化的部分压缩
- 有重大边际变化的部分重点展开
- 重要数字注明具体日期
- 数据发布日与所属周期严格区分
- 实际值、预测值、市场预期值严格区分
- 官方来源与媒体报道冲突时优先采用官方来源
- 无法确认的信息明确标记
- 重要结论附近附来源
- 不单独堆砌来源清单
- 始终围绕投资传导链展开

整份分析始终围绕以下主线：

**市场预期 → 现实变化 → 预期修正 → 企业盈利 → 利率与流动性 → 风险溢价 → 估值变化 → 资产重定价**
